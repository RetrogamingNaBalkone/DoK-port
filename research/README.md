# Локальное хранилище исследований

Эта папка хранит материалы, которые нельзя терять при очистке `build/`.
Полное содержимое локальное, исключено из Git и поставки; этот указатель
и сводки в `analysis/`/`docs/` входят в Git.

- `ghidra/projects/` — актуальные проекты PKR/PKE/Old Gold.
- `ghidra/*pass*` — предыдущие проходы; рядом настройки Ghidra.
- `evidence/` — ASM, автоматический C, экспортированные сегменты, векторы,
  исходные наблюдения и исследованные ресурсы.
- `experiments/` — отчёты и текстовые снимки исходников G20A/G20C.
  Промежуточные сборки, сгенерированные банки и повторные кадры удалены;
  сохранён контрольный 2775 с ROM/ELF/map. Архивы больше не являются
  полными каталогами для перелинковки: необходимые банки надо генерировать заново.
- `_migration/` — пофайловые SHA-256 и соответствие старых/новых путей.

Перенос: [паспорт](../docs/tasks/RESEARCH-STORAGE.md),
[сводный манифест](../analysis/research-relocation-20261027.json).
Последующая очистка по запросу пользователя:
[отчёт](../analysis/storage-cleanup-20261027.json). Исторические отчёты
остались без изменений и могут ссылаться на удалённые сборочные выходы;
старые collectors требуют их повторной сборки и новых проверок.
Старые манифесты и журналы сохраняют пути исходного запуска. Для поиска
старого `build/<каталог>/...` используйте `moves` сводного манифеста.
Хеши архивных драйверов относятся к старой версии; после изменения путей
проверка актуальности драйвера может требовать нового запуска анализа.

Это не редактируемый движок. Автоматический C не считается собираемым кодом
или проверенным эквивалентом оригинала. Сохраняйте различие файловых смещений,
NE-сегментов, адресов Ghidra и DPMI-селекторов.

Оставшиеся в `build/` текущие сборки также могут содержать диагностические
кадры/логи. Завершённое исследование следует сохранять здесь вместе с
манифестом и описанием в `docs/`; `build/` пока не является свободно удаляемым
каталогом: в нём ещё есть используемые сборкой пакеты и базовые объекты.
