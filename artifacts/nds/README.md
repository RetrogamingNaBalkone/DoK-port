# Текущая NDS-сборка

`dok.nds` — один автономный ROM с обоими языками RU/EN. Все игровые данные
встроены в NitroFS; внешние `assets.ndp`, `ui.dat`, `frontend.dat` не нужны.
Язык переключается в главном меню и меню паузы.

На обычной Nintendo DS/DS Lite homebrew запускается через flashcart,
вставляемый в слот DS-картриджа. Если загрузчик поддерживает запись на свой
носитель, игра сохраняет только настройки в `dok/settings.dat`, создавая
каталог при необходимости. Без записываемого хранилища игра работает,
но выбор языка не сохраняется между запусками. Игровых сохранений нет.

Происхождение, SHA-256, команды и ограничения:
[playtest09 от 31 октября 2026 года](../../docs/nds/spec/playtest09-20261031.md).
`manifest.json` содержит SHA ROM и проверенных встроенных файлов.

Публикация из проверенной компиляции:

```powershell
py -3.14 -B -X utf8 ports/nds/tools/package_rom.py --target build/nds/n23/playtest09-ru
```

Это текущий кандидат N23; полная приёмка N23 и физическая проверка DS/DS Lite
ещё открыты. Бинарные файлы и игровые данные не включаются в Git.

Исправления плейтеста: исходный FONT8 без масштабирования, HUD с оружием
справа от патронов и ключами справа внизу, ускоренная загрузка с индикацией,
исправлена воспроизведённая остановка после бластера. Крупные замены текстур
удерживают предыдущую сцену. Нижняя рамка убрана, сообщения и числа центрированы.
Таймеры/интервалы анимаций проверены; визуальный плейтест остаётся открытым.
