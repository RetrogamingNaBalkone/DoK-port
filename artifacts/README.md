# Отобранные сборки

Каталоги `gba/`, `nds/` и `sdl2/` содержат выбранные результаты для проверки или выдачи пользователю. Они создаются по мере появления сборок. Промежуточные результаты находятся в `build/<порт>/`.

Сборки и игровые ресурсы исключены из Git; в этом дереве допускаются README с описанием назначения и происхождения результатов. Исторические хеши и ограничения сохраняются в документации соответствующего порта.
