# DoK Source Port — Windows x64, предварительный плейтест

Работают PKR, PKE и Old Gold; программный VGA-рендерер и самостоятельный
OpenGL 2, широкий обзор Hor+, HUD поверх сцены, клавиатура/мышь и геймпад.

Положите рядом с dok_port.exe свои PKR.RES, PKE.RES и/или OLD_GOLD.RES.
Нужен хотя бы один архив. Запустите Play-OpenGL.cmd или Play-Software.cmd.
Можно также перетащить RES на окно приложения либо указать `--res ПУТЬ`.
На заставке Left/Right переключают набор; Up/Down — уровень Кремля;
Enter/A запускает. У Old Gold одна карта LEVEL4.

- WASD — движение и стрейф, Q/E — дополнительные кнопки стрейфа.
- Мышь / стрелки Left/Right — поворот; движение, стрейф и поворот совмещаются.
- Ctrl / левая кнопка мыши — огонь, Space / Enter — дверь.
- 1/2 и PageUp/PageDown — оружие; Shift — бег, Alt — медленное движение.
- Геймпад: левый стик — движение/стрейф, правый — поворот, A — дверь,
  X / правый триггер — огонь, плечевые кнопки — оружие, Start — пауза.
- Esc — пауза; F11 — borderless fullscreen. Потеря фокуса ставит игру на паузу.
- F3 — показать/скрыть FPS (изначально включён).
- F4 — nearest/linear. По умолчанию nearest; в GL меняет фильтр сцены,
  в software — масштабирование кадра. GL HUD и текст остаются пиксельными.
- F12 — PNG-скриншот в `screenshots` текущей рабочей папки, с уникальным именем.
- Enter/A листает тексты и подтверждает повтор после смерти.
- Во время игры наберите `IDKFA`: все ключи и оба оружия, сообщение
  «Ах ты хитрый думер!». Регистр и раскладка не важны (физические клавиши IDKFA).
  Новое оружие даёт заряд как при обычном подборе; повторный чит запас не увеличивает.

Размер окна: `dok_port.exe --size 1280x720`. Выбор рендерера:
`--renderer gl` (по умолчанию) или `--renderer software`.
Фильтрация: `--filter nearest` (по умолчанию) или `--filter linear`.
Переключение F4 пока не сохраняется между запусками.
GL HUD r4: исходные значки и FONT8 в отдельном экранном слое, компактная нижняя
строка без подписей, стопка карточек оружия, ключи под зарядом. Сообщения справа;
здоровье показывает краткую прибавку/потерю. Desktop-профиль, портативная компоновка
для PSP 480×272 и PortMaster отложена. Software сохраняет классическую панель.
Прямой запуск: `dok_port.exe --res OLD_GOLD.RES --level LEVEL4 --skip-intro`.
В Old Gold для выхода нужно собрать все105 рублей; счётчик виден в HUD.

Это контрольная сборка для плейтеста, не готовый релиз. Сохранений, меню
настроек, переназначения кнопок, независимого выбора языка и карты пока нет.
Программный путь пока VGA320×200; остальные DOS-видеорежимы не реализованы.
HUD Old Gold адаптирован к общей игровой области320×160, а не воспроизводит
исходную панель попиксельно. Общие анимации декораций ещё не подключены.
Есть известные расхождения геометрии и растеризации с DOS. Звук OG передаёт
байты исходного SB-пути; звучание и громкость ещё не сверены с DOS-записью.
Linux/ARM/PortMaster, GLES, PSP и Switch пока не проверены и не собраны.

Проверено: CTest13/13, отдельный сценарий OG (105 рублей, обе палочки,
600 кадров с движением/AI/снарядами, условие выхода), запуск обоих рендереров.
Полного прохождения человеком пока не было. Для сообщения об ошибке полезны
набор/уровень, рендерер, шаги воспроизведения и `%APPDATA%/DoK-port/SourcePort/port.log`.
Архивы игры в поставку не входят. SDL2 распространяется с приложенной лицензией.
