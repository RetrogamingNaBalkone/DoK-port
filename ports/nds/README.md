# Nintendo DS

Место независимой реализации для DS/DS Lite. [План](../../docs/nds/plan.md), [handoff](../../docs/nds/handoff.md), [паспорт N01](../../docs/nds/tasks/N01.md).

Реализация не начата. Будущие исходники, инструменты и тесты размещаются внутри этого каталога, выходы — в `build/nds/`, отобранные сборки — в `artifacts/nds/`. SDK устанавливается в общий пользовательский каталог. Игровые сохранения не добавляются; на microSD записываются только настройки.
