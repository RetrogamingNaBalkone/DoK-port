# DoK Source Port — Windows x64, предварительный плейтест

Работают PKR, PKE и Old Gold; программный рендерер и самостоятельный
OpenGL 2, широкий обзор Hor+, HUD поверх сцены, клавиатура/мышь и геймпад.

Положите рядом с dok_port.exe свои PKR.RES, PKE.RES и/или OLD_GOLD.RES.
Нужен хотя бы один архив для игры. Запустите Play.cmd (сохранённые настройки).
Play-OpenGL.cmd и Play-Software.cmd принудительно выбирают вывод на этот запуск.
Можно также перетащить RES на окно приложения либо указать `--res ПУТЬ`.
«Начать игру» открывает выбор набора, если их несколько, затем штатную
заставку, предысторию и выбор уровня. У Old Gold одна карта LEVEL4.
Меню: стрелки/крестовина, Enter/A — выбрать, Esc/B — назад; работает мышь.
Текст листается PgUp/PgDown или L1/R1, иллюстрация остаётся на месте.
На первом запуске русский язык выбирается для русской локали ОС,
для остальных — английский. Ручной выбор запоминается. Сюжет и игровые
сообщения пока остаются на языке RES независимо от языка интерфейса.

Современное управление (начальный пресет):

- WASD — движение и стрейф, Q/E — дополнительные кнопки стрейфа.
- Мышь / стрелки Left/Right — поворот; движение, стрейф и поворот совмещаются.
- Ctrl / левая кнопка мыши — огонь, Space / Enter — дверь.
- 1/2 и PageUp/PageDown — оружие; Shift — бег, Alt — медленное движение.
- Геймпад: левый стик — движение/стрейф, правый — поворот, A — дверь,
  правый триггер — огонь, левый — бег, плечевые кнопки — оружие, Start — пауза.
- Esc — пауза; F11 — borderless fullscreen. Потеря фокуса ставит игру на паузу.
- F3 — показать/скрыть FPS (изначально включён).
- F4 — nearest/linear. По умолчанию nearest; в GL меняет фильтр сцены,
  в software — масштабирование кадра. GL HUD и текст остаются пиксельными.
- F12 — PNG-скриншот в `screenshots` текущей рабочей папки, с уникальным именем.
- Enter/A листает тексты и подтверждает повтор после смерти.
- Во время игры наберите `IDKFA`: все ключи и оба оружия, сообщение
  «Ах ты хитрый думер!». Регистр и раскладка не важны (физические клавиши IDKFA).
  Новое оружие даёт заряд как при обычном подборе; повторный чит запас не увеличивает.

Размер окна: `dok_port.exe --size 1280x720`. Выбор рендерера:
`--renderer gl` (по умолчанию) или `--renderer software`.
Фильтрация: `--filter nearest` (по умолчанию) или `--filter linear`.
Меню настроек разделено на графику, звук, управление, геймплей и интерфейс.
Настройки и F3/F4/F11 сохраняются в `%APPDATA%/DoK-port/SourcePort/settings.ini`.
CLI-параметры перекрывают их только на текущий запуск. Рендерер/разрешение
применяются с подтверждением за 15 секунд; без подтверждения происходит откат.
Software: только 320×200, 640×400, 640×480, 800×600, 1024×768; выбранное
разрешение меняет сам кадр и размер окна. Ручное растягивание окна меняет
только масштаб. В borderless вывод использует рабочий стол.
CLI: `--software-mode 800x600`, `--locale ru` или `--locale en`.

Классический пресет клавиатуры: стрелки — движение/поворот, Alt + влево/вправо —
стрейф, Ctrl — огонь, Shift — бег, Space — дверь. Классический геймпад:
крестовина — движение/поворот, L1/R1 — стрейф, A — огонь, B — бег,
X — дверь, Y — следующее оружие, Select — карта (пока недоступна), Start — пауза.
Пресеты устройств независимы; назначения можно менять. При конфликте можно
заменить назначение либо отменить. Esc отменяет захват; без клавиатуры —
удерживать Start и нажать Select. Инерция движения включена по умолчанию,
отключается в «Геймплей»; течение воды действует в обоих режимах.

GL HUD r4: исходные значки и FONT8 в отдельном экранном слое, компактная нижняя
строка без подписей, стопка карточек оружия, ключи под зарядом. Сообщения справа;
здоровье показывает краткую прибавку/потерю. Desktop-профиль, портативная компоновка
для PSP 480×272 и PortMaster отложена. Software сохраняет классическую панель.
Прямой запуск: `dok_port.exe --res OLD_GOLD.RES --level LEVEL4 --skip-intro`.
В Old Gold для выхода нужно собрать все105 рублей; счётчик виден в HUD.

Это контрольная сборка для плейтеста, не готовый релиз. Сохранений и карты
пока нет. Высокие software-режимы рисуют мир в выбранном разрешении;
HUD масштабируется из VGA, попиксельное соответствие DOS VESA не заявляется.
HUD Old Gold адаптирован к общей игровой области320×160, а не воспроизводит
исходную панель попиксельно. Общие анимации декораций ещё не подключены.
Есть известные расхождения геометрии и растеризации с DOS. Звук OG передаёт
байты исходного SB-пути; звучание и громкость ещё не сверены с DOS-записью.
Linux/ARM/PortMaster, GLES, PSP и Switch пока не проверены и не собраны.

Проверено: CTest15/15, семь сочетаний ресурсов, 72 кадра меню двух рендереров
на двух языках, 35 software-сцен, смена рендерера в паузе без сброса мира,
сохранение/перезапуск и откат видео. OG: 105 рублей, обе палочки,
600 кадров с движением/AI/снарядами, условие выхода. Ввод проверен также
виртуальным SDL-геймпадом; физический контроллер требует плейтеста.
Полного прохождения человеком пока не было. Для сообщения об ошибке полезны
набор/уровень, рендерер, шаги воспроизведения и `%APPDATA%/DoK-port/SourcePort/port.log`.
Архивы игры в поставку не входят. SDL2 распространяется с приложенной лицензией.
