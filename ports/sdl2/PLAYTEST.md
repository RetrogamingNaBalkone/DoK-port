# OGDoK — Windows x64, плейтест

Общий SDL2-порт «Старого золота» и русского и английского изданий
«Подземелий Кремля». Доступны программный и OpenGL-рендереры, русские
и английские сюжеты, сообщения и интерфейс.

## Системные требования

Минимальная ОС — **Windows 8 x64**. Windows 7 не поддерживается.
Запуск на Windows 8 пока не проверен; это заявленная нижняя граница совместимости.

## Запуск

Положите свои `OLD_GOLD.RES`, `PKR.RES` и/или `PKE.RES` рядом с `OGDoK.exe`.
Для игры достаточно одного архива. Автопоиск проверяет только файлы `.res`
непосредственно рядом с EXE; папка `data` и вложенные папки не проверяются.
Ресурсы можно также добавить через «Ресурсы игр» в главном меню,
перетащить в окно или указать через `--res ПУТЬ`. Выбор через меню и
перетаскивание запоминаются; аргументы CLI действуют только на текущий запуск.
Игра определяется по содержимому архива, поэтому файлы можно переименовывать.
При разных файлах одного издания источник выбирается явно.
Меню и настройки доступны без ресурсов игры.

Запустите `OGDoK.exe`. Рендерер выбирается в настройках графики;
выбор сохраняется для следующих запусков.
«Начать игру» открывает выбор игры, заставку, предысторию и уровень.
Сначала в списке идёт «Старое золото» / Old Gold. Английское издание Кремля
имеет небольшие отличия в картах и балансе монстров.

Язык всех текстов выбирается в разделе «Графика и интерфейс» независимо от имеющегося RES.
При первом запуске используется язык ОС, затем сохраняется ручной выбор.

## Управление

- WASD — движение и стрейф; Q/E — дополнительные кнопки стрейфа.
- Мышь или стрелки влево/вправо — горизонтальный поворот.
- Ctrl / левая кнопка мыши — огонь; Space / Enter — открыть дверь.
- 1, 2, колесо мыши вверх/вниз и PageUp/PageDown — сменить оружие на другое,
  если оно получено; Shift — бег, Alt — медленное движение.
- Tab — открыть/закрыть карту по отпусканию клавиши; Esc — пауза или выход из карты.
  При открытой карте мир продолжает работать, как в оригиналах.
- Геймпад: левый стик — движение/стрейф, правый — поворот, A — дверь,
  правый триггер — огонь, левый — бег, плечевые кнопки — оружие, Start — пауза.
- Меню: стрелки/крестовина, Enter/A — выбрать, Esc/B — назад; работает мышь.
  Тексты листаются PgUp/PgDown или L1/R1.
- F3 — счётчик FPS; F4 — фильтр текстур GL либо масштабирование software;
  F11 — полноэкранное окно без рамки; F12 — PNG в папке `screenshots`.
- IDKFA во время игры выдаёт ключи и оружие. Сообщение переводится:
  «Ах ты хитрый думер!» / «You sneaky Doomer!». Повтор не пополняет запас.

Клавиатура и геймпад имеют независимые современные и классические пресеты
и переназначение. Классический геймпад работает без правого стика:
крестовина — движение/поворот, L1/R1 — стрейф, A — огонь, B — бег,
X — дверь, Y — следующее оружие, Select — карта, Start — пауза.
Esc отменяет захват нового назначения; с геймпада — удерживать Start и нажать Select.

В разделах устройств можно выключить мышь или геймпад для игры.
Навигация по меню и переназначение кнопок продолжают работать;
выключенная мышь не захватывается игровым окном.

Потеря фокуса ставит игру на паузу. Карта показывает исследованную область;
найденная карта добавляет
предметы и врагов на уже исследованных участках.

## «Старое золото»

Здесь одна карта и две волшебные палочки. Герой начинает без оружия,
с магией **0/0**. Пополнения магии не подбираются до получения первой палочки:
это исходное правило игры. Палочка увеличивает вместимость магии и позволяет
стрелять. Для выхода нужно собрать все **105 рублей**; счётчик виден в HUD.

## Изображение и настройки

Автоматический HUD использует классическую панель при 4:3 и современную
компоновку на широком экране. Оба варианта доступны с обоими рендерерами.
FOV рассчитывается автоматически от исходной DOS-сцены в кадре 4:3.
Широкий кадр добавляет обзор по горизонтали (Hor+); современный HUD в 4:3
освобождает область панели и добавляет обзор по вертикали (Vert+).
Классическая панель резервирует нижнюю полосу; в широком кадре расширяется
горизонтальный обзор. Родная панель остаётся снизу по центру.
Увеличенный обзор не расширяет пробуждение монстров.

В полноэкранном OpenGL выбирается внутреннее разрешение всего кадра.
Оно определяет аспект: кадр вписывается в экран с полями без растяжения.
Размер окна хранится отдельно; справочная строка показывает аспект.

Одна строка фильтрации меняется по выбранному рендереру. Для текстур OpenGL
оставлены два заметно различающихся варианта: Nearest сохраняет резкие пиксели,
Smooth смягчает их и уменьшает рябь вдали. Smooth объединяет линейную
фильтрацию, трилинейные mipmaps и анизотропию 8×; отдельные ступени убраны.
Для масштабирования software-сцены: Nearest, Linear, Sharp Bilinear и
экспериментальный xBR-lv2. xBR сглаживает пиксельные контуры при увеличении;
при выводе без увеличения используется Nearest. Он может менять характер
мелких деталей и стоит дороже. Значения рендереров сохраняются независимо.
xBR по возможности выполняется на GPU; программная отрисовка мира при этом
сохраняется. Если аппаратный проход недоступен, остаётся более медленный CPU-путь.
FXAA сглаживает GL-сцену перед оружием, HUD и текстом. По умолчанию Nearest.
Software поддерживает кадры 320×200, 640×400, 640×480, 800×600 и 1024×768.
Игровой кадр software всегда выводится в 4:3 с полями, включая переход из OpenGL.
Сообщения классической панели сохраняют исходный отступ слева и выравниваются
по центру поля только по вертикали.

В звуке доступны два независимых уровня: эффекты и музыка заставки.
Старые значения пересчитываются с учётом прежней общей громкости.
Видеорежим требует подтверждения за 15 секунд, иначе откатывается.
Инерцию движения можно отключить; течение воды продолжает действовать.
«Геймплей → Сохранения → Выкл.» отключает сохранение и загрузку игры,
включая F5/F9, меню паузы и загрузку после смерти: в оригиналах сохранений
не было. Существующие слоты остаются на диске и доступны после включения.
По умолчанию сохранения включены, в том числе в прежних профилях.
«Геймплей → Покачивание в „Старом Золоте“ → Выкл.» фиксирует высоту камеры
при движении в Old Gold. Настройка не влияет на «Подземелья Кремля» и
сохраняется между запусками. По умолчанию покачивание включено.

## Настройки и портативный режим

Каталог профиля выбирается в следующем порядке:

1. Папка из `--user-dir ПУТЬ`, если параметр указан.
2. Папка самого EXE, если рядом есть файл `portable` или `portable.*`,
   например `portable.txt`. Регистр букв и содержимое файла не имеют значения.
   Папка с таким именем портативный режим не включает.
3. Обычный профиль платформы: в Windows `%APPDATA%/DoK-port/SourcePort/`.

В профиле находятся `settings.ini` и `port.log`. Портативный профиль можно
перенести вместе с папкой игры. Его внутренние пути ресурсов сохраняются
относительно профиля, внешние — абсолютными. Маркер и автоматический поиск
RES привязаны к EXE, а не к рабочей папке ярлыка или командной строки.

Новый профиль начинается с настроек по умолчанию. Автоматического копирования
из AppData нет; для переноса настроек скопируйте `settings.ini` вручную при
закрытой игре. Прежние абсолютные пути поддерживаются, но после перемещения
внешнего файла его потребуется выбрать заново через «Ресурсы игр».
Перед заменой повреждённых настроек исходный файл сохраняется как
`settings.ini.bak` (либо с числовым суффиксом). При отказе записи игра сообщает
об ошибке и не переключается на другой профиль.

### Сохранения

F5 — быстро сохранить, F9 — сразу загрузить быстрое сохранение текущей игры.
Назначения можно изменить в управлении. По одному quicksave и десять именованных
слотов для Old Gold, PKR и PKE; слоты общие для всех уровней выбранной игры.
После выбора игры доступно «Загрузить игру», также загрузка доступна в паузе
и после смерти. В паузе доступны ручное сохранение и обе быстрые операции.

У каждой записи есть превью, уровень, время, здоровье и попытки. Имя можно
ввести по-русски или вставить через Ctrl+V. Перезапись и удаление требуют
подтверждения. Загрузка через меню при текущей игре требует подтверждения;
F9 загружает сразу. Новая игра, смерть и завершение уровня не перезаписывают сейвы.

Папка `saves` находится рядом с `settings.ini` в том же выбранном профиле:
`--user-dir`, portable или стандартная папка пользователя. Внутри независимые
папки `old_gold`, `pkr`, `pke`; для переноса скопируйте весь профиль при закрытой
игре. Файлы `slot01.sav`–`slot10.sav` и `quick.sav` содержат состояние и превью;
`.bak` — предыдущая исправная запись. При повреждении основной записи меню
предлагает загрузить резервную. Незавершённые `.tmp` не загружаются.

Сохранения требуют совместимых игровых данных и версии правил. Язык, видео,
HUD и назначения управления в сейв не входят. Импорт DOS/WASDify не поддерживается.

## Командная строка

Синтаксис: `OGDoK.exe [параметры]`. Каждый параметр со значением принимает
следующий аргумент. Пути с пробелами заключайте в двойные кавычки.
Относительные пути CLI отсчитываются от рабочего каталога запуска.

| Параметр | Назначение |
|---|---|
| `--user-dir ПУТЬ` | Каталог настроек и журнала; имеет приоритет над portable. При повторении используется последний. |
| `--res ПУТЬ` | Подключить RES; допускается от одного до трёх повторений, в любом порядке. |
| `--res-source ПУТЬ` | Выбрать загруженный источник при конфликте архивов одного издания. Можно повторять; для одного издания действует последний выбор. |
| `--renderer gl\|software` | OpenGL или программный рендерер. |
| `--size ШИРИНАxВЫСОТА` | Размер окна и внутреннее разрешение полноэкранного OpenGL, например `1280x720`. Диапазон: 320–7680 × 200–4320. |
| `--software-mode РАЗМЕР` | Программный кадр: `320x200`, `640x400`, `640x480`, `800x600`, `1024x768`. |
| `--locale ru\|en` | Язык интерфейса, сюжетов и сообщений. |
| `--hud auto\|classic\|desktop` | Автоматический, классический или современный игровой интерфейс. |
| `--filter nearest\|smooth` | Фильтр текстур OpenGL. Прежние `linear`, `mipmaps`, `trilinear`, `aniso2`, `aniso4`, `aniso8` принимаются как имена Smooth. |
| `--frame-filter nearest\|linear\|sharp\|xbr` | Масштабирование программной сцены. |
| `--fxaa on\|off` | Сглаживание GL-сцены. |

При наличии хотя бы одного `--res` загружаются только указанные архивы:
автопоиск, сохранённые пути и сохранённый выбор источника отключены.
Без `--res` восстанавливаются сохранённые пути и выполняется автопоиск рядом
с EXE. Одинаковые копии объединяются; разные варианты одного издания требуют
явного выбора. Ошибка одного файла не мешает подключить остальные.
`--res-source` должен указывать пригодный загруженный источник или его копию.

CLI-переопределения сами по себе не записываются в настройки. Явные изменения
через интерфейс сохраняются в выбранном профиле. Добавлять или менять RES
можно из главного меню; во время игры, включая паузу, смена запрещена.

Примеры для Windows:

```bat
OGDoK.exe --res "D:\Games\Old Gold\OLD_GOLD.RES"
OGDoK.exe --res "D:\Games\OLD_GOLD.RES" --res "D:\Games\PKR.RES" --res "D:\Games\PKE.RES"
OGDoK.exe --user-dir "D:\Game profiles\OGDoK" --res "D:\Games\PKR.RES"
OGDoK.exe --renderer software --software-mode 800x600 --locale en
```

### Диагностические параметры

| Параметр | Назначение |
|---|---|
| `--frames N` | Завершить запуск после N отрисованных кадров; 0 — без ограничения. |
| `--screenshot ПУТЬ` | Сохранить кадр при достижении `--frames` или завершении replay. |
| `--level LEVEL1` | Выбрать уровень: `LEVEL1`–`LEVEL3` для PKR/PKE, `LEVEL4` для Old Gold. |
| `--skip-intro` | Вместе с `--level` сразу начать уровень. |
| `--hidden` | Скрытое окно без VSync и захвата мыши для автоматических проверок. |
| `--ui-script ПУТЬ` | Выполнить сценарий интерфейса для воспроизведения проверок. |
| `--input-replay ПУТЬ` | Воспроизвести записанный ввод; требует соответствующих `--level` и `--skip-intro`. |
| `--replay-live-input` | Разрешить живой ввод вместе с `--input-replay`. |

FOV и аспект вычисляются автоматически; `--fov` и `--aspect` не поддерживаются.

## Границы плейтеста

Сохранения SP17 включены; фактические результаты проверки указаны в паспорте SP17.
Это предварительный Windows-пакет. Физический геймпад, GLES,
Linux/ARM/PortMaster, PSP и Switch требуют отдельной проверки.
Цифровой Sound Blaster-путь и реальные DOS-записи сопоставлены;
побитовое равенство аналогового звука и эмуляторного микшера не заявляется.

Для сообщения об ошибке укажите игру, уровень, рендерер и шаги воспроизведения.
Журнал `port.log` находится в выбранном профиле.
Локальный пакет может содержать RES; вариант без ресурсов требует ваших архивов.
Лицензия SDL2 приложена в `LICENSES.txt`.
# Исправления Old Gold, 5 ноября 2026

Исправлены ближнее отсечение стен OpenGL и пересечение спрайтов монстров
со сплошными стенами. Классическая панель возвращает исходные позиции и
пять значков денег; точка героя полноэкранной карты стала контрастной.
Физическое застревание монстра в стене в проверке не воспроизведено.
