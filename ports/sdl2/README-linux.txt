OGDoK — Linux x86_64

Распакуйте архив и запустите ./OGDoK. Добавьте OLD_GOLD.RES, PKR.RES и/или
PKE.RES из своих оригиналов рядом с OGDoK. Ресурсы в пакет не входят.

Требуются glibc 2.35 или новее, libstdc++ с поддержкой GCC 11 и SDL2 2.0.20
или новее. Для Ubuntu 22.04: sudo apt install libsdl2-2.0-0 libstdc++6 libgl1
Для OpenGL нужен драйвер с GL 2.0; доступен программный режим.

Профиль выбирается так: --user-dir → файл portable рядом с программой →
каталог SDL в пользовательском профиле. Настройки, сохранения и снимки
хранятся в выбранном профиле. Для переносного запуска создайте пустой
файл portable рядом с OGDoK в доступном для записи каталоге.
При первом запуске разрешение основного экрана автоматически записывается
как размер окна и fullscreen. Имеющийся settings.ini имеет приоритет;
--size задаёт временный размер без замены сохранённого разрешения.

Примеры:
  ./OGDoK --renderer gl
  ./OGDoK --renderer software
  ./OGDoK --res /path/to/PKR.RES --user-dir /path/to/profile

Управление: WASD, мышь, ЛКМ — огонь, Space — дверь, Esc — меню.
Поддерживается SDL-геймпад; настройки и пресеты доступны в меню.
Полная инструкция по настройкам и управлению — README.txt исходной
Windows-сборки в репозитории ports/sdl2 (игровые настройки общие).

Не заменяйте свои RES и профиль при обновлении. Сохранения можно переносить
между Windows, Linux и PortMaster; пути ресурсов и настройки выбирайте заново.
Это пакет для плейтеста; приёмка полного Linux-прохождения ведётся отдельно.
