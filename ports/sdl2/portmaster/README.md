# OGDoK for PortMaster

Place `ogdok.zip` in your firmware's PortMaster autoinstall folder
(`/roms/ports/autoinstall/` on ROCKNIX) and open PortMaster. The installer
registers the preview in EmulationStation when gamelist updates are enabled.
Add your own `OLD_GOLD.RES`, `PKR.RES` and/or `PKE.RES` beside `ogdok/OGDoK`,
then launch OGDoK from the ports menu.
If OGDoK finds no usable game files, PortMaster displays these filenames and
the destination folder before returning to the ports menu.

Settings, saves, screenshots and logs live in `ogdok/user/`. When updating,
replace the program files and keep that directory and your RES files.
The package never supplies a user profile. Saves can be copied between
Windows, Linux and PortMaster; resource paths and settings are device specific.

On the first run OGDoK uses the device language (Russian for a Russian
locale, English otherwise) and the primary display resolution. Choose a
different language under **Graphics and interface**. The game always runs
fullscreen. The default renderer is GLES2 with Nearest filtering and
FXAA/xBR off.
To select a 480x320 game canvas, use the OpenGL renderer and choose 480x320
under **Graphics and interface → Resolution**, then apply and confirm.
Native SDL gamepad input is used; the PortMaster exit combination is provided
by gptokeyb. No keyboard emulation is installed.

Use the in-game controls menu to select the modern or classic preset and
edit gamepad bindings. Start pauses, D-pad navigates menus, A confirms,
B returns. The pause menu offers ten named slots for saving and loading.
Touch input can operate menus. During play, OGDoK ignores mouse events
generated by the touchscreen, including taps that would otherwise fire.

Menu text scales automatically using the display's reported pixel density,
with a resolution-based fallback.

To enlarge the modern in-game HUD, open **Graphics and interface → HUD scale**
and use D-pad Left or Right to choose 100–200%. If Auto uses the classic panel
on your screen, set the HUD to Modern first. The scale takes effect immediately
and is saved in your profile. The HUD limits enlargement to fit the game frame.
With a mouse, left click cycles the scale up and right click cycles it down.

Hardware acceptance is pending on RG Vita Pro/ROCKNIX. Future RG DS Plus
tests use 1024x768 on one screen and record the state of the second screen.
Neither device establishes performance on RK3326.

Build instructions: `docs/source-port/linux-portmaster.md` in the source repo.
