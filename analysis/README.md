# Что хранится в Git

В этом каталоге два вида JSON:

- **Данные оригиналов:** каталоги ресурсов, форматы, структуры, параметры,
  размещения объектов, различия версий и адресные привязки. Хранятся полностью.
- **Результаты запусков:** подробные замеры, векторы, покадровые выборки,
  вложенные копии проверок и перечни удалённых файлов. Крупные исторические
  отчёты остаются локально по прежним путям и явно исключены из Git.
  Их компактные сводки лежат в `summaries/`.

Классификация конкретных файлов — [report-policy.json](report-policy.json).
Размер использован для поиска кандидатов, но не является правилом удаления:
крупные уникальные таблицы оригиналов сохранены. Небольшие итоговые отчёты
и актуальные результаты UI01 остаются на своих путях в Git.

Каждая сводка содержит путь, размер и SHA-256 полного отчёта, исходные статусы,
ограничения и компактное представление результатов. Большие списки заменены
числом элементов и JSON Pointer к разделу полного отчёта. Сводка описывает
старый запуск и не утверждает, что проверка повторена на текущем коде.

Полные JSON не перемещены и не переписаны: существующие скрипты продолжают
читать и создавать их по прежним путям. При повторном запуске обновите сводки:

```powershell
C:/Source/wasdify/.venv/Scripts/python.exe -B scripts/summarize_reports.py
C:/Source/wasdify/.venv/Scripts/python.exe -B scripts/summarize_reports.py --check
```

После чистого клонирования локальных подробных отчётов нет. Для машинной
проверки нужен новый запуск соответствующего driver; сводка не заменяет его
входы. Часть старых сборочных выходов ранее удалена, см.
[паспорт хранения](../docs/tasks/RESEARCH-STORAGE.md).

Не добавляйте новые покадровые дампы и копии вложенных проверок в Git.
Для нового крупного отчёта сначала проверьте его содержание: уникальные
данные оригиналов оставляйте полностью; подробный прогон добавьте в
`local_reports` политики и исключения `.gitignore`, затем создайте сводку.

Изменения индекса не удаляют старые отчёты из истории Git. Переписывание
истории и коммиты этой задачей не выполняются.
