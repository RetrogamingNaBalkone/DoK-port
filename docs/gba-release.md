# GBA: воспроизводимая сборка и кандидат G21

Состояние на 1 ноября 2026 года: автоматическая регрессия выполнена,
**финальная приёмка G21 открыта**. Это инструкция для приватного кандидата,
не объявление нового публичного релиза. Опубликованная Beta 1 не заменена.

## Состав и запуск

Одна ROM содержит три независимых уровня и русский/английский язык.
Выбор языка не меняет карты и общий профиль баланса. Готовая ROM не требует
отдельных EXE/RES или файлов данных. Игровых сохранений нет.

Кандидат: `artifacts/gba/DoK-port_G21_Candidate.gba`.
Те же байты — в текущей UI01 и `artifacts/gba/DoK-port_G21_BatFix.gba`.
Архив: `artifacts/gba/DoK-port_G21_Candidate.zip` — ROM, README и manifest.
Он не содержит оригинальных EXE/RES, извлечённого пакета ресурсов,
декомпиляций или исследовательских материалов. Публичный релиз не создан.

| Кнопки | Действие |
|---|---|
| Крестовина | Движение и поворот |
| A | Огонь |
| B | Бег |
| L / R | Шаг вбок |
| L + R | Смена оружия |
| Start | Действие / открыть дверь |
| Select | Карта |
| Start + Select | Пауза |

В меню A/Start подтверждают выбор, B возвращает назад. На текстовых экранах
A/Start листают вперёд, B — назад, Select меняет язык.

## Входы и команда сборки

Общие инструменты пользователя: Python 3.14, Zig 0.13.0, Unicorn 2.1.4,
mGBA libretro `0.11-212-7a12d6d` из `LOCALAPPDATA/Programs/mGBA/libretro-20261024/`.
Версия и SHA core, хэши исходников, отчётов и оригиналов входят в отчёт G21.
Linux-бинарники и Thumb-объекты проверяются компиляцией; выполняется
Windows host suite и ARM-код в mGBA.

Нужны предоставленные пользователем `originals/pkr/{RUS,ENG}/PK{R,E}.{EXE,RES}`,
проверенные G02 runtime exports в `research/evidence/runtime/` и Ghidra exports
G07/G10/G13. Это локальные входы исследования, не файлы поставки.
Пакер сверяет EXE/RES с inventory и все шесть runtime JSON с G02 verification;
непроверенный/устаревший JSON отвергается. Генерировать данные из GBA-кода
вместо оригиналов не требуется и не допускается.

Из корня репозитория:

```powershell
py -3.14 -X utf8 ports/gba/scripts/check_g21.py
py -3.14 -X utf8 tools/reports/summarize_reports.py
```

Драйвер собирает свежий пакет в `build/gba/g21-clean-assets/`, выполняет
host/cross/original checks, frontend с полной регрессией и повторную сборку
в отдельном каталоге, дополнительные проверки и исследования BUG01/BUG02.
Пути можно изменить параметрами `--out`, `--repeat`, `--assets`, `--ceiling`.
Вывод `--stage assemble` только сверяет и упаковывает уже записанные результаты;
он не запускает тесты. Для раздельного прогона доступны `--stage build` и
`--stage checks`. Каталоги после исследования сохраняют ELF, map и текущую ROM;
пользовательские файлы берутся из `artifacts/gba/`.
Текущие каталоги по умолчанию — `g21-bat-fixed`, `g21-bat-repeat`,
`g21-bat-ceiling`; исходный контроль `g21-final` не перезаписывается.

## Проверки и ограничения

| Контрольные сценарии | L1 RU | L1 EN | L2 RU | L2 EN | L3 RU | L3 EN |
|---|---|---|---|---|---|---|
| Запуск, intro/ending, штатный FINISH, retry/lives | пройдено | пройдено | пройдено | пройдено | пройдено | пройдено |
| Меню, текст, карта, переключение языка | пройдено | пройдено | пройдено | пройдено | пройдено | пройдено |
| Sprite/оружие, AI/combat, аппаратные переходы | пройдено | пройдено | пройдено | пройдено | пройдено | пройдено |
| Полное навигационное прохождение новой ROM | нет | нет | нет | нет | нет | нет |
| Проверка этой ROM на физической GBA | нет | нет | нет | нет | нет | нет |

FINISH/бой в автоматических сценариях проверяются с контролируемыми позициями
и состояниями. Это не маршрут от входа до выхода через все комнаты.
Пользовательский плейтест завершён ранее; новый общий плейтест не запрашивается.
Аппаратный успех VBlankOnly 30 октября относится к прежнему образцу, не к этой
сборке. Звук автоматически проверен, нового прослушивания пользователем нет;
WAV прежнего подтверждения G16 отсутствует и не объявлен проверенным заново.

Изменения G21 включают воспроизводимость и проверки: передача свежего
пакета через оба этапа сборки, исправление include-путей cross-build после
переноса в `ports/gba/`, устранение зависимости двух oracle от окружения
соседнего проекта, честный учёт отсутствующего старого WAV, новые аудиты.
Кроме того, [исправлен BUG01](gba/g21-bat-hit-fix.md): область попадания игрока
центрирована на акторе;216 воспроизведённых промахов устранены,2880 наведённых
выстрелов прошли.518 geometry cases и32 live midrange cases дополняют общую
регрессию. Урон/скорость/события/AI и вражеские снаряды сохранены.
Средний FPS десяти боевых сцен изменился на−0,15…+3,95%, худшие VBlank/кадр
сохранены либо улучшены; CPU-максимумы не везде уменьшились.
Код отрисовки не менялся,750 контрольных PPU кадров потолка exact.
Предыдущие оптимизации описаны в [отчёте массовых боёв](gba/mass-battle-optimization.md).

Открытые ограничения качества:

- BUG02: найдены исходные поклеточные LIGHT-швы, но соответствие всего
  пользовательского «теневого столба» этой причине не доказано. Баг открыт.
- Частота кадров зависит от сцены; стабильные 30 FPS не являются условием
  выпуска и не заявлены. Общий бюджет G20 открыт.

Подробные доказательства, степень уверенности и следующие действия —
[исследование G21](gba/g21-investigation.md). Полный локальный индекс —
`analysis/gba/g21-regression-20261101.json`, Git-сводка —
`analysis/summaries/g21-regression-20261101.json`.
До разрешения оставшихся вопросов качества G21 не отмечать готовой;
новый публичный релиз требует отдельного решения пользователя.
