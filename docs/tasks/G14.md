# G14: AI: обнаружение и перемещение

## Контекст нового чата

Рабочий корень: `C:\Source\DoK-port`. Сначала прочитать `AGENTS.md`,
`docs/gba-plan.md`, `docs/handoff.md`. Главная цель — GBA; SDL2 не является
зависимостью. Этот паспорт не предполагает доступности предыдущей переписки.

**Зависимости:** G13. Проверить их фактические результаты в плане и файлах.
Выполнять только границы этой задачи; соседние задачи — отдельные чаты.

Вход после G13: [combat.md](../combat.md), `analysis/g13-review.json`, общий
ROM `build/g13/`. `dok_combat_spawn` принимает owner object ID и template glyph;
same-class immunity, flight/damage/impact/cleanup уже реализованы. WAKE сообщает
первый контакт sleeping state 0 без вычитания health; DAMAGE/DEATH/RECLAIM
разделены. G14/G15 должны подключить consumers, а не подменять AI переходы
visual completion. RECLAIM обязан снимать будущие AI owners до повторного
использования glyph slot. Dynamic occupancy хранится отдельно от static MMap
и подключена через borrowed collision overlay для одного активного GBA world.
Перед уничтожением его context нужно вызвать `dok_collision_overlay(0,0,0)`;
при смене уровня production adapter устанавливает context заново. Object 36,
player 60 и ARM runtime 33864 не изменились. EWRAM после G13 — 239416 байт,
свободно 22728; IWRAM 23980, до stack reserve остаётся 596 байт. Новые холодные
функции размещать в ROM. Performance до 30 FPS не доведена; это остаётся G20.

## Реализация

Перенести обнаружение и навигацию монстров в переносимый C и GBA-runtime. Определить источник случайности, состояние RNG и возможность повторить сценарий. Боевые переходы согласовать с интерфейсом будущего G15.

## Критерии готовности

Монстры активируются и меняют курс по проверенным условиям; трасса воспроизводится при том же seed/input. RUS/ENG LEVEL1 сохраняют разные параметры. Проверены заблокированное движение, границы и повторный glyph.

Проверки выбирать по реальным рискам задачи. Сравнение C/Python полезно, но само
по себе не доказывает совпадение с работающей DOS-игрой. Если тест или запуск
не выполнен, указать это явно и не отмечать соответствующий критерий готовым.
