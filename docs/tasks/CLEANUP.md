## Изменения скриптов

- `prototype_gba_bsp.py` и `research_gba_fps.py` удаляют собственные объектные
  выходы через `finally`, в том числе после ошибки компилятора. Учитываются
  только пути `.o`, переданные компилятору в текущем вызове. Базовый каталог
  не может совпадать или пересекаться с выходным каталогом. Для ручной
  перелинковки или использования результата как новой базы есть `--keep-objects`.
- `verify_packing.py` создаёт повреждённые и повторные пакеты в уникальных
  временных каталогах и удаляет их при успехе и исключении. Итоговый JSON
  сохраняет команды, размеры и хеши; пути временных пакетов после проверки
  больше не существуют.
- Общий код — `scripts/experiment_cleanup.py`. Каталоги наследуют права
  родителя: стандартный `TemporaryDirectory` Python 3.14 с режимом `0700`
  оказался недоступен в текущей Windows sandbox. Это проверенное ограничение
  данной среды, не утверждение обо всех установках Python.
- `scripts/clean-experiments.ps1` повторяет описанную ограниченную очистку.
  Без аргументов выводит оценку, с `-Apply` удаляет файлы и пишет новый
  датированный отчёт. Проверяет абсолютные пути и запрещает reparse points.
  Запускать после завершения сборок, которые используют кэш и объекты.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/clean-experiments.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/clean-experiments.ps1 -Apply
```
