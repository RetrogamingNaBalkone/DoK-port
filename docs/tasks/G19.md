# G19: Сохранения GBA

## Контекст нового чата

Рабочий корень: `C:\Source\DoK-port`. Сначала прочитать `AGENTS.md`,
`docs/gba-plan.md`, `docs/handoff.md`. Главная цель — GBA; SDL2 не является
зависимостью. Этот паспорт не предполагает доступности предыдущей переписки.

**Зависимости:** G02, G13, G15, G18. Проверить их фактические результаты в плане и файлах.
Выполнять только границы этой задачи; соседние задачи — отдельные чаты.

## Анализ

Определить полный набор изменяемого состояния: карты, actor states, инвентарь, события/относительное время, RNG и прогресс. Выбрать тип хранения и ограничения платформы после проверки инструментов. Совместимость с DOS-save не считать требованием без отдельного решения.

## Реализация

Сделать версионированный формат без host/native-указателей, с контролем целостности и проверкой диапазонов. Реализовать GBA backend и интеграцию меню. Предусмотреть пустую/повреждённую память и восстановление после оборванной записи выбранным способом.

## Критерии готовности

Сохранение в бою и загрузка после перезапуска ROM воспроизводят состояние и продолжающиеся события. Проверены обе локализации, версия формата, повреждение и отсутствие сохранения. Backend проверен в эмуляторе; доступная проверка носителя/железа отражена отдельно.

Проверки выбирать по реальным рискам задачи. Сравнение C/Python полезно, но само
по себе не доказывает совпадение с работающей DOS-игрой. Если тест или запуск
не выполнен, указать это явно и не отмечать соответствующий критерий готовым.

## Ожидаемые артефакты

Это планируемые пути, не утверждение об их существовании. Имена можно уточнить
при реализации с обновлением паспорта и передачи контекста.
