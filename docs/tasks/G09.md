## Критерии готовности

Закрытая дверь блокирует, открытая пропускает, нужный ключ проверяется по правилам оригинала. Повторная активация и связанные glyph не ломают состояние. Подтверждены используемые триггеры всех трёх уровней; неизвестные ветви перечислены.

Проверки выбирать по реальным рискам задачи. Сравнение C/Python полезно, но само
по себе не доказывает совпадение с работающей DOS-игрой. Если тест или запуск
не выполнен, указать это явно и не отмечать соответствующий критерий готовым.
