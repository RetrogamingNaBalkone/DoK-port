## Анализ

Восстановить подготовку/серии атак, cooldown, выбор снаряда, реакцию на урон, смерть, финальные кадры и уведомления. Проверить все группы врагов и варианты параметров из сводных таблиц, а не только одного боярина.

## Реализация

Соединить AI с боем и анимацией, реализовать все используемые состояния врагов. Разобрать освобождение ресурсов/слотов и уведомления при смерти. Добавить стабильные сценарии для каждой группы и критических ветвей.

## Критерии готовности

Все используемые виды врагов могут обнаружить, атаковать, получить урон и умереть без зависших событий. Порог здоровья и burst/cooldown проверены по источнику. Пройдены варианты ru/en; неперенесённые native-ветви явно перечислены.

Проверки выбирать по реальным рискам задачи. Сравнение C/Python полезно, но само
по себе не доказывает совпадение с работающей DOS-игрой. Если тест или запуск
не выполнен, указать это явно и не отмечать соответствующий критерий готовым.

## Результат

**Завершено 26 октября 2026 года.** `analysis/g15-review.json` связывает
исходные доказательства, host/ARM проверки, source hashes и итоговый ROM.

- Portable/GBA: полная используемая state machine class9, attack cycle/melee5,
  strict timer/burst/reset, glyph3/4 projectiles, hurt и death frames.
- Native corpse: +19=0, обе ветви MMap/TMap, flags|0x10 без0x400, сохранение
  последнего кадра и занятого glyph slot, снятие owner, DEAD notification.
- EXE SHA до/после Ghidra совпали. Адреса/ABI/границы — `docs/ai-combat.md`.
- Native x86 на язык:648 burst,6 melee/hurt,12 player damage,4 corpse cases.
  Внешние boundaries указаны в `analysis/g15-original-verification.json`.
- Windows host:14 групп×RU/EN, каждый death frame/cleanup, both corpse planes,
  zero/nonzero burst, strict threshold, full series/reset/LOS, projectile
  selection/deadline, moving/contact hurt, actual dynamic front-class8 и clamp. Linux static/Thumb скомпилированы.
- ROM/ELF/map в `build/g15/`; ROM32864108 байт, SHA-256
  `a7d0dc7d938a4e076ba8f2be0d863bdd56c1600e0e2dd712828cf7d5e3e2fa3f`.
  EWRAM247872/free14272, IWRAM23980, до8KiB stack reserve596 байт.
- Renderer RU/EN/reset/guards и interactions/time ARM-регрессии прошли на
  этом ROM; static renderer4668642…4690694 cycles.30FPS остаются G20.

Повтор: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-gba-ai-combat.ps1 -CrossChecks -OriginalEvidence`.
Основные пути: `src/ai.c`, `include/dok/ai.h`, `include/dok/runtime.h`,
`src/runtime.c`, `src/renderer_sprites.inc`, `gba/ai_probe.c`,
`tests/test_ai_combat.c`, `scripts/verify_ai_combat_{host,original,gba}.py`,
`docs/ai-combat.md`; итоговый aggregate — `scripts/report_ai_combat.py`.
Полный DOS/физическая GBA не проверены. Sound/UI consumers — G16/G17;
игровые transitions/cleanup от них не зависят. ARM:28 вариантовE01–E14×RU/EN прошли; stack high-water2360/margin5576. Следующий ID — G16.

Ограничение диагностики: scalar +B0/+B6 — старые G02 startup constants,
не storage активного DOS clock. Engine их не читает; compact timer проверен.
