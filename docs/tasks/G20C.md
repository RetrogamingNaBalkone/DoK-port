# G20C: Проверка отрисовки непрозрачных участков колонок

## Контекст и статус

Добавлено 27 октября 2026 года по запросу пользователя: выполнить до UI G20B.
**Статус: готова к началу.** Это отдельный ограниченный опыт после G20A,
а не возобновление завершённого архитектурного исследования.

Сначала читать `AGENTS.md`, `docs/gba-plan.md`, `docs/handoff.md`,
[итог оптимизации](../gba-optimization-handoff.md),
`analysis/g20a-final-handoff.json` и `analysis/g20a-final-costs.json`.
Контроль — ROM2775, CPU-слой120×128. Offline sparse-post audit подтвердил
точное восстановление колонок и оценил метаданные; native ускорение неизвестно.

## Задача

Реализовать и измерить отрисовку маскированных текстур по непрозрачным
участкам колонок (sparse runs/posts), пропуская прозрачные интервалы.
Не менять разрешение, геометрию, LIGHT16, AI, игровые правила и дальность.
Ноль непрозрачной текстуры остаётся чёрным пикселем; пропуск допустим только
для маскированного материала. Сохранить clipping, coverage и перекрытия.

Ограничиться этим опытом: не перебирать заново проигравшие архитектуры и
не начинать Performance. При отсутствии существенного общего выигрыша
зафиксировать отрицательный результат и перейти к G20B.

## Проверки и критерии готовности

- Парные native-clock mGBA замеры против2775 со звуком: пять тяжёлых видов,
  spatial440 и живые маршруты120 кадров на трёх уровнях, обе локализации.
- Проверить итоговую PPU-картинку, маски, масштабирование и перекрытия,
  включая динамику; указать фактический охват проверок.
- Измерить полное CPU-время, FPS предъявления, ROM/RAM/стек; не выдавать
  экономию одной стадии или долю прозрачных texels за выигрыш всего кадра.
- Сохранить контрольный ROM, воспроизводимые команды, ROM/ELF/map и отчёты.
  Принимать новый путь только по парным данным без регрессий картинки и игры.
- Документировать решение принять/отклонить и ограничения. Отрицательный
  результат закрывает опыт; достижение30FPS не является условием G20C.
- Обновить этот паспорт, план и handoff. G20 budget закрывать только по
  фактическим критериям; следующим этапом остаётся UI G20B.
