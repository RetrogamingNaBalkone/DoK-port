# G08: Коллизии и первая прогулка по уровню

## Контекст нового чата

Рабочий корень: `C:\Source\DoK-port`. Сначала прочитать `AGENTS.md`,
`docs/gba-plan.md`, `docs/handoff.md`. Главная цель — GBA; SDL2 не является
зависимостью. Этот паспорт не предполагает доступности предыдущей переписки.

**Зависимости:** G07. Проверить их фактические результаты в плане и файлах.
Выполнять только границы этой задачи; соседние задачи — отдельные чаты.

## Анализ

Восстановить проверки занятых клеток и flags, радиус/габариты, границы мира, скольжение, ограничения высоты, использование MMap/TMap/FCMap. Выяснить порядок движения и проверки, не заменять его типичным движком по умолчанию.

## Реализация

Перенести столкновения и соединить с GBA-прототипом. Дать ходить и поворачиваться в настоящем уровне; обеспечить безопасный режим при неперенесённых типах преград. Добавить диагностический вид карты/координат при необходимости.

## Критерии готовности

Прогулка по LEVEL1 работает в GBA-ROM. Герой не проходит обычные стены и границы; углы и узкие места проверены повторяемым вводом. В целевом ROM RU/EN проходят один сценарий на общей карте G03 без изменения мира при смене языка. Исходные карты RUS/ENG используются отдельно для DOS-сверки. Известные расхождения описаны.

Проверки выбирать по реальным рискам задачи. Сравнение C/Python полезно, но само
по себе не доказывает совпадение с работающей DOS-игрой. Если тест или запуск
не выполнен, указать это явно и не отмечать соответствующий критерий готовым.

## Результат

**Готово, 25 октября 2026 года.** Модуль `include/dok/collision.h`,
`src/collision.c` подключён к общей GBA-сцене LEVEL1; управление G07 без
поступательной инерции сохранено. Восстановлены квадратный footprint Min Dis,
flags, MMap/TMap, порядок скольжения, три подшага, occupancy и door counters.
FCMap/высота в этом native-пути не участвуют. Отличия безопасного адаптера,
ABI, адреса и доказательства: [collision.md](../collision.md).

Ghidra обоих EXE и SHA до/после; 55 152 x86-вектора плюс1200 исходных обёрток
с картами/счётчиками. 12 Windows-наборов прошли; Linux static и Thumb compile
прошли. Общий collision suite исполнен на ARM. mGBA:972 шага на язык по общей
G03-карте, одинаковые позы/карты RU/EN, сохранение мира при смене языка,
реальные кнопки и удержание у стен, отсутствие дрейфа, guards/poisoned reset.
Углы, узкие проходы, границы и неперенесённые препятствия проверены suite.
1455 камер LEVEL1–3, HUD/палитра,443 520 strips, linked payloads и время прошли.

ROM/ELF/map/PNG: `build/g08/`; ROM32 833 692 байта, SHA
`7e643146b765003bc90778f00fe78b7a1cf88ee5972075462f7a997cd1a64a64`.
EWRAM129 228, main stack2352/запас5584; startup443 062,

Полный новый DOS-session, физическая GBA/оригинальный BIOS, Linux execution,
