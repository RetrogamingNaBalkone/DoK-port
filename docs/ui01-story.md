# UI01: предыстория из главного меню

27 октября 2026 года, дополнение G20B по плейтесту G21.

Главное меню: «Начать игру», «Язык», «Управление», «Предыстория», «Выход».
Пауза сохраняет четыре прежних пункта. «Предыстория» / Story открывает
исходный ресурс README выбранного языка, независимо от LEVEL1–3.
A/Start перелистывают две страницы и затем возвращают к тому же пункту
меню. B листает назад, с первой страницы возвращает в меню. Select меняет
язык. Музыка меню продолжается; мир не создаётся и не изменяется.

## Источник и границы восстановления

Проверенный источник — запись 0 в RES, файловое смещение 4382 (0x111e),
а не адрес EXE/Ghidra или runtime-селектор:

- PKR.RES: 404 байта, SHA-256 ресурса
  `6b7253f6ca66ce8dfb042c1eeae354e3bebc8b5416167c3197490945b44f2572`.
- PKE.RES: 426 байт, SHA-256 ресурса
  `64eabbb994ccb107d681de4cb75af778f15366fbcb3e071171cc8e8627f7c7d6`.

Каталоги — `analysis/resources-ru.json` и `analysis/resources-en.json`.
Распаковки — `research/evidence/resources/{ru,en}/0000.bin` и `0000.txt`.
Текст описывает раскопки, пробуждение нечисти и задание диггеру. Байты,
исходные переносы и CP866 сохранены; используется существующий ROM view,
без новой копии ресурса в RAM. Оригиналы не изменялись; анализ EXE для этой
адаптации не выполнялся. Отдельный пункт меню — согласованная GBA-адаптация,
а не утверждение о наличии такого пункта в DOS.

## Реализация и проверка

В flow добавлено состояние STORY=7; прежние значения сохранены.
Экран использует палитру меню и существующие FONT8/FONT16, рамку и пагинацию.
Кеш статического меню исключает flow-экраны, чтобы не подавлять перелистывание.
Пять строк главного меню размещены с шагом 14 px; пауза сохраняет шаг 17 px.

Сборка: `scripts/build_gba_frontend.py --out build/ui01-story`.
Проверка: `scripts/verify_story_gba.py --build-dir
build/ui01-story/hardware/hw_v128_entity_rect --report build/ui01-story/story.json`.
В mGBA проверены обе страницы обоих языков по пикселям исходного FONT8,
надпись пункта меню, B/Start/A/Select, возврат фокуса, неизменность мира,
отсутствие reset и непрерывность музыки. PNG просмотрены.
Windows host UI прошёл; Linux и Thumb скомпилированы.
Flow всех шести миров, UI и 16 фазовых проверок коротких нажатий прошли;
boot 10 VBlank, максимальная задержка UI 5 кадров.

Текущая ROM: `artifacts/gba/DoK-port_UI01.gba`, 16015068 байт, SHA-256
`f16dfa824a5761796554aa3d205d35f6ad2123ba70dfb15354b1b1e605714f21`.
ELF/map/PNG и полные отчёты — `build/ui01-story/`.
Физическая GBA, чистый repeat и новый полный audio/performance прогон
не проверены. G20B готово, G21 продолжается, бюджет G20 открыт; SDL2 не затронут.
