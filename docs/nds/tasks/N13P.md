## Цель и работа

Первый обязательный совместный контроль основных рисков 3D-архитектуры:
актёры, двери, LIGHT, палитры, вода и отражения работают одновременно.

1. Повторить накопленный набор N07P/N12 и добавить переходы освещённости/дистанции, animated water,
   отражения с объектами и дверями, повороты у воды, светлые/тёмные crowded scenes.
   Не проверять новую подсистему только на пустой сцене.
2. Измерить комбинации кадр актёра × LIGHT-вариант × локализация, рабочий набор
   палитр/текстур, промахи/вытеснения, загрузки, подготовку отражённых проходов,
   CPU/GE/line нагрузку и остатки RAM/VRAM. Проверить установившийся и холодный кэш.
3. Уточнение пользователя 29 октября: сначала оценить архитектуру с освещением,
   разрешено отступить от точного LIGHT ради быстрого GPU-затемнения. Критерий —
   художественный замысел: дальние объекты скрываются во тьме, создавая пугающую
   неизвестность. Проверить чёрный аппаратный fog по глубине прежде дальнейших
   точечных оптимизаций. N13 остаётся точным эталоном; приближение явно отделять
   от восстановления. Source timing, вода, объекты и исходные ресурсы сохраняются.
4. Вынести решение: совместный renderer жизнеспособен либо требуется переработка
   cache/палитр/проходов. При нехватке бюджета устранить её до N14.

## Приёмка

- [x] Полный накопленный совместный набор и парные показатели общего протокола.
- [x] ≥99% штатных интервалов ≤2 VBlank; окно 1 с не ниже половины развёртки;
  60-цель и холодные загрузки отражены отдельно.
- [x] Нет потери выбранного художественного затемнения/воды/mirror UV/объектов,
  неверных палитр, overflow и изменений мира; отличие от точного LIGHT описано;
  reserve и рабочие наборы соблюдены.
- [x] Решение об архитектуре, доказательства и остающийся бюджет для живого боя записаны.

Программная приёмка не доказывает физический FPS: DS/DS Lite остаётся N24.
Игровых сохранений нет; только settings writes. GBA/SDL2 не менять.

## Артефакты, handoff и результат

Результаты — `build/nds/n13p/`, постоянные доказательства/точные ROM/ELF/manifests —
`research/evidence/nds/n13p/final/`, [compact](../../../analysis/nds-n13p-performance.json),
[решение и воспроизведение](../spec/N13P-architecture.md).

- Baseline RU/EN:41 cases/2740 presentations,2,57/2,56 virtual FPS,p99 47 VB.
  Точный кэш:4,15/4,11 FPS,170640 B RAM;41 контрольный кадр на язык идентичен.
- Выбран GPU black fog: RU/EN около40 FPS; все1849 штатных интервалов на вариант
  ≤2 VB, minimum cadence29,913049. Цель60 не принята. Audit около15,8 FPS отдельно.
- Полный41/2740 набор пройден обычными RU/EN и audit. Все462 source-frame hashes,
  source callback traces и число объектов совпали с baseline. Три fade целиком
  чернят верхний экран; FAT неизменён, игровых сохранений нет.
- Контрольный GPU depth ramp: ближний белый255, на2400 —186, на3000 —105,
  на3600 —16, на4000/4800 —0. Просмотрены парные игровые кадры трёх уровней.
- Source index0 alpha сохранён; nonzero→0 LIGHT holes заменены RGB-затемнением.
  Новая геометрия не разрезается, CPU effect pool128 КиБ вместо384; raw cache
  использует освободившуюся RAM. Начальные кадры действующих анимаций загружаются
  вместе со всем их рабочим набором до маршрута. Reserve655360 B не тронут.
- 36 effect checks,10516 runtime checks/1500 sweeps,12 pinned replacement checks,
  7040 exact-cache checks/56 packets;150 native synthetic crops на язык и540
  actual phase pairs повторены после изменения crop. Cadence/strip tests12 PASS.

Решение — **продолжать с аппаратным3D, переработав путь освещения на GPU fog**.
Точный LIGHT остаётся эталоном N13, а кэш разрезанной геометрии не выбран.
Бюджет будущих AI/боя, touch-карты и звука ещё не доказан — N17P/N21P остаются.
NDS-план/handoff обновлены; GBA/SDL2 не изменялись. Следующий ID — **N14**;
автоматического продолжения нет. Начинать с выбранной fog-ROM и spec N13P,
не возвращать reference default точного N13 по ошибке.
