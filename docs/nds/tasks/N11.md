N12 не начиналась.

Программная приёмка завершена: host/native/ARM9 gate, новый runtime с исходным
x86 oracle и просмотр кадров прошли. После обнаруженного допустимого source
crop при phase>=extent renderer исправлен; итоговые gate и runtime выполнены
уже с исправлением. Все три критерия выполнены на эмуляторе. Физическое железо
остаётся N24, а работа после N11 останавливается по просьбе пользователя.

### Принятые решения и реализованное поведение

Общая модель принята до деталей. N05 владеет единственными mutable картами,
N10 — flags/door counters, N11 — phase/extent/state/ready/marker и previous-FC ref.
Все class7 owners заранее регистрируются в N08 с native capacity4/тремя slots;
ранние Use-дубликаты сохраняют исходный отказ заполненной очереди без rollback.
Keys/score заимствуются из fixtures до N14; ключи не расходуются. Требуется
любой общий бит key mask, source-сенсор обходит замок. Class6 — проверенный
исходный no-op, а не выдуманный toggle. Пустое hero Use не меняет мир.

OPEN/CLOSE/AUTO сохраняют исходные signed WORD поля, порог проходимости,
occupancy, обе задержки AUTO, marker и завершение callback. Повторные клетки
одного door/sensor glyph разделяют объект. Floor class12 ставит slow и
выполняет conveyor; class13 срабатывает при смене объекта, не номера клетки.
Category1000 сравнивает score с world total и выдаёт FINISH без перехода уровня.
Прочие stat categories передаются будущему потребителю, без новой системы stats.

Для source direct wrapper добавлен публичный `dok_collision_displace`:
один resolver и одна occupancy-транзакция, без N09 quarter-step guard.
Штатный C2=4 даёт conveyor350; разбиение на короткие шаги не применяется.
Прежние тела функций N10 сохранены байтами, старые ROM/reports не переписаны.
Архив двух прежних исходников и причина расширения —
`research/evidence/nds/n11/prior-source/` и `source-supersession.json`.

Исходная C2 arithmetic сохранена: unsigned DIV, ADD modulo2³², SHR1, signed
минимум4; door использует signed LOWWORD/min8, floor — signed DWORD.
Явная адаптация NDS: C2 измеряет фактический service sweep, независимо от
запроса нового кадра. Fixed30, GBA cadence/grid и catch-up не вводились.
Два controls latch разделяют частое main Use и редкие hero motion callbacks,
сохраняя несколько коротких pulses. Use X/B остаётся release-only; один общий
release даёт одно действие, раздельные samples — отдельные действия. Pause
очищает input и оба latch, held подавляются до отпускания.

Door renderer читает snapshot одной фазы, не двигает симуляцию и сохраняет
исходные crop/mirror по клетке. Полностью открытая панель скрывается без
остаточной полосы — явная NDS-коррекция, требуемая паспортом. Невидимость
панели не используется как доказательство свободного collision footprint.
LEGAL phase>=extent обрабатывается исходным resample, не отвергается как
повреждённая фаза. Переход OPEN30→phase29, повторный Use с C2=8→phase29/extent8,
CLOSE28 и CLOSE6 проверен отдельно: первые две фазы скрыты принятой коррекцией,
последняя обрезается корректно. Все переходы сохраняют source state machine.

Нижний экран остаётся диагностическим до N20/N21. Billboard actors относятся
к N12, LIGHT/палитры/вода/отражения — N13, pickups/inventory — N14, weapon effects —

естественное прохождение и не кампания. Игровых сохранений и microSD gameplay
writes нет. Физическая DS/DS Lite, flashcart/loader, реальные FPS/latency/IRQ/
