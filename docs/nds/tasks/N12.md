# N12: Объекты, анимации и перекрытия

Статус: **готово (эмулятор)**. Принята 29 октября 2026 года.

## Контекст нового чата

Рабочий корень: `C:\Source\DoK-port`. Предыдущая переписка недоступна.
Обязательно прочитать [AGENTS.md](../../../AGENTS.md), [NDS-план](../plan.md)
и [NDS-handoff](../handoff.md), затем этот паспорт.
Направление NDS независимо от GBA и SDL2; их завершение не требуется.
Основа — декомпиляции PKR/PKE, ASM и проверки оригиналов. GBA-код не копировать;
исследования использовать как указатели на доказательства. Исключение — явно
принятые данные баланса из NDS-плана.

**Зависимости:** [N07](N07.md), [N11](N11.md), [N07P](N07P.md). Проверить фактические результаты и handoff зависимостей.
Планируемые результаты ещё не существуют только потому, что описаны в паспорте.

## Цель

Добавить полное представление статических и анимированных объектов в 3D-сцене.

## Актуальный порядок проверки

По уточнению пользователя от 28 октября 2026 года эту задачу пока проверять
на host/эмуляторе; реальное оборудование проверить на итоговой сборке.
[Политика проверки](../spec/validation-policy.md) имеет приоритет над
исходными промежуточными аппаратными пунктами ниже. После программной
приёмки допустим статус «готово (эмулятор)» и переход к зависимой задаче.
Аппаратные пункты явно отложены до N24, не считаются выполненными.
Реальные DS FPS и аппаратную совместимость по эмулятору не заявлять.

## Работа

1. Восстановить выбор кадров/направлений, crop, pivot, масштаб и привязку к поверхности из оригинальных ресурсов.
2. Реализовать billboard и прозрачный индекс, корректное перекрытие стенами, дверями и другими объектами. Число кадров анимации не связывать с FPS рендера.
3. Проверить crowded scenes и пределы аппаратных списков; данные не должны молча отбрасываться. Согласовать состояние анимации со SceneSnapshot.

## Границы

Подбор/бой ещё не требуются: состояния объектов можно задавать fixtures; время анимации использует принятый N08-контракт.

Общие требования NDS: DS/DS Lite, верхний кадр 256×192 с коррекцией DOS 4:3
(сцена 154 строки, HUD 38), нижний экран — карта во время игры; мир RU и общий
профиль монстров, RU/EN. Игровых сохранений, autosave и импорта saves нет.
Записываются только настройки. Не менять статусы и handoff GBA/SDL2.

## Критерии готовности и проверки

- [x] Кадры, направления и масштабы соответствуют исходным данным, нет цветных рамок прозрачности.
- [x] Объекты около стен, дверей и камеры не просвечивают и не исчезают при повороте.
- [x] Полные наборы LEVEL1–3 проходят прогон, нет переполнения списков и непреднамеренного мерцания.

Проверки выбираются по рискам задачи: оригинальные данные/исполнение отдельно
от новых host/ARM9 реализаций, эмулятор отдельно от физической DS/DS Lite.
Совпадение двух новых реализаций не доказывает эквивалентность DOS.
Если проверка не выполнена, назвать причину и оставить критерий открытым.
«Готово» допустимо только после выполнения критериев и передачи результата.

## Обязательный handoff

После работы, в том числе частичной:

1. Обновить раздел «Результат» этого паспорта: состояние критериев, изменения,
   факты/гипотезы, отличия от DOS и пути доказательств с образцом/адресацией.
2. Записать точные команды и версии инструментов, хеши контрольных артефактов,
   результаты проверок и явно невыполненные проверки. Для аппарата — модель DS,
   картридж/loader, условия и измерения; для эмулятора — версию и настройки.
3. Обновить строку N12 в [реестре](../plan.md) и [NDS-handoff](../handoff.md).
   Передать ограничения, следующий ID, готовность его входов и конкретный первый шаг.
4. Плановый следующий шаг: **N13**. Если N12 не принята, следующий чат
   продолжает N12; следующую задачу автоматически не начинать.

## Результат

**Готово (эмулятор), 29 октября 2026 года.** Критерии выполнены; физическая
DS/DS Lite остаётся N24. Следующий ID — **N13**, разрешён текущим поручением
вместе с N13P. После N13P требуется решение об архитектуре; N14 не запускать.

Модули, правила, адреса, команды и ограничения — [N12-sprites](../spec/N12-sprites.md);
окончательные hashes и archive manifest —
[nds-n12-sprites.json](../../../analysis/nds-n12-sprites.json).
Добавлены независимые `sprites`, `sprite_assets`, bounded RAM/GPU cache и
отдельная ROM. Старый backend — неизменённый префикс C-файла, новый API добавлен
после него; точные прежние bytes сохранены в `research/evidence/nds/n12/baseline/`.
95 действующих pins N07P и 439 исторических входов проверены с точными архивами
семи заменённых источников. GBA/SDL2 этой задачей не менялись.

- Native Ghidra/Unicorn: **1240** billboard vectors, **12** constructor cases,
  24 анимации/154 кадра каждой версии, signed −31072. Builder исполнен для всех
  клеток: **1494** placements сверены на **4144** позах. Сохранены initial frame0
  монстра, SAR16 и подавление MMap сплошной стеной TMap. Образцы/адресная система
  и far calling convention приведены в spec; SHA EXE/RES до/после совпали.
- Host: **24 451** scheduler/player checks; 81 одинаковый callback при 72/37
  чтениях изображения. Метаданные C сверены с RES; pinned capacity, eviction,
  отказ без вытеснения текущего кадра и bytes каждого payload проверены отдельно.
  Полный scan: **65 192** позы / **586 728** checks; max sprites39/28/82,
  max quad288/290/263 в LEVEL1/2/3. Данные ради лимита не отбрасываются.
- ARM9 RU/EN/audit: **26 cases / 1790 новых frames** каждый. Включены прежние
  936 N07 frames, crowded turns, все исходные кадры и controlled masked depth.
  По **462 ARM9 SHA-трассы** на вариант подтверждают actual texture bytes всех
  кадров трёх уровней, включая EN POPAL. N04 payload при READY независимо
  совпал с RAM; FAT не изменился. Flat coverage и **21 738** устойчивых textured
  pixels подтвердили прозрачные дырки и перекрытия стеной/двумя объектами.
  Контрольные PNG просмотрены.
- Штатный набор1296 presentations: RU/EN **43,61/43,56** virtual FPS,
  p99/max **2/2 VBlank**, все активные интервалы ≤2. Минимальная оконная cadence
  **29,913049**; цель60 не достигнута. 11 первых presentations отнесены к loading.
  Integer count1s может равняться29 при идеальных двух VBlank: частота считается
  по реальному времени охватывающих окно новых интервалов; оба числа сохранены.
  Тест границы/stall — `test_render_metrics.py`, 8 checks.
- Audit: **16,41 FPS**, p99/max4/4, guards прошли; это отдельный overhead.
  Массовый walk кадров — artificial state stress, не native animation cadence.
  Начальные sprite bindings проверяются при загрузке уровня, остальные кадры
  demand-loaded. GPU max260096 B, palette512 B. Static/startup221184 +
  managed2293760 + SDK499712 + reserve655360 =3670016 B.

RU ROM — `build/nds/n12/ru/dok_nds_sprites.nds`, 198656 B, SHA-256
`bc035a51c906857ecb600bce70c4cee830faefb48a02d48d895b13e2b9827c53`.
Остальные ROM/ELF/map hashes — в compact. Полные reports/ASM/controls —
`research/evidence/nds/n12/`, текущие сборки — `build/nds/n12/{ru,en,audit}/`.
Tools: Python3.14.6, Zig0.13.0, Unicorn2.1.4, общий BlocksDS1.24.0-1/GCC16.2.0
(20 locked packages), melonDS DS libretro1.4.0: DS mode, builtin BIOS, direct boot,
software renderer, JIT/threaded renderer off, readonly FAT, sync off.

Ограничения: объектные состояния fixtures, живые AI/бой позднее; LIGHT identity
пока только граница N12, эффекты/вода — N13. Signed callbacks проверены отдельно
от смены изображений fixtures. Полный hardware stack profile, физическая DS,
Linux execution и DOS-попиксельная эквивалентность не заявляются.
Первая операция N13: сверить compact/manifests, восстановить LIGHT/after-LIGHT
mask и реестр воды/отражений/палитровых переходов. Совместный бюджет — N13P.
