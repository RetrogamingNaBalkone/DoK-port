# N02: Диагностическая NDS-сборка и общий SDK

Статус: **готово (эмулятор)**. Выполнена 29 октября 2026 года; аппаратная проверка отложена до N24.

## Контекст нового чата

Рабочий корень: `C:\Source\DoK-port`. Предыдущая переписка недоступна.
Обязательно прочитать [AGENTS.md](../../../AGENTS.md), [NDS-план](../plan.md)
и [NDS-handoff](../handoff.md), затем этот паспорт.
Направление NDS независимо от GBA и SDL2; их завершение не требуется.
Основа — декомпиляции PKR/PKE, ASM и проверки оригиналов. GBA-код не копировать;
исследования использовать как указатели на доказательства. Исключение — явно
принятые данные баланса из NDS-плана.

**Зависимости:** нет. Проверить фактические результаты и handoff зависимостей.
Планируемые результаты ещё не существуют только потому, что описаны в паспорте.

## Цель

Получить независимую воспроизводимую диагностическую .nds для DS/DS Lite и подтвердить платформенные сервисы.

## Конкретные входы

- [docs/building.md](../../building.md)
- [docs/nds/feasibility.md](../feasibility.md)
- [docs/nds/plan.md](../plan.md)

Перечисленные файлы существуют при фиксации паспорта. Упомянутые внутри них
локальные экспорты, ROM и старые build-отчёты могут быть удалены или недоступны:
сначала проверить наличие. Не загружать целиком многомегабайтный decompiled-экспорт;
по индексам выбирать конкретные функции и соответствующий ASM.
Для нового анализа EXE использовать сохранённые Ghidra-проекты, проверить SHA-256
образца до/после; адресацию и доказательства записывать явно.

## Актуальный порядок проверки

По уточнению пользователя от 28 октября 2026 года эту задачу пока проверять
на host/эмуляторе; реальное оборудование проверить на итоговой сборке.
[Политика проверки](../spec/validation-policy.md) имеет приоритет над
исходными промежуточными аппаратными пунктами ниже. После программной
приёмки допустим статус «готово (эмулятор)» и переход к зависимой задаче.
Аппаратные пункты явно отложены до N24, не считаются выполненными.
Реальные DS FPS и аппаратную совместимость по эмулятору не заявлять.

## Работа

1. Проверить общие установки инструментов, затем установить недостающий BlocksDS/libnds в общий каталог пользователя, не в репозиторий. Зафиксировать версии, переменные окружения и воспроизводимую команду Windows.
2. Создать минимальную независимую NDS-цель: два экрана, счётчик VBlank/времени, scan кнопок и touch с видимыми координатами, диагностический звук и чтение файла с microSD через DLDI. Отсутствие файла/носителя обрабатывать понятной ошибкой.
3. Ввести измерение CPU/frame intervals и диагностический вывод вне release-экрана. Проверить загрузку на эмуляторе и физической DS/DS Lite; записать модель флеш-картриджа, loader и условия запуска.

## Границы

Не переносить игровой цикл, геометрию и GBA startup. Диагностический звук может быть синтетическим, оригинальный тракт относится к N18.

Общие требования NDS: DS/DS Lite, верхний кадр 256×192 с коррекцией DOS 4:3
(сцена 154 строки, HUD 38), нижний экран — карта во время игры; мир RU и общий
профиль монстров, RU/EN. Игровых сохранений, autosave и импорта saves нет.
Записываются только настройки. Не менять статусы и handoff GBA/SDL2.

## Критерии готовности и проверки

- [x] Две чистые сборки совпали с закреплённым SDK; сохранены текущие .nds, ELF/map и SHA-256.
- [x] В эмуляторе все 12 кнопок и touch дают ожидаемые события; порядок экранов проверен по PNG, звук и файл читаются. Физические органы ввода проверяются в N24.
- [ ] Аппаратный запуск, физические кнопки/стилус, аудиовыход и loader/DLDI отложены до N24 по поручению пользователя. Это не блокирует статус «готово (эмулятор)».

Проверки выбираются по рискам задачи: оригинальные данные/исполнение отдельно
от новых host/ARM9 реализаций, эмулятор отдельно от физической DS/DS Lite.
Совпадение двух новых реализаций не доказывает эквивалентность DOS.
Если проверка не выполнена, назвать причину и оставить критерий открытым.
«Готово» допустимо только после выполнения критериев и передачи результата.

## Результат

**Готово (эмулятор), 29 октября 2026 года.** Все программные критерии выполнены.
Аппаратные пункты открыты до N24 по [порядку проверки](../spec/validation-policy.md).
Следующий ID — **N03**; N01 и N02 дают его исследовательские и платформенные входы.

### Реализация и решения

- Общий SDK вне репозитория: `C:/Users/dspev/.local/msys64`, Wonderful
  `/opt/wonderful`, BlocksDS `/opt/wonderful/thirdparty/blocksds/core`.
  BlocksDS 1.24.0-1, ARM GCC 16.2.0, GNU make 4.4.1; 20 фактических пакетов
  закреплены в [toolchain_versions.json](../../../ports/nds/toolchain_versions.json).
  Драйвер проверяет lock, переменные задаёт только дочернему UCRT64 shell.
- Независимая диагностика `ports/nds/platform/diag/`: два экрана, VBlank,
  64-битные ticks, CPU/work, 12 кнопок, touch, PSG и чтение marker через FAT/DLDI.
  `g_nds_diag` — наблюдаемый ABI 1, 248 байт, RAM только читается frontend.
  Игровой цикл, ресурсы и GBA-код не переносились.
- Платформенная цель — GNU C11 из-за inline ASM libnds; ядро N03 — strict C11.
  Полный redraw первоначально пропускал VBlank: теперь ввод/часы обновляются
  каждый VBlank, текст отдельно, шестью группами около 10 Гц. Для слышимого
  PSG 440 Гц SDK получает 3520 шагов/с восьмиступенчатой волны. Ошибки выявлены
  фактическим исполнением ROM и проверкой PCM, затем исправлены.
- ROM открывает marker только как `rb`, проверяет ровно 16 байт
  `DOK_NDS_DIAG_V1\n`, различает ошибки. Записи файлов и игровых сохранений нет.
  Core при direct boot добавляет ROM в FAT до исполнения ARM9. После host flush
  проверяются отдельные SHA после load/run/unload; начальный SHA тоже сохранён.
- Субагенты выполнили платформу, emulator harness и независимый review.
  Команды, SDK API и ограничения — в [N02-building](../spec/N02-building.md).

### Доказательства и ограничения

Компактный итог — [analysis/nds-n02-platform.json](../../../analysis/nds-n02-platform.json).

журнал `rebuild-console.log`. Исходные ошибки сохранены отдельно, без старых

bootstrap без отдельного cached archive; независимая проверка всех подписей
этим не заявляется.

реальные DS FPS не проверены; это N24. Игра, renderer, полный бюджет N03
