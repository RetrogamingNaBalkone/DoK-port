# N21: Оригинальная заставка, меню и настройки

Статус: **готово (эмулятор)**, 29 октября 2026 года.
Паспорт зафиксирован 28 октября; все программные критерии выполнены.

## Контекст нового чата

Рабочий корень: `C:\Source\DoK-port`. Предыдущая переписка недоступна.
Обязательно прочитать [AGENTS.md](../../../AGENTS.md), [NDS-план](../plan.md)
и [NDS-handoff](../handoff.md), затем этот паспорт.
Направление NDS независимо от GBA и SDL2; их завершение не требуется.
Основа — декомпиляции PKR/PKE, ASM и проверки оригиналов. GBA-код не копировать;
исследования использовать как указатели на доказательства. Исключение — явно
принятые данные баланса из NDS-плана.

**Зависимости:** [N04](N04.md), [N06](N06.md), [N18](N18.md), [N19](N19.md). Проверить фактические результаты и handoff зависимостей.
Планируемые результаты ещё не существуют только потому, что описаны в паспорте.

## Цель

Создать полный frontend с оригинальной заставкой, двумя языками и только настройками на диске.

## Работа

1. Показать оригинальную стартовую заставку с надписями/копирайтом и музыкой; подготовить статические изображения offline под N06. Короткие A/Start не должны теряться на загрузке.
2. Создать главное меню (начать, язык, управление, предыстория, выход), выбор трёх именованных уровней и паузу (продолжить, язык, управление, главное меню). Все текстовые заставки BINTRO/EINTRO/ENDTXT и предысторию развести: фон сверху, полный текст снизу, пагинация.
3. Хранить только настройки с версией и безопасными defaults: начальный язык RU, далее последний выбранный. Обработать недоступную/повреждённую запись без блокировки игры. В меню не включать сохранение/загрузку прогресса.

## Границы

Документы GBA содержат платформенные экраны и сокращения: переносить исходные материалы и доказательства. До N22 переходы игры могут использовать явно обозначенные fixtures.

Общие требования NDS: DS/DS Lite, верхний кадр 256×192 с коррекцией DOS 4:3
(сцена 154 строки, HUD 38), нижний экран — карта во время игры; мир RU и общий
профиль монстров, RU/EN. Игровых сохранений, autosave и импорта saves нет.
Записываются только настройки. Не менять статусы и handoff GBA/SDL2.

## Критерии готовности и проверки

- [x] Оригинальная титульная картинка, надписи и музыка присутствуют; все34 страницы RU/EN проверены по исходным байтам и фактическому LCD-растру, правильный аспект сохранён. Физическое чтение с DS и прослушивание остаются N24.
- [x] Ввод на переходе поглощается, pause/resume не двигает игровое время; язык не меняет мир. Проверены одно-VBlank Start,32 ранних A/Start,12 языковых POPAL-переключений и независимое восстановление HUD/карты.
- [x] Перезапуск восстанавливает язык, но не игровой прогресс. Отсутствующий/повреждённый settings-файл даёт RU defaults, запись недоступна — настройки действуют в RAM. Реальные FAT-образы проверены после unload.

Проверки выбираются по рискам задачи: оригинальные данные/исполнение отдельно
от новых host/ARM9 реализаций, эмулятор отдельно от физической DS/DS Lite.
Совпадение двух новых реализаций не доказывает эквивалентность DOS.
Если проверка не выполнена, назвать причину и оставить критерий открытым.
«Готово» допустимо только после выполнения критериев и передачи результата.

## Результат

Реализованы новый portable frontend/controller, production loop, исходные
статические экраны и settings-only I/O. Все программные группы проверок
прошли; root отдельно просмотрел11 native-size captures. Постоянный архив
проверен побайтно, компактный итог —
[`analysis/nds-n21-frontend.json`](../../../analysis/nds-n21-frontend.json).

- [Исходные доказательства](../spec/N21-evidence.md): свежие read-only
  Ghidra-экспорты PKR/PKE, 14 native selector vectors, по два title/README
  entry points; SHA-256 оригиналов до/после совпали. Музыка once→stop.
- [Контроллер и настройки](../spec/N21-state-settings.md): 142931 host checks,
  state56 bytes; Linux static link без заявления о выполнении. Все переходы
  поглощают held keys/touch; OUTRO возвращает к выбору уровня; выход открывает
  полный ENDTXT. На диск кодируется только язык, ровно16 bytes.
- `frontend.dat`: 4684 bytes, 38 записей, полный исходный CP866 RU/EN,
  34 страницы FONT16 30×9 по N06. Картинки и палитры используются из
  принятого N04-пакета; payload не дублируется в ROM.
- Первый эмуляторный smoke подтвердил title/main/controls/back и589824
  INDEX8/LCD RGB pixels, но тёмный цвет текста отвергнут: исходный menu
  index86 давал1.852:1 на чёрном; выбран исходный ярко-зелёный index2
  с15.304:1. Ранний source/ROM сохранён в
  `research/evidence/nds/n21/rejected-dark-text/`; итоговые проверки идут
  с читаемым цветом2 и неизменённой исходной палитрой.

Полные независимые RU/EN прогоны проверили103/105 состояний,
10125312/10321920 INDEX8 и столько же фактических LCD RGB-пикселей. Пройдены
все16/18 страниц README/BINTRO1–3/EINTRO1–3/ENDTXT, три именованных уровня,
пауза, возвраты, страницы назад и production-выход через полный ENDTXT.
По6 смен языка на паузе сохранили world/simulation hashes и игровые значения.
VBlank IRQ сохраняет короткие A/Start до загрузки;32 реальных одно-VBlank
нажатия RU/EN×A/Start×фазы0…7 не потерялись и не приняли следующий пункт.

Оригинальные title110 и README110 проиграны once целиком в каждой локализации:
четыре43-секундных PCM capture достигли исходного EOS474361, корреляции≈0.99243,
underrun/stale/fault0. Музыки-loop в меню нет. Прослушивание не заявляется:
пользователь разрешил численные проверки и перенос прослушивания в N24.

POPAL локализуется только в render demand: исходные111 графических пар
проверены, отличаются только три пикселя последнего кадра POPAL. Оба исходных
варианта хранятся в том же packed store:168→169 frames,284600 packed bytes.
1049583 host checks прошли для двух полных simulation banks; две подмены
RU/EN ожиданий отвергнуты. В эмуляторе12 combinations UI-язык×уровень×compile
bank проверили все32768 actual decoded bytes, языковой N04 ID в фактическом
stream descriptor и ссылающийся quad. World/bank IDs остаются неизменными.

Обе production-сборки без диагностических chords прошли boot/BINTRO/PLAY/
одно-VBlank pause/held-A resume. Отдельный native-x86 map/HUD observer
проверил восстановление двух экранов после frontend на каждом уровне и
обоих UI-языках:12 точек,233472 HUD pixels и1179648 map pixels, столько же
фактических LCD RGB-пикселей. Settings-only проверки: успешная16-byte запись, перезапуск
с EN без игрового прогресса, corrupt→RU и исправление записи, настоящая
read-only FAT ошибка без отката выбранного в RAM языка. Любые изменения
FAT ограничены `/DOK/SETTINGS.DAT`.

Memory ledger итоговой fixture: startup524288 + managed2293760 + SDK196608
+ reserve655360 =3670016 bytes. **SDK ровно на принятом минимуме, margin0**.
Новый код N21P должен сначала освободить бюджет; резерв расходовать нельзя.
Shared buffers и owners подробно описаны в [N21-frontend.md](../spec/N21-frontend.md).
Совместный performance budget не принят: N20 имела≈15.4 virtual FPS, карта
по-прежнему рисуется целиком каждый presentation; это обязательный вход N21P,
где пользователь потребовал idle/dirty updates и немедленные drag/zoom.
