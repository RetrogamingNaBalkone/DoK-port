# N21P: публикация диагностического снимка карты после загрузки графики

C20 переносит пять `DC_FlushRange` из `nds_map_prepare` в `nds_map_commit`.
Они охватывают22 016 байт: три плоскости карты, POST visited, PRE visited,
glyphs и palette. Сами копии снимка, раскрытие карты, растр и его очистка
кэша остаются до ожидания VBlank. Код main, заголовок/ABI и растр C19
побайтово не меняются; новых состояний, выделений памяти или кэшей нет.

Порядок завершения кадра: map DMA → GPU upload → HUD → очистка кэша
диагностического снимка → публикация descriptor и чётного sequence.
DMA карты читает только pixels, чей cache clean остался в prepare.
Перенесённые массивы не читаются GPU, HUD или ARM7; после их подготовки
до завершения публикации они неизменны. Sequence остаётся нечётным на всём
интервале изменения/передачи, поэтому внешний наблюдатель не получает
промежуточный снимок как завершённый.

Стоимость не исключается из CPU-профиля: `profile[6]` суммирует собственные
участки публикации до и после ожидания, `profile[7]` — все собственные участки
карты. Перенос меняет размещение этой работы относительно границы кадра.
Первоначальная гипотеза приписывала очистке весь участок публикации примерно
0,832 мс перед SwapBuffers. Focused1066 опроверг такую атрибуцию: после
переноса участок сократился лишь до0,7093 мс; в нём также остаются подсчёт
PRE visited и построение descriptor. CPU проблемного кадра сократился
с32,1207 до31,958 мс, но тот же case16/frame66 сохранил3 VBlank и минимум
29,42267 FPS. Функциональные/native/audio проверки прошли. C20 не принят
по бюджету, полная матрица для него не запускалась.

`pre-map-flush/pins.json` сохраняет предыдущий исходник и неизменные входы.
`map-flush-source-supersession.json` доказывает точное обратное перемещение
блока во всём runtime-файле, прежний pixel clean, неизменность transfer и
порядок публикации/учёта CPU. Независимый разбор находится в
`N21P-C20-independent-review.md`. Эти проверки не моделируют ARM cache и
не заменяют focused1066, полную матрицу, actual LCD/native pixel oracle
и строгие окна map/GPU DMA. Физическая Nintendo DS остаётся пунктом N24.
