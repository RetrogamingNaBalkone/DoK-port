# N23: перенос без ведущего пробела и постраничная кнопка B

8 ноября 2026 года. Пользователь обнаружил ведущие пробелы в README
(строки с «хозяев…», «силы зла…») и других заставках; уточнил поведение B
на последующих страницах и подсказку главного меню.

## Текущее поведение

- Пробел-разделитель, попавший после ровно заполненной строки, пропускается
  при автоматическом переносе. Это действует и на границе страниц.
  Группа таких пробелов не создаёт отступ или лишнюю пустую страницу.
- Правило применяется ко всем прозаическим текстам README/BINTRO/EINTRO
  RU/EN через `dok_ui_paginate_prose()`. Расчёт страниц и рисование используют
  один вариант пагинатора. Оригинальные буквы и пунктуация не меняются.
- Явные абзацы и их интервалы сохранены. Ширина30 символов,11 строк,
  шаг12 пикселей; README по-прежнему занимает две страницы RU/EN.
- B со второй и следующих страниц INTRO/STORY/OUTRO показывает предыдущую.
  С первой страницы STORY/INTRO — главное меню. С первой страницы OUTRO
  продолжается действующий экран завершения; A завершает его к выбору уровня.
  Подсказка INTRO зависит от страницы: B: В меню на первой, B: Назад на остальных.
- Главное меню показывает только «A: Далее» / A: Next; B там не имеет действия.

Базовый `dok_ui_paginate()` обслуживает действующий HUD и исходные сообщения,
где сохраняется их побайтовая раскладка. Оба варианта используют общий код,
различается только удаление разделителя автоматического переноса в prose.
Это два текущих назначения UI, не совместимость со старыми сборками.

Исходные данные сверены по именам ресурсов README/BINTRO1–3/EINTRO1–3
оригинальных PKR/PKE RES. Это ресурсная адресация, не EXE/Ghidra/DPMI.
Оригиналы и пакеты ресурсов не менялись. Звук сохраняет полный неизменяемый
PCM из music48; статус проверки DraStic остаётся неподтверждённым.
