# N23: FPS, вода и тайминг дверей

3 ноября 2026 года. Запрос пользователя: FPS справа вверху, стабильная вода,
правильный темп потайных дверей, включая первую дверь к бластеру LEVEL2.
Продолжение N23; N24 не начата. Основа сборки — features audio21, текущие исходники.

## Проверенные причины и принятое изменение

Исследования оригинала: [N11](N11-evidence.md), [N13](N13-effects.md),
[кадровая оценка C2](playtest10-20261031.md). Это прежние проверки PKR/PKE,
нового анализа EXE в этой задаче нет. Адреса там — Ghidra NE, не runtime-селекторы.

В gameplay runtime вода имела interval0: один шаг за dispatch,18 шагов,
отмена, повторный getter. Темп зависит от FPS; отмена и повторное включение
добавляют удержание конца цикла. Теперь production frontend выводит18 фаз
по игровым часам,60 фаз/с, с сохранением дроби и без разрыва на конце цикла.

Дверь получает extent из C2 при активации, но продолжает шагать по кадрам.
При изменении FPS во время открытия длительность меняется. Production wrapper
теперь накапливает elapsed*extent шагов за секунду; замедлившийся кадр может
выполнить несколько исходных callbacks. Core по-прежнему задаёт состояния,
collision flags, звуки, occupancy, исходные задержки +52 и auto-close.
Удельный темп нормализован к примерно секунде на traversal; это явная
NDS-адаптация, а не утверждение о покадровой эквивалентности DOS.
Ожидание первого callback416ticks сохранено. Игровая пауза останавливает clock.
Диагностические frontend=0 пути и source core не изменены.

FPS считает завершённые сцены за секунду source clock, с десятичной цифрой.
Счётчик поверх MAIN справа вверху использует FONT8, небольшой тёмный фон,
обновление значения раз в секунду. Первое окно показывает `FPS --.-`.
Строки копируются в bitmap VRAM выровненными32-bit DMA.

## Проверки и результат

Финальный кандидат `animation26-ru`, RU/EN в одном ROM. Размер10 168 832 байта;
SHA-256 `6271c50db8183fc9f897d1bd38bd1afff00d36193c2966e957563923a8cf220f`.
Поставка — `artifacts/nds/dok.nds` после NitroFS-проверки упаковщиком.

Host:4453 checks PASS и101 исходная проверка interactions PASS. Исполняется
реальный production wrapper: extent8/30/52/74/96, разные интервалы кадров,
включая задержку5000ticks, открытие, закрытие, занятая дверь. Проверены
дробная шкала воды и FPS, DWORD wrap и смена world epoch.

melonDS:240 read-only наблюдений LEVEL2 подтвердили точную фазу и дробь
воды по PIT, все18 фаз, заморозку на45 кадрах паузы. FPS59,8; проверено
изображение на реальном LCD: двухцветный прямоугольник справа сверху.
В ранних кандидатах обнаружена DMA из DTCM stack: счётчик был в RAM,
но изображение отсутствовало. Итоговый bitmap буфер — static main RAM,
выравнивание32байта. Цвета выбираются из самой тёмной и светлой записей
палитры текущего уровня, исключая прозрачный индекс0.

Маршрут LEVEL2:100 клеток обычными кнопками,2144 video frames, PASS.
Первая потайная дверь по маршруту к оружию — glyph103 (`g`), extent58:
от первого наблюдённого phase1 до ready/open10223ticks (~1,020с).
Первые ненаблюдённые фазы сюда не входят. Все1225 обычных presentation
интервалов ≤2VBlank; среднее44,55FPS, минимум окна29,91FPS.
Это ограниченная регрессия, не приёмка полной N23 или60FPS.

Сводка — `analysis/nds-animation-20261103.json`, полные отчёты и снимки —
`research/evidence/nds/n23/animation-20261103/`. Исходники, ROM/ELF/map и
манифест финального кандидата — `research/evidence/nds/n23/candidates/animation26-ru/`.
