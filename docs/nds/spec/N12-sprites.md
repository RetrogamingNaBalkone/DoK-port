# N12: объекты, кадры и аппаратные перекрытия

29 октября 2026 года. Независимые модули NDS — `render/sprites.c`,
`render/sprite_assets.c`, `render/texture_cache.c`; диагностическая сборка —
`Makefile.n12`, `platform/sprites_probe/`. Код GBA не используется.

## Исходные правила

Образцы: PKR.EXE SHA-256
`12f78afc0eba05f76b5dc0bb99da38d7daa20585024c0ba958fe828aa3864d28`,
PKE.EXE `cce7bc5993d0734ad87e93db37a70b8b52faedfff14ac48d6e317e5ac996a37b`.
Адреса ниже — **Ghidra NE loader**, не файловые смещения, NE-индексы или
runtime-селекторы DPMI. Свежие экспорты, ASM, отдельный непроверенный
автоматический C, проекты и журналы закреплены в
`research/evidence/nds/n12/original/{ru,en}/analysis-manifest.json`.
Драйвер проверяет SHA образцов до/после и открывает проекты read-only.

| Правило | PKR | PKE |
|---|---|---|
| Последовательный accessor, END устанавливает индекс −1 | `1050:0054` | `1018:0F62` |
| Indexed accessor ограничивает индекс первым/последним кадром | `1050:00DF` | `1018:0FED` |
| Base-конструктор: flag `0800` выбирает кадр 0 | `1068:02F5`, `03C1…0413` | `1020:07CF` |
| Конструктор монстра безусловно выбирает кадр 0 Flic | `1068:36B1`, `3713…372E` | `1020:3E14`, `3E76…3E91` |
| Base animation callback | `1068:0421` | `1020:0901` |
| Billboard constructor | `10B0:0CCB` | `1040:0CE3` |
| Сборщик TMap/MMap | `1098:30C1` | `1030:3571` |

Far CALL/RETF и очистка аргументов вызывающим кодом сохранены в instruction
probes. Идентификаторы ресурсов заменяют offset16:selector16; сериализованные
указатели не переносятся в адресное пространство ARM9. Метаданные N04
заимствуются на весь срок жизни банка.

Ширина и высота — signed low16 от `frame dimension * object.width_parameter`.
Половина ширины вычисляется SAR16, включая отрицательные нечётные числа.
Native projector требует depth > 0, использует denominator depth+200,
low32 IMUL и SAR15; ключ — max(0, depth−SAR16(width,2)). Величина масштаба
не является радиусом столкновения. Перенос явно отказывает в неподдержанных
неположительных размерах; instruction oracle отдельно проверяет их арифметику.

TMap class3/6/9/10 и MMap class3 находятся в центре клетки, MMap class9
использует actor X/Z. Основание Y — sign16(−FCMap.H−object.H). **Сплошная
стена TMap class2 исключает весь оставшийся проход клетки**, включая MMap:
PKR `1098:429E…42AE`. Наличие seed в такой клетке не разрешает рисовать его
через стену. Начальные seed и общий профиль берутся из N05; AI не добавлен.

Native base flag `0800` и специальный конструктор class9 определяют начальный
кадр; общий Sprite монстра не подменяет кадр 0. Анимационные изображения
получают runtime image flags8. Число кадров, параметры A/B, размеры и signed
интервалы сохраняются из RES; два интервала `86A0` остаются −31072.
Нет выдуманного восьмистороннего набора: billboard обращён к камере,
нужный кадр/последовательность передаётся состоянием представления.

## Время и неизменяемый снимок

`dok_sprite_player_step` выполняет один исходный base callback: уменьшает
remaining, переходит к следующему кадру с перезапуском через END, публикует
signed interval для N08 `set_interval`; remaining<=0 отменяет callback.
Он не читает FPS или часы. C-тест подаёт одинаковые N08 sweeps при двух
частотах чтения изображения и сверяет одинаковые 81 callback и конечное
состояние при 72/37 чтениях. Возврат из отрицательного интервала сохраняет
исходное unsigned deadline-поведение N08.

Snapshot содержит epoch, revision, const world и const bindings[256]. Gather
не изменяет мир. Append требует совпадения epoch/revision и действующий lease;
проверяет полный объём и диапазоны до изменения сцены. Данные не отбрасываются
при превышении лимита. Изменять bindings, occupancy или actor pose при живом
снимке нельзя. Рендер не запускает AI, подбор или бой.

Паспорт N12 разрешает fixtures. Диагностика фиксирует начальные состояния и
отдельно проходит все 154 кадра — по одному явно заданному состоянию за
presentation. Это **проверка каждого ресурса**, а не скорость проигрывателя.
Она помечена `source_kind=12` и вынесена из штатного профиля. Native timing
подтверждён отдельными x86 callbacks и тестом N08; живое поведение монстров
продолжает N16.

## 3D и кэш

N06-проекция, локальная решётка 512 world units, сцена 256×154 и HUD 38 строк
сохранены. Billboard имеет основание в исходном Y и базис камеры sin/cos.
UV охватывают исходные 0…width−1 / 0…height−1 без включения POT padding.
Masked индекс0 пропускает запись глубины; общий аппаратный Z-buffer закрывает
объекты стенами, дверями и другими объектами. Это адаптация DS 3D, не обещание
побитового равенства DOS painter/raster.

Полный набор спрайтов/кадров LEVEL1 занимает 1 249 728 байт в GPU index8 POT.
Он не помещается ни в VRAM384 КиБ, ни в остаток RAM asset pool. Банк хранит
метаданные; в GPU отправляются только материалы опубликованной сцены и
видимые кадры. RAM-кэш компактен, ограничен остатком N03 asset region,
не вытесняет pinned записи текущего кадра; после всех require разрешается
получать указатели. Ошибки SHA/ёмкости/параметров не публикуют новую запись.

Измеренные FAT/catalog/hash задержки при первом повороте устранены загрузкой
всех начальных glyph bindings в RAM на явной границе загрузки уровня. Остальные
кадры загружаются по требованию. Все payload проходят N04 schema/SHA. Промахи,
вытеснения, bytes и время остаются в отчётах; массовая смена кадров fixtures
не выдаётся за установившийся gameplay.

GPU stream разделяет планирование адресов, submit и commit. Plan не пишет
тексели. После VBlank swap commit копирует pending payload до начала 3D
растеризации; начало/конец проверяются по VCOUNT. Старые полигоны не получают
тексели нового кадра. При фрагментации адреса перепаковываются без записи
пикселей до commit. Начальный набор загружается при скрытой 3D-сцене до первого
submit и отмечается loading; его стоимость не попадает в штатные интервалы.
Обычный N07 backend остался неизменённым префиксом C-файла; новый API добавлен
после него. Точные прежние bytes сохранены в `n12/baseline/`.

В N12 LIGHT остаётся identity: после-LIGHT маска и палитровые варианты — N13.
Это ограничение этапа, а не принятый финальный вид игры.

## Проверки и воспроизведение

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ports/nds/tools/export_sprite_evidence.ps1
py -3.14 -B -X utf8 ports/nds/tools/check_sprites.py --runtime
py -3.14 -B -X utf8 ports/nds/tools/check_sprites.py --variant en --runtime
py -3.14 -B -X utf8 ports/nds/tools/check_sprites.py --variant audit --runtime
```

SDK общий: BlocksDS1.24.0-1/GCC16.2.0, 20 закреплённых packages; Zig0.13.0,
Python3.14.6, Unicorn2.1.4. Core melonDS DS libretro1.4.0: DS mode, builtin BIOS,
direct boot, software renderer, JIT/threaded renderer off, readonly FAT, sync off.
Core по умолчанию берётся из принятой общей установки; `--core <DLL>` задаёт его
явно и проверяет SHA. SDK не устанавливается и не копируется в проект.

Host gate проверяет 439 прежних входов с точными архивами семи заменённых
источников и 95 текущих pins N07P. Не отключает старую integrity-проверку ради
новых файлов. Исходные EXE/RES не меняются. Результаты и версии —
`research/evidence/nds/n12/host-ru.json`, `original-report.json`,
`world-original-report.json`; текущие сборки — `build/nds/n12/{ru,en,audit}/`.
Компактный итог и окончательные hashes — `analysis/nds-n12-sprites.json`.

Native: 1240 billboard-векторов, 12 constructor cases, все 24 последовательности
и callbacks обеих версий. Все 4096 клеток каждого уровня разобраны исходным
builder; 1494 billboard placements сверены на 4144 позах с native AABB/projector.
Полный host scan — 65 192 позы, максимум 39/28/82 спрайта и 288/290/263 quad
в LEVEL1/2/3. Ни одно размещение не удаляется ради бюджета.

GPU-проверка содержит накопленные N07 сцены, crowded повороты, каждый исходный
кадр и отдельную controlled сцену двух masked объектов со стеной. По 21 738
устойчивым пикселям проверены прозрачные дырки, передний/дальний объект и
перекрытие стеной; края имеют заранее заданный 2 px guard. Flat coverage
отдельно проверяет отсутствие дыр и общий depth с геометрией. SHA-трассы
считаются на ARM9 по фактическим texture bytes для всех кадров, включая EN POPAL.

Физическая DS/DS Lite, flashcart, IRQ и аппаратный FPS остаются N24.
Нижний экран здесь диагностический; полный бюджет gameplay/карты/звука не доказан.
