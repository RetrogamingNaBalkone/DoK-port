# N05: RU-мир, профиль и локализация

29 октября 2026 года. Архитектурные границы приняты до реализации.
Статус — **готово (эмулятор)**. [Паспорт](../tasks/N05.md),
[контракты N03](N03-contracts.md), [пакет N04](N04-assets.md).

## Разделение данных

Полный CP866 LEVEL из пакета остаётся неизменяемым и живёт дольше всех
заимствованных spans. Независимый strict C11 parser сохраняет восемь настроек,
все определения, common/class-specific поля с native offset/type и исходным
токеном, inherited Sprite/Flic/Sound, сообщения и все три карты. Неизвестная
семантика не получает выдуманного игрового имени. Неизвестная схема отвергается.
Базовая модель и effective copy с профилем существуют отдельно.

Начальный мир строится только из RU-модели и effective значений. Он содержит
геометрию, карты, определения и проверенные по placement ASM начальные seeds.
Один seed относится к определению, а не к каждой клетке; неразмещённые
определения и повторения glyph сохраняются. Это ещё не полный runtime объект,
AI или исполняемый мир. Неизвестные constructor значения явно не объявляются
известными нулями. Последующие N08–N17 восстанавливают runtime преобразования.

У построения мира нет аргумента языка. Отдельный presentation descriptor
выбирает локализованные refs и CP866 тексты по `(glyph,class,slot)`; числа,
геометрия, порядок определений и размещение EN не копируются в мир.
Изменение языка не пересоздаёт мир и не меняет epoch/IDs/профиль.

## Строгий профиль

Известные архивы/LEVEL фиксируются SHA-256, actual source bytes проверяются;
метаданные сами по себе не доказывают соответствие образцу. Полная семантическая
модель проверяется переносимым fieldwise digest без native padding/pointers,
чтобы исходные bytes вместе с подменёнными parsed полями не прошли guard.
Константы сверяются независимым oracle по исходным RES.

Только LEVEL1 получает изменения:

| Область | Поле | Требование |
|---|---|---|
| glyph 0x81, 0x86 | HP / speed / wake | 42 / 20 / 9000 |
| glyph 0x8C | HP | 12 |
| class 9 + animation БОЯР_И | N | 24 |
| class 9 + animation МЫШЬ_Л | N | 8 |
| первая Баба-яга, glyph 0xA0 | HP / speed / scale / wake | 54 / 60 / 7 / 3400 |

Фактически меняются 39 scalar values: 33 N бояр, четыре speed/wake,
HP 0x8C, speed 0xA0. Остальные выбранные значения — проверяемые old=new
инварианты. N не объявляется количеством кадров; его AI-семантика — N16.
33 определения бояр соответствуют 31 размещению, мышей 30/30; это контроль
образца, а не список позиций или требование одного размещения на определение.
LEVEL2/3, остальные числа, оружие, collision radii, карты и размещение остаются RU.
Diff содержит old/new/reason и происхождение для изменённых и сохраняемых решений.

## Память и отказ

Typed caller-owned base/effective/локализованная модель и начальный мир
укладываются в world 384 КиБ; transient typed candidate — в scratch 128 КиБ.
Lease исходных RU/EN текстов и тестовый export учитываются в asset pool 1 МиБ;
workspace каталога — в I/O 128 КиБ. Фактические ARM9 resident 346332 байта, scratch 105052 байта; полная память
и фактические проверки — в паспорте N05.
Гарантии отказа: опубликованные out/base/world и diff не меняются, candidate
может измениться. Нет скрытых malloc в ядре, per-frame alloc или игровых saves.

## Проверка

Независимый stdlib oracle читает исходные RES и сравнивает все common/class
поля, refs/text spans, карты, seeds и bindings, а не только изменённые HP.
Тесты проверяют unexpected source/parsed model, EN как источник мира,
отсутствующие/неверные поля, порядок определений и транзакционные отказы.

ARM9 probe читает тот же внешний пакет через FAT/DLDI. Все LEVEL1–3 и обе
локализации предъявляют полный JSON export в RAM; эмулятор считывает его
независимо и сравнивает с oracle. Переход между случаями — обычной кнопкой A,
без записи emulated RAM. Проверка на физической DS/DS Lite остаётся N24;
FPS, полный игровой working set и DOS equivalence этой задачей не заявляются.

## Переносимый digest модели

`dok_balance_model_digest` использует SHA-256 над последовательностью байтов.
Тег ASCII `DOKNDS-N05-MODEL1` заканчивается NUL. Все целые little-endian;
знаковые числа записываются как соответствующие unsigned bit patterns.

1. u32 source_bytes, u32 source_asset_id, u16 source_index, u8 language,
   u8 reserved, 32 байта source SHA, восемь u16 settings, u32 ignored_step_ver,
   u32 truncated_messages.
2. Palette и Light spans, u16 object_count, 256 u16 glyph_index.
3. Для каждого активного определения в исходном порядке: u16 class/flags/
   width/height/sprite_flags, u8 glyph/marker, u16 field_count/reserved;
   spans Sprite/Flic/Sound/raw_line/raw_tail; затем все активные поля:
   u16 native_offset, u8 kind/reserved, u32 value, token span.
4. Три полные карты по 4096 байт в порядке TMap/MMap/FCMap.

Каждый span — u32 offset, u32 length и соответствующие исходные bytes.
Указатели, padding и неактивные элементы массивов не участвуют. Перестановка
определений меняет digest и отвергается как неизвестная модель; группы профиля
всё равно выбираются по class + animation, без списка позиций в массиве.
Семь контрольных digest (RU/EN base ×3 и effective RU LEVEL1) независимо
вычислены oracle и сверены с C; это fingerprint данных, не скрытый игровой банк.

## Принятый результат

Все критерии N05 закрыты по host/эмулятору: 26930 host checks, полная независимая
сверка шести C-экспортов, 5000 bindings и 38 эмуляторных assertions. Из RAM реально
исполняемого ARM9 прочитаны и сверены все шесть полных JSON, максимум 475246 байт.
Числовые old/new/reason для 39 изменений и 35 сохраняемых условий опубликованы
в [компактном итоге](../../../analysis/nds-n05-balance.json).

Полный повтор: `python -X utf8 ports/nds/tools/check_world.py`, затем
`run_world_emulator.py --core <общий melonDS DS libretro DLL>`. Точные версии,
SHA, команды, первичные отчёты и пределы — [в паспорте](../tasks/N05.md).
Семантика AI/constructor runtime ещё не реализована, физическая DS — N24.
