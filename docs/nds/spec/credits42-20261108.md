# N23: две страницы «Об авторах»

8 ноября 2026 года, по запросу пользователя. Пункт главного меню —
«Об авторах» / Credits. Обе локализации содержат ровно две страницы:

1. NewCom, Москва, 1995; авторы трехмерной технологии Александр Разбаков
   и Андрей Разбаков; художник Дмитрий Цирухин.
2. DS-порт — «Ретрогейминг на балконе»; ссылка
   `t.me/RetroGamingNaBalkone` и QR-код.

Имена, роли и год сверены с ресурсом ENDTXT оригинальных PKR/PKE RES
через `frontend_pixel_oracle.OriginalFrontendArt.original_text()`. Это
ресурсная адресация по имени ENDTXT, не адрес EXE, NE или runtime-селектор.
Содержимое оригиналов не менялось; сокращены пустые строки и отступы,
название игры заменено заголовком раздела. Текстовые ресурсы frontend.dat
сохраняются исходными; компактная компоновка титров задаётся отдельно.
GBA служит только образцом состава страниц и источником ссылки/QR-маски,
его код движка и архитектура в DS не переносились.

Шрифт оригинальный FONT8, один символ 8×8. QR V3 M, 29×29 модулей,
масштаб 2 пикселя на модуль, белое поле 4 модуля: итог 74×74 пикселя.
QR расположен x12/y48, подпись x104; URL по центру y140.
Палитра нижнего дисплея резервирует индексы254/255 для чёрного/белого
на этой странице. Палитра фона верхнего дисплея не меняется.

A листает вперёд; после второй страницы возвращает в главное меню.
B со второй возвращается к первой, с первой — в меню на пункт «Об авторах».
Оба выхода завершают игровое состояние штатным STOP_GAME. Release gate
сохранён. При вызове титров игровым потоком используется та же компоновка.
