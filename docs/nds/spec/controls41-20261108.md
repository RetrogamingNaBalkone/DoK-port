# N23: оружие на лицевых кнопках, FPS на Select

8 ноября 2026 года. Пользователь назначил переключение оружия на свободные
лицевые кнопки, Select — на счётчик FPS.

| Действие | Современная схема | Классическая схема |
|---|---|---|
| Следующее доступное оружие | B | A |
| Показать / скрыть FPS | Select | Select |
| Двери / действие | X | X |

Остальные привязки указаны в [плане](../plan.md#управление) и на экране
«Управление» RU/EN. Смена оружия срабатывает при нажатии. Use срабатывает
при отпускании X; B современной схемы больше не поступает в Use.
В классической B остаётся бегом, A поступает только в смену оружия.

Select обрабатывается frontend только в PLAY и не передаётся игровому
consumer смены оружия. Переключение FPS однократное по фронту: удержание
не повторяет его. Start имеет приоритет при одновременном нажатии.
В меню, паузе, на экране смерти и до отпускания кнопок после перехода
видимость FPS не меняется. Изначально счётчик показан; выбор сохраняется
в текущей сессии, включая pause/retry, но не записывается на носитель.
Подсчёт FPS продолжается и при скрытой надписи.

Поле `show_fps` помещается в прежние 64 байта `dok_frontend`.
При изменении видимости инвалидируются `overlay_valid` и `overlay_blank`:
следующий штатный weapon overlay восстанавливает пиксели под FPS, включая
ветку без оружия и сохранённый в VRAM неизменный bitmap. Это не очистка
прямоугольника произвольным цветом. Частоты логики, бой и формат настроек
не менялись. Готовая ROM не содержит тестовых изменений инвентаря.

## Проверки

- Frontend host: 151718 проверок, все 4096 комбинаций обеих схем,
  toggle/hold, pause/death/release gate и взаимное исключение Select/оружия PASS.
- Flow host: 655965 проверок PASS.
- `check_controls41_emulator.py`: обе схемы, реальные физические кнопки,
  переключение двух реальных weapon definitions 1→2→1, Select без смены
  оружия, удержание 90 frames, pause/resume PASS. Это явный fixture инвентаря
  через RAM NDS по DWARF точного ELF, не прохождение и не сохранение игры.
- LCD-проверка: участок букв FPS отличается после скрытия и точно
  восстанавливается после показа; скрытие проверено поверх первого оружия
  и после смены bitmap. Снимки с надписью/без неё просмотрены.
- UI/input/RU–EN/settings/FAT/restart: 6979584 INDEX8 и столько же RGB
  pixel checks PASS; обновлённые экраны обеих схем проверены oracle.
- SDK heap 200704 ≥196608 байт, reserve655360, managed2293760; лимиты прежние.
- Новая длительная выдержка, DS/DraStic и прохождение не выполнялись.
