# N04: независимый offline-конвертер

29 октября 2026 года. [pack_assets.py](../../../ports/nds/tools/pack_assets.py)
создаёт пакет по принятому [дисковому контракту DOKNDS1](N04-assets.md).
Он использует только стандартную библиотеку Python и не импортирует GBA,
SDL2 или исследовательские анализаторы. Разбор написан заново по описаниям
оригиналов; независимый oracle не импортирует этот конвертер.

## Входы и доказательства формата

Входные неизменяемые файлы и ожидаемые SHA-256 закреплены в исходнике:

| Образец | Байт | SHA-256 |
|---|---:|---|
| PKR.RES | 2718099 | `af7135fbcfc765c1e963682a29b108ffe90d652d96fa130cf9db6b217277b816` |
| PKE.RES | 2717872 | `865da340621fa6f90548a84e9ae9bf0a85071befb32a40ca1d359e488f74d458` |

Источники: [RES](../../originals/resources.md),
[анимации](../../originals/animations.md), [звук](../../originals/sound.md),
[пиксели/LIGHT](../../originals/rendering-assets.md),
[уровни](../../originals/levels.md). Файловые offset в provenance относятся
к RES, а не к адресам Ghidra или DPMI-селекторам.

Форматные ASM-опоры ранее получены в Ghidra: загрузка каталога PKR
`10E0:0000` / PKE `1058:0C02`; image load `10F8:02D9` / `1060:034D`;
animation load `1050:026B` / `1018:11B1`; SVM stream load `10E8:007C` /
`1058:1254`. Здесь это адреса Ghidra NE-loader, не файловые offset.
Новый EXE-анализ этим инструментом не выполняется.

## Преобразование

У каждой версии проверяются 146 contiguous records с 30-байтовыми записями.
Исходные имена разбираются как CP866 до первого NUL. Неинтерпретируемые
остатки имени, cache/pointer-поля и хвост архива сохраняются hex-строками
в локальном provenance. В runtime-каталоге имена дополняются нулями;
native pointer никогда не становится адресом ARM9 или хоста.

Покрытие каждой версии: 77 изображений, 24 анимации/154 кадра, 23 звука,
9 текстов, 3 LEVEL, 5 палитр, 3 LIGHT, 2 шрифта. Все 292 исходных блока
сохраняются как RAW_SOURCE, включая различающиеся EN LEVEL и POPAL.
Выбор RU-мира принадлежит последующим игровым задачам, а не удалению EN данных.

Конвертер проверяет точные размеры image18 и окончания анимаций; frame ticks,
A/B, stored flags и неизвестное поле заголовка сохраняются без смысловых
переименований. Runtime load-time flags=8 кадра записываются отдельно.
FONT8/FONT16 и LIGHT получают типизированные варианты без изменения байтов.
LEVEL_CP866 остаётся полным текстом; LEVEL_MAPS содержит только три точные
плоскости и геометрию. Полная grammar/objects/balance остаётся N05.

Каждый SVM проверяется по 36-байтовому заголовку. Signed PCM8 получается
точным XOR `0x80`; исходная номинальная частота не пересчитывается.
Короткие эффекты имеют одну часть, заставка — восемь частей максимум
65536 байт. Descriptor сохраняет rate/count/C/D/unknown28/unknown32 и
явно ссылается на ID, sample offset и длину каждой части.

Все девять текстовых ресурсов получают CP866 и UTF-8 варианты. CR, LF,
пробелы и `$` сохраняются полностью; NUL или переносы не добавляются.
PANEL_DAT остаётся конфигурационным текстом, не объявляется заставкой.

Семь full-screen фонов 320×200 преобразуются в 256×192 с учётом DOS 4:3.
Nearest sampling использует центры пикселей, строго по формуле общего
контракта. Художественные надписи остаются в оригинальном рисунке;
соседние BINTRO/EINTRO/ENDTXT не впекаются в картинку.
Для BSPR/ESPR применяется GAMEPn, для заставки — ЗАСТАВКА_ПАЛ.

GPU INDEX8 содержит все исходные 77 изображения и 154 кадра с POT-размерами
не меньше 8 и zero padding. Целевая STATIC_GPU имеет storage 256×256 и
content 256×192. Это данные для `GL_RGB256`, а не окончательный material.
Установленный SDK `videoGL.h` задаёт POT 8…1024 и отдельный
`GL_TEXTURE_COLOR0_TRANSPARENT`; конвертер не назначает этот флаг.
Исходный renderer проверяет ноль после LIGHT, поэтому нельзя заранее
объявлять source index0 единственным правилом прозрачности.
UV/padding, LIGHT, отражения, crop и проекцию уточняют N06/N07/N13.

## Детерминизм и запись

ID и порядок records заданы форматом. Уникальные payload размещаются
в порядке первого ID с выравниванием32 и нулевым padding. Совпадение SHA
проверяется полным сравнением байтов перед alias. В package нет времени,
случайных чисел, absolute machine paths или зависимости от порядка файловой
системы. SHA header/catalog/payload включены в пакет.

Перед публикацией и при финальном отчёте повторно проверяются SHA исходников.
Package и PNG разрешены только внутри `build/nds/`, JSON — внутри
`research/evidence/nds/n04/`. Resolve проверяет выход через alias;
фиксированный корень вывода не может перенаправляться junction/symlink.
Существующий файл с hard-link aliases отвергается. Имена ресурсов не
используются как пути: PNG именуются языком, числовым индексом и ролью.

## Воспроизведение и результат

Из корня репозитория, фактически CPython 3.14.6:

```powershell
C:/Source/wasdify/.venv/Scripts/python.exe -X utf8 ports/nds/tools/pack_assets.py
```

Необязательные `--output` и `--report` допускают пути только в указанных
деревьях. Default package — `build/nds/assets/dok-assets.ndspak`, отчёт —
`research/evidence/nds/n04/converter-report.json`, provenance — соседний
`provenance.json`, PNG — `build/nds/assets/previews/`.

Текущий package: **9230016 байт**, 1466 catalog entries, 738 уникальных
payload и 728 aliases. SHA-256:
`2f03ba02c9986b4e0bd321e94ca00df8a355f7dbb1dff5598a950d3366061511`.
Сам converter-report фиксирует SHA исполнявшегося исходника, всех входов,
header/catalog/package и локального provenance. Это результат конвертера;
приёмку независимой сверки и runtime фиксируют паспорт N04 и общий отчёт.

Создаются source/target PNG всех семи фонов обоих языков и синтетический
aspect oracle. Его исходная окружность описана в DOS-сетке эллипсом
radiusX=60/radiusY=50: после X×0,8/Y×0,96 получается круг radius48.
Грубая сетка 40×25 становится 32×24. PNG применяют VGA6→RGB8 для обзора,
а package palette использует VGA6→RGB555; PNG не является DAC-захватом DOS.

Локальные отрицательные проверки выхода сохранены в
`research/evidence/nds/n04/converter-output-guards.json`: отвергнуты
путь исходного RES, выход через `..`, отчёт вне research и hard-link alias;
контрольные байты сохранены. Проверки пакета и преобразований выполняет
отдельный oracle. Физическая DS/DS Lite остаётся N24; реальная частота
звука, FPS, renderer и проходимость здесь не заявлены.
