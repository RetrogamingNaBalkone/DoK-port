# N21P: сохранность исторических артефактов

Итоговый локальный архив сохраняет текущие сборки, доказательства и
обоснованные контрольные образцы. Полное сохранение каждого промежуточного
host executable не требуется AGENTS.md. При раскрытии старых вложенных
отчётов обнаружены три отсутствующие версии метаданных и семь прежних
исполняемых файлов; это не отсутствующие входы финальной C21.

Неизменяемый `historical-artifact-retention-limitations.json` содержит точные
path/origin/expected SHA, причину, заменяющую область проверки и pins
сохранившихся replay inputs. Root разрешил только эту ограниченную политику.
`performance_waivers` и `source_integrity_overrides` пусты.

Три metadata references — прежний C7 host-report, изменяемый C17 process JSON
и ранний C18 host-report. Первые два отдельно описаны в
[предыдущем ограничении](N21P-historical-metadata-limitations.md); тот artifact
не переписан. Третий возник в root-проверке первого C18 host JSON; текущая
сохранённая версия отчёта имеет другой SHA. C18 отклонён по быстродействию,
а его source/host/native evidence и окончательный C19 raster proof сохранены.
Старый SHA не объявляется совпадающим с текущим файлом.

Семь execution references находятся только внутри старых `pre-math` и
`pre-compact` discovery reports: Windows validation/equivalence/dump EXE и
Linux dump, записывавшиеся по повторно используемым build paths. Поиск
11 533 NDS executable/text-proof файлов их прежних SHA не нашёл. Сохранены
исходники, headers, тесты, Python tools, отчёты и точные compile commands
с общим Zig 0.13.0. Linux execution в этих отчётах не заявлялся. Replay
возможен по сохранённым входам, но сейчас не выполнялся; побайтовое
восстановление старых executables не утверждается.

Нельзя заявлять100% сохранность всех вложенных исторических binary/report
pins. Финальные452 source/tool inputs, семь ROM/ELF, все предъявленные кадры,
покрытие профиля, native/LCD/audio и окна DMA проверены независимо и остаются
обязательными. Старые JSON не изменялись. Данный artifact не добавляет
исключений для производительности, механики, пикселей, памяти или финальной
целостности исходников.
