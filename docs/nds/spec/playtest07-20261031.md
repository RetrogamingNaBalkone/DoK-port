## Зависание после бластера

Пользователь: LEVEL1, подобрать бластер и идти к первой комнате.
На точном playtest03 ordinary-input маршрут воспроизвёл остановку:
297 presented frames, затем frame298, hero x22429/z24028,
`g_nds_effect_probe[31]=1166`. Texture commit начался на VCOUNT192,
закончился на217; допустимое окно192…213 нарушено. `frontend_loop`
вернул ошибку65536; `main:done` навсегда оставлял последний экран.
Это остановка игры из-за проверки бюджета, а не зависание Python/эмулятора.

Исправление в новом NDS renderer:

- Подготовленные текстуры передаются 32-битной DMA из выровненных буферов.
- Более32KiB обновлений заранее переводят renderer в уже существующий
  preload-путь с отключённым 3D rasterizer, до submit новой геометрии.
  Крупная замена не пытается вместиться в короткое окно обычного кадра.
- Невместившаяся bounded relocation тоже допускает безопасный rebuild
  в preload, вместо безусловного завершения игры.
- Проверки окна для обычного commit сохранены. Экспериментальный порог64KiB
  отвергнут: playtest06 позже остановился на frame2265 с end line214.
  Итоговый playtest07 использует проверенный консервативный порог32KiB.

Крупная замена может кратко скрыть 3D-слой, пока загрузка и swap не завершатся.
Она помечена LOADING; такие интервалы исключены старым FPS-анализатором.
Поэтому его штатные FPS не доказывают общую плавность этого пути.
Полные маршруты и аппаратная оценка остаются открытыми.

## Шрифт и HUD

По уточнению пользователя сохранение пропорций FONT16 было ошибочной
интерпретацией: нужен менее вытянутый вид букв, а не уменьшенная высокая форма.
Окончательный вариант использует исходный **FONT8 8×8, без масштабирования**
для игровых сообщений и сюжетных страниц RU/EN. Игровое поле сообщения —
30 колонок ×2 строки, все исходные строки целиком видны. Это заменяет прежнее
решение «одна строка любой ценой». Номера здоровья/заряда пока остаются FONT16.
Сюжетные страницы сохраняют прежние30 колонок/9 строк и пагинацию, внутри
строки16px выводится исходный8px glyph. Меню уже использует FONT8.

Два оружия расположены справа от патронов: x150 и178; ключи — x212/226/240
в правой нижней части. Исходные `ПОРУЖИЕ1/2`85×39 теперь вписаны с сохранением
отношения сторон в прозрачные tiles20×10 (сам рисунок20×9), вместо14×14.
Банк сохраняет8192 байта; хвост7778…8177 переиспользуется без роста памяти.
Исходные RES не менялись; индексы/SHA — `playtest-ui/sources.json`.

Host oracle читает исходные RES независимо от нового UI blob. Проверены
546 исходных сообщений,1316 целевых растров,1024 glyph cases, все signed16
значения чисел и132669 защищённых HUD-растров.

## Ускорение и индикация загрузки

- Catalog reader получает8×4096-байтовый кэш immutable pages из первых32KiB
  освобождённого open workspace. Он не пересекает visited/planes/frontend/map
  mirrors, начинающиеся с45056/49152/61440/65536 байт I/O slab.
  `test_catalog_pages.c` сравнивает последовательные и перемешанные чтения
  с исходным файлом, проверяет guards и обе fault injections.
- Frames заранее сжимаются сборочным host-инструментом. NitroFS `frames.dat`
  содержит169 записей, включая обе localized overlay frames; декодированные
 1282496 байт совпадают с package pixels. Runtime проверяет весь packed bank
  по скомпилированному SHA-256 и наличие нужных sprite entries.
-22 эффекта заранее сжимаются тем же lossless codec в `sounds.dat`314352 байта.
  Runtime сохраняет прежнюю сортировку по размеру и два банка163840 байт,
  загружает готовые данные и проверяет SHA. Двойного чтения и сжатия PCM на DS
  больше нет. `check_packed_loading.py` декодирует все clips и сравнивает каждый
  PCM byte/rate с независимым исходным RES. Музыка заставки сохраняет прежний
  streaming и проверки восьми chunks.
- Ранний LOADING и индикатор этапов отображаются до NitroFS/FAT init и во время
  подготовки уровня. Это этапы, не обещание равномерного процента времени.

ROM вырос примерно на0,60MB; дополнительной копии toolchain нет. Расход
managed slab2293760, static startup507904, SDK headroom212992,
reserve655360 байт сохраняется. Хеши ROM и пяти NitroFS файлов — в manifest.
Числа времени финального прогона приведены в компактной сводке; прежний точный
playtest03 имел заставку7,488с и входы уровней8,575/9,377/8,993с.
Это эмуляторные границы видео, не физическая DS или wall-clock Python.

## Воспроизведение

Общий Python3.14, Zig0.13.0, BlocksDS1.24.0/GCC16.2.0. Сборка с `-Werror`;
MSYS2 требует выхода из песочницы из-за Win32 signal pipe. Для повторной
компиляции выбрать новый label: существующие manifests immutable.

```powershell
py -3.14 -B -X utf8 -c "import sys,json;from pathlib import Path;sys.path.insert(0,'ports/nds/tools/performance');from build import build;f=json.loads(Path('build/nds/n23/playtest03-ru/build-manifest.json').read_text())['feature_selection'];build('playtest07-ru',f)"
py -3.14 -B -X utf8 ports/nds/tools/performance/check_packed_loading.py build/nds/n23/playtest07-ru
py -3.14 -B -X utf8 ports/nds/tools/check_playtest_ui.py
py -3.14 -B -X utf8 ports/nds/tools/check_hud_host.py
py -3.14 -B -X utf8 ports/nds/tools/check_playtest_controls.py build/nds/n23/playtest07-ru
py -3.14 -B -X utf8 ports/nds/tools/performance/ordinary.py --target build/nds/n23/playtest07-ru --level 1 --cells 220 --video-budget 10000 --run-id freeze01
py -3.14 -B -X utf8 ports/nds/tools/run_joint_frontend_emulator.py --target build/nds/n23/playtest07-ru --language 1 --mode live --levels 1 2 3 --steady-presentations 120
py -3.14 -B -X utf8 ports/nds/tools/run_frontend_emulator.py --target build/nds/n23/playtest07-ru --mode world-smoke --no-storage
py -3.14 -B -X utf8 ports/nds/tools/package_rom.py --target build/nds/n23/playtest07-ru
```

Эмуляторные команды запущены через `performance/run_logged.py` с `.log.gz`
в target. Полные исходники, ROM/ELF/map и generated input hashes сохранены
build driver в `research/evidence/nds/n23/candidates/playtest07-ru/`.
Новый анализ исходных EXE не выполнялся. Адреса здесь — функции нового
NDS-кода и DS VCOUNT, не файловые/NE/DPMI адреса оригиналов.
Далее N23: пользовательский повторный плейтест, оценка крупных замен текстур,
полные текущие маршруты и remaining FPS acceptance. N24 не начата.
