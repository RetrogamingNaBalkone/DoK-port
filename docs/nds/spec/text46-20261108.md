# N23: компактные абзацы заставок и возврат по B

8 ноября 2026 года, по запросу пользователя. «Предыстория» и тексты
вступлений/завершений всех уровней RU/EN перекомпонованы для экрана DS.
Оригинальные слова, пунктуация и порядок сохранены; меняется только пробельная
разметка. README не содержит принудительных переносов после «зла,» и
«хозяев.»: весь первый смысловой абзац переносится по текущей ширине.

## Компоновка

`dok_frontend_text_prepare()` в UI-контроллере убирает DOS-переносы внутри
абзаца, крайние и повторные пробелы; несколько пустых строк заменяет одной.
В EINTRO1/2/3 исходные пустые строки между фрагментами одного предложения
также соединяются: например, «Теперь ей не вырваться из подземелий!».
Разделение абзацев в этих коротких завершениях сохраняется после . ! ?.
Предыстория и BINTRO сохраняют исходные смысловые границы пустых блоков.

Шрифт FONT8,30 столбцов,11 строк на странице, шаг строки12 пикселей.
Один пустой ряд между абзацами вместо исходных повторных пустых строк.
README начинается y28 после заголовка y8; BINTRO/EINTRO — с y8.
Подсказки y172, номер страницы y184. Последний глиф README заканчивается
на y155; подсказка отделена минимум16 пустыми пиксельными строками.
Исходный FON и музыка меню сохранены.

| Текст | RU: страниц | EN: страниц |
|---|---:|---:|
| Предыстория / README | 2 | 2 |
| BINTRO1 | 2 | 2 |
| EINTRO1 | 1 | 1 |
| BINTRO2 | 1 | 2 |
| EINTRO2 | 1 | 1 |
| BINTRO3 | 2 | 2 |
| EINTRO3 | 1 | 1 |

Разметка готовится in-place отдельно при расчёте количества страниц и при
отрисовке; оба пути используют одинаковую функцию. Изменения не затрагивают
исходные RES, пакеты оригинальных данных, HUD-сообщения или GBA/SDL2.
Адресация доказательств — ресурсы README/BINTRO1–3/EINTRO1–3 в PKR/PKE RES,
не адреса EXE, Ghidra или DPMI. Это намеренная адаптация UI к DS.

## Кнопка B

- Начальная заставка TITLE: B открывает главное меню, как A/Start.
- Вступление уровня INTRO: B с любой страницы возвращает в главное меню
  на «Начать игру», выдавая STOP_GAME; загрузки уровня не происходит.
  Подсказка прямо указывает «B: В меню» / B: Menu.
- Предыстория: B возвращает на предыдущую страницу, с первой — в меню.
- Завершение уровня OUTRO: B возвращает на предыдущую страницу;
  A после последней страницы открывает выбор уровня.

Release gate не позволяет удерживаемой B повторно пройти переход.
