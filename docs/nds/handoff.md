## Что принято и не должно потеряться

- Независимое восстановление по PKR/PKE, декомпиляциям, ASM и оригинальному
  поведению. GBA — исследовательский референс, не кодовая основа. Завершение
  других портов не является зависимостью. SDK — общий пользовательский, не в проекте.
- DS/DS Lite, DS mode, BlocksDS/libnds, отдельный подготовленный пакет на microSD.
- Верхний экран 256×192: исходные 320×200 трактуются как показ 4:3,
  а не квадратнопиксельные 8:5. Сцена 256×154 и DOS-HUD 256×38 сохраняют
  исходный обзор с округлением границы. Жизнь/заряд — числами, иконки слева.
- Низ — исследуемая карта без остановки игры, drag и кнопки «−», «+», «Центр».
  Масштабы 2/3/4/6/8, старт 3; drag отключает следование, «Центр» включает.
  DOS-раскрытие восстанавливается отдельно от GBA-веера.
- Все текстовые заставки: фон сверху, полный текст снизу с пагинацией RU/EN.
  Оригинальная стартовая заставка с надписями и музыкой обязательна.
  Статические картинки готовятся offline с правильным исходным аспектом показа.
- Крестовина — ходьба/стрейф, Y/A — левый/правый поворот, R — огонь,
  удержание L — бег, X/B — Use, Select — следующее доступное оружие,
  Start — пауза. Touch не вращает игровую камеру.
- RU-карты LEVEL1–3, общий профиль монстров, язык меняет локализацию, а не мир.
  Точные числа профиля — в плане/N05: бояре 81/86 HP42/speed20/wake9000,
  8C HP12, группа бояр N24, мыши N8, первая Баба-яга HP54/speed60/scale7/wake3400.
- Три независимых уровня, исходный retry и выходы; автоматической кампании нет.
  **Игровых сохранений нет**, включая autosave и восстановление после перезапуска.
  Записываются только настройки. «Продолжить» в паузе — текущая сессия в RAM.
- 30+ FPS трактуются как вывод через VBlank (~29,9); цель 60 — каждый VBlank.
  Ранние аппаратные замеры N07 и приёмка полной игры N23 обязательны.
  Аппаратный 3D разрешён, но исходные свет/вода/отражения не удаляются ради FPS.

## Проверка текущей документационной задачи

Выполнены чтение проектных правил и целевых источников, запись плана/паспортов
и локальная структурная проверка: число задач, статусы, совпадение зависимостей,
порядок без циклов, наличие источников/Markdown-ссылок и разделов handoff.
Проверка изменений: `git diff --check`; обзор состава: `git status --short`.
Игровые тесты и NDS-сборки к этой задаче не применимы и не заявляются выполненными.
Все планируемые outputs паспортов помечены как ещё не созданные.

Фактический итог: **26 Markdown-документов NDS, 24 паспорта, 366 проверенных
локальных ссылок, 24 согласованные строки зависимостей; циклов нет**.
`git diff --check` прошёл. Новые Markdown-файлы дополнительно проверяются
через `git diff --no-index --check` относительно пустого файла, поскольку
обычный `git diff` не включает ещё не отслеживаемые файлы.

Для повторения структурной проверки из корня репозитория (PowerShell):

```powershell
$OutputEncoding = [System.Text.Encoding]::UTF8
@'
from pathlib import Path
import re
base = Path('docs/nds')
tasks = sorted((base / 'tasks').glob('N*.md'))
assert [p.stem for p in tasks] == [f'N{i:02d}' for i in range(1, 25)]
plan = (base / 'plan.md').read_text(encoding='utf-8')
rows = re.findall(r'^\| \[(N\d{2})\]\(tasks/\1.md\) \| .*? \| (.*?) \| не начата \|$', plan, re.M)
assert len(rows) == 24
for ident, raw in rows:
    deps = set(re.findall(r'N\d{2}', raw))
    body = (base / 'tasks' / f'{ident}.md').read_text(encoding='utf-8')
    declared = re.search(r'\*\*Зависимости:\*\* (.*)', body).group(1)
    assert deps == set(re.findall(r'\[(N\d{2})\]', declared))
    assert all(int(d[1:]) < int(ident[1:]) for d in deps)
    assert 'Статус: **не начата**.' in body
    assert '## Обязательный handoff' in body
    assert 'Планируемые результаты, сейчас не созданы' in body
links = 0
for p in [base / 'plan.md', base / 'handoff.md', *tasks]:
    for target in re.findall(r'\[[^\]]+\]\(([^)]+)\)', p.read_text(encoding='utf-8')):
        if target.startswith(('https://', 'http://', '#')):
            continue
        assert (p.parent / target.split('#')[0]).exists(), (p, target)
        links += 1
print(f'OK: {len(tasks)} tasks, {links} local links, no dependency cycles')
'@ | C:/Source/wasdify/.venv/Scripts/python.exe -
```

Использован существующий Python из общего исследовательского окружения;
команда `python` в PATH оказалась неработающим Microsoft Store alias.
SDK или Python ради фиксации документов не устанавливались.
