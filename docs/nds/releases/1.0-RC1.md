# Dungeons of Kremlin — Nintendo DS 1.0-RC1

«Подземелья Кремля» для Nintendo DS и DS Lite: три уровня, оригинальная
графика, противники, оружие, звуки и музыка.

## Особенности порта

- Вся игра в одном `.nds`-файле — дополнительные папки с ресурсами не нужны.
- Русский и английский языки в одной сборке. Язык можно переключать
  в главном меню и во время паузы.
- Игра и показатели здоровья, боеприпасов и ключей — на верхнем экране;
  карта — на нижнем.
- Карту можно перемещать стилусом, приближать и отдалять. Кнопка «Центр»
  возвращает слежение за героем.
- Две схемы управления: современная со стрейфом на крестовине
  и классическая с поворотами на крестовине.
- Прямое управление без инерции, бег, стрейф и переключение оружия.
- Выбор уровня, пауза, предыстория, вступления и завершения уровней.
- Музыка главного меню продолжает играть при переходах между его разделами.
- Счётчик FPS можно показать или скрыть кнопкой Select.
- Язык и схема управления запоминаются между запусками, если доступна
  запись настроек. Сохранений прохождения нет.

## Управление

| Действие | Современная схема | Классическая схема |
|---|---|---|
| Вперёд / назад | Крестовина вверх / вниз | Крестовина вверх / вниз |
| Поворот влево / вправо | Y / A | Крестовина влево / вправо |
| Стрейф влево / вправо | Крестовина влево / вправо | L / R |
| Стрельба | R | Y |
| Бег | Удерживать L | Удерживать B |
| Двери и действие | X | X |
| Следующее оружие | B | A |
| Пауза / продолжить | Start | Start |
| Показать / скрыть FPS | Select | Select |

В меню: крестовина — выбор пункта, A — подтверждение, B — назад.
В текстах A открывает следующую страницу, B возвращает на предыдущую.
