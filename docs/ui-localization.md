# HUD, меню и локализация G17

**Актуальный вид HUD после уточнений пользователя 26 октября:**
[компактные панели, оригинальные иконки/рамки, зелёный текст](ui-hud-refresh.md).
W/L и hex-маска ключей убраны. Ключи показываются иконками при наличии.
Приведённые ниже геометрия HUD и цвета darkest/brightest описывают историческую
проверку G17; обновление имеет отдельные ROM и отчёты. Полноценная заставка
и главное меню остаются в [бэклоге UI01](gba-backlog.md).

Проверено 26 октября 2026 года. Итог — единый RU/EN ROM с настоящими
`FONT8/FONT16`, числовым HUD, стартовым меню, паузой, справкой, показателями
и уведомлениями предметов, дверей и завершённой смерти монстров.
Историческая граница G17: новая игра, жизнь/смерть героя, переходы и финал.
Актуальная реализация G18 и изменённые пункты титульного меню описаны в
[game-flow.md](game-flow.md); ниже сохранено доказательство исходного G17 UI.

## Исходные образцы и доказательства

Адреса ниже — **адреса NE-загрузчика Ghidra**, не файловые смещения,
не индексы NE-сегментов и не runtime-селекторы DPMI.

| Образец | SHA-256 до и после Ghidra |
|---|---|
| `originals/pkr/RUS/PKR.EXE` | `12f78afc0eba05f76b5dc0bb99da38d7daa20585024c0ba958fe828aa3864d28` |
| `originals/pkr/ENG/PKE.EXE` | `cce7bc5993d0734ad87e93db37a70b8b52faedfff14ac48d6e317e5ac996a37b` |

`scripts/analyze-ui.ps1` запускает `InspectUI.java` read-only в сохранённых
`build/ghidra/{ru,en}/Kremlin.gpr`. Свежие листинги, бинарные NE-блоки,
отдельный автоматический **непроверенный** C, журналы и манифесты находятся
в `build/ui/{ru,en}/`. Автоматический C не входит в модули движка.

| Назначение | RUS | ENG |
|---|---|---|
| Глиф, clipping, transparent/opaque | `1058:0158` | `1018:153E` |
| Строка, шаг символа, CR/LF/`$` | `1058:02AC` | `1018:1692` |
| HUD и dirty flags | `10C0:0BA1` | `1050:0F04` |
| Копирование уведомления | `10C0:1278` | `1050:15DB` |
| Удаление уведомления по счётчику | `10C0:12D0` | `1050:1633` |
| Центрированный текст/ожидание ввода | `10C0:155D` | `1050:18C0` |
| Стартовый выбор уровня | `1008:02F7` | `1008:044B` |
| Предмет: сообщение `+58` | `1068:2F8A` | `1020:362D` |
| Завершённое открытие/закрытие двери | `1068:3262/334E` | `1020:3917/3A03` |
| Запертая дверь, выбор ключа | `1068:347E` | `1020:3B33` |
| Завершение смерти, текст `+BE` | `1068:3E8D…3EC2` | `1020:45F6…462B` |

Листинг глифа проверяет `LES` для объекта/ROM-шрифта, `IMUL` высоты на
unsigned byte символа, `CBW` байта строки, маски MSB→LSB, signed32 clipping
через `JG/JL`, far-вызов pixel operation и `RETF` с caller cleanup.
Оригинальный объект хранит far font pointer по `+1A`, высоту по `+24`,
foreground/background по `+1E/+20`, clip bounds по `+38…+44`.
Маски `128,64,…,1` находятся в RUS `1190:04D4`, ENG `10D0:04DC`.
`FONT8` — 2048 байт, `FONT16` — 4096: 256 CP866-глифов по8/16 строк,
ширина8. Оба шрифта берутся из исходного RES, без растрирования системным
шрифтом и без дублирования payload в ROM.

Оригинальное уведомление копирует **38 байт** в HUD `+2C`, дополняет пробелами
после NUL, ставит NUL в `+52` и dirty bits `|22`. Строковый formatter отдельно
понимает LF/CR/`$`; это не означает, что его форматирование требуется для
каждого fixed-span сообщения LEVEL. Парсер LEVEL сохраняет до39 исходных байт;
фактический максимум сообщений RU —36, EN —33, поэтому различие38/39 в этих
образцах не меняет видимый текст.

Набор подтверждённых исходных экранов включает стартовый выбор уровня1–3,
показ игрового HUD, сообщения и центрированные заставки/ожидание клавиши.
DOS-конфигурация видеорежима и устройств также присутствует в startup;
GBA использует фиксированный экран и собственные кнопки. Игровые заставки,
новая игра/выбор этапа, смерть героя и завершение относятся к G18.
Названия пунктов и геометрия GBA-меню — решения порта; побайтовая эквивалентность
всех DOS-экранов не заявляется.

## Экран GBA и доступные действия

Сцена сохраняет **240×144**, x0…239/y0…143,120 независимых колонок.
UI рисуется в полных240 пикселях. Вся полоса **240×16**, y144…159, отдана
двум строкам по30 глифов `FONT8`. Без активного уведомления полоса пустая.
Собственной нижней панели показателей нет.

HUD использует контрастный фон и значения текущего player:

| Позиция | Содержимое |
|---|---|
| Слева сверху, x2/26 y2 | `HP`, signed здоровье, до6 символов |
| Справа сверху, x162/178 y2 | `E`, signed заряд, до6 символов |
| Слева снизу сцены, x2/10 и66/74 y134 | `W` номер оружия, `L` жизни |
| Справа снизу сцены, x186/202 y134 | `K` и четыре hex-цифры маски ключей |

`K0001/0002/0004/0008` — медный/железный/золотой/секретный ключ.
Экран показателей содержит легенду, максимальные жизнь/заряд, очки и флаг
открытия карты. Там нет обещания уже реализованного полноэкранного automap.
Числа `-32768/32767` и маска `FFFF` проверены без пересечения и обрезки.
Буквенные сокращения HUD одинаковы в обоих языках; меню и сообщения переведены.

На старте четыре пункта: «Продолжить», «Язык», «Управление», «Показатели».
В паузе добавляется «Главное меню». Фокус виден как инвертированная строка.
Заголовки используют `FONT16`, остальные подписи — `FONT8`.
В G17 «Продолжить»/Start **сохраняет уже созданный мир**, включая возврат
через главное меню. Это ещё не reset/new-game action G18.

| Режим | Кнопки |
|---|---|
| Игра | D-pad: движение/поворот, A: огонь, B: бег, L/R: шаг вбок |
| Игра | L+R: следующее оружие; Start: Use; Select: без смены языка |
| Игра | **Start+Select: пауза**, Use и смена языка подавлены для chord sample |
| Меню | Up/Down: циклический выбор; A/Start: выполнить |
| Стартовое меню | Select: язык; B не выходит в игру |
| Пауза | B/Select: вернуться в игру; язык меняется выбранным пунктом |
| Справка/показатели | B/Select/Start: назад в родительское меню |

Кнопка, закрывшая меню, блокируется до отпускания: удержание A не начинает
стрельбу, Start не передаёт Use. После паузы не появляется накопленный ввод.
Одновременный chord заменяет прежний диагностический Start+Select panic.

## Уведомления и локализация

`src/ui.c` не получает mutable world pointer. Изменяются только UI state и
ссылка на текущий language view. Числа, карты, общий balance и всё mutable
состояние33864 байта сохраняются при смене языка. Оригинальные RU/EN views
проверяются отдельно; различия исходного баланса не становятся переключателем.

Предметы используют настоящий sink `DOK_ITEM_PICKUP` и field `+58`;
`DOK_AI_DEAD` показывает `+BE` после последнего death interval и corpse cleanup.
Начало смерти не выдаёт сообщение преждевременно. Doors emit открытие/закрытие
и locked key requirement. Неподдержанные действия не получают выдуманного
сообщения. Class6 остаётся восстановленным no-op; FINISH ждёт G18.

Четыре ожидающих message identity `(object, native field offset)` и одна
активная identity образуют ограниченную очередь. При перегрузке удаляется
самое старое **ожидающее** сообщение. Текст разрешается из выбранного
ROM view при показе, поэтому язык меняется и у уже активного сообщения.
Строки не копируются в mutable world.

Оригинальные сообщения дверей извлечены из data NE-блоков. RUS `1190`:
`058C/059D` — открылась/закрылась, `05AE/05C1/05D6/05EA/05FB` — ключи.
ENG `10D0`: `059C/05A7`, `05B4/05CA/05DE/05F4/0601` соответственно.
`src/ui_native_text.inc` сохраняет точные CP866 байты, включая исходное
`COOPER KEY IS NEEDED`. Это не поле `door+60`: native `door+62` — временный
far pointer на выбранную константу. В порт не переносится runtime selector.

Политика GBA: фиксированный перенос после30 глифов, две строки/60 байт
на страницу, максимум240 байт, до4 страниц. Контрольные байты<32 выводятся
как пробелы. Страница держится30000 simulation ticks, около2,992 с;
меню останавливает её clock. Длинные строки не обращаются за frame или текст.
Это адаптация, а не восстановление DOS-счётчика срока сообщения.

## Пауза, память и измерения

Timer2/3 продолжают работать для profiler; при паузе сохраняются ticks и
rational remainder, hardware previous обновляется. На входе/выходе счётчик
ресинхронизируется, поэтому paused wall time не попадает в simulation debt.
Scheduler deadlines, AI, двери и движение сохраняют своё время. PCM/DMA1 и
Timer0/1 продолжают текущий голос; пауза UI не перезапускает звук.

ROM `build/g17/dok-diagnostic.gba`: **32876132 байта**,
SHA-256 `b63ae8087b6f4cff5f121bd919b982ecbf750a2d786c581ae85166c2f7b7aefb`.
До32MiB осталось678300 байт. ELF/map сохранены рядом.
EWRAM248564/free13580, прирост428 к G16. IWRAM20684/free3892 до8KiB
stack reserve: прежние HUD helpers удалены из IWRAM, новый UI исполняется
из ROM. Наблюдённый main stack2360/margin5576; IRQ80/margin80.
Новых VRAM bank, palette reserve или дополнительных framebuffer нет.
Цвета текста — darkest/brightest текущей игровой палитры.

Renderer regression:4735552…5222592 cycles. Разрешение/детализация сцены
не снижены. **30FPS не достигнуты**, оптимизация остаётся G20.

## Проверки и воспроизведение

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-gba-ui.ps1 -CrossChecks -OriginalEvidence
```

Pipeline составлен также из уже выполненных отдельных шагов; полный driver
одним вызовом не повторялся. Он выполняет host compile/tests, Linux static
и Thumb compile, ROM, read-only Ghidra/native x86, ARM UI и regression.
`-RegressionOnly -CrossChecks` использует готовые build/host artifacts.
`scripts/ui_copy.py` воспроизводит CP866 menu copy `src/ui_text.inc`.

`analysis/g17-review.json` связывает source/ELF/ROM/map и девять отчётов:

- Host: keypad/chord/held edges, queue overflow, timer wrap, corrupt span,
 240-byte cap и framebuffer guards всех пяти экранов×двух языков.
- Original x86: **2048** глифовых vectors, все256 символов двух шрифтов,
 clipping и transparent/opaque; **18** native message-copy vectors.
 Внешняя virtual pixel operation только записывает координаты; `LES`,
 font indexing, сравнения и far return исполняются оригинальным кодом.
- Независимый ARM UI: реальные кнопки, фокус/возврат, пауза и дробная часть,
 raw timer во время паузы, подавление Fire/Use, mutable world hash RU/EN,
 точные исходные `FONT8/FONT16` pixels, signed16 extremes, четыре страницы,
 реальные item pickup и полная смерть монстра с `+BE` на обоих языках.
- Actual PNG обеих локализаций в `build/g17/ui-check/` визуально проверены;
 SHA и заключение — `analysis/g17-visual-review.json`.
- Renderer/reset/guards, interactions/Start/sensors/conveyors/FINISH,
 rational active clock600VBlank/reset,28 AI combat variants и capture
 всех23 PCM прошли на этом ROM; underruns0.

Legacy harnesses явно пропускают титульное меню через test mailbox.
UI harness сохраняет настоящий boot и управляет кнопками. Clock regression
вычитает один постоянный excluded raw counter, затем проверяет точное
rational отношение всех активных samples. Первая штатная simulation update
предшествует snapshot: native startup parameter98 меняется1→-1 независимо
от языка. `DOK_PROBE_FAST_VIDEO=1` откладывает только Python RGB conversion;
ARM rasterization и raw video callback продолжаются, PNG конвертируются
из фактического кадра при сохранении.

Test ABI: `g_ui_probe` — uint32 `request,ack,op,arg,object,slot`; request пишется
последним. Op1: state0play/1title/2pause/3help/4stats; op2: language0/1;
op3: message object/slot; op4: stress length, cap240, byte`A+i%26`;
op5: UI-only tick(arg), без изменения game clock. Object`FFFE`, slots0…6
обозначают door constants; `FFFF` — synthetic literal.
`g_ui_diag` —16 uint32: `magic=55493137,state,focus,language,messages,object,
slot,length,page,pages,remaining,draws,font8,font16,last_keys,errors`.
Pages нумеруются с0, font flags — boolean. Mailbox не является игровым вводом.

Физическая GBA, оригинальный BIOS и целая DOS-сессия не проверены.
Linux static/Thumb скомпилированы; запуск Linux/MSVC/CMake не выполнялся.
Слуховое подтверждение относится к принятой пользователем записи G16;
новый G17 аудиозахват проверен численно и не объявляется новым прослушиванием.
