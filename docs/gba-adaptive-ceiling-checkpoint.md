# Адаптивный низкий потолок: промежуточный результат

27 октября 2026. Исследовательская ветка, **не выбранный игровой ROM**.
Основной кандидат остаётся2775; G20/G20A/goal открыты.

`research/experiments/g20a-hw-adaptive-v2/hw_v128_low_adaptive/`, ROM
eacf37cdf67c051baca11e47b79f93e537f2b972eb506634432826292c5ae55c,
16 572 192B. Ветка использует coarse16×16 visibility estimate для выбора
Mode1/Mode2; geometry/coverage не урезаются. Mode1 сохраняет горячий CPU shader
низких потолков, Mode2 использует BG3 mask-only путь. UI переключается между
BG0 и native OBJ. Front DMA layout хранится отдельно от режима рисуемого кадра;
Mode4 сохраняет завершённый front. `HW_EDGE_RAM_CALL` выключен для IWRAM budget.

EWRAM261332/free812; IWRAM24476/free100 до прежнего stack reserve8192.
Полная проверка стеков и общего нового backend ещё не выполнена.

Измерения mGBA native clock с PCM:

- 18 выбранных PPU кадров: RGB и coverage exact относительно2775; здесь выбранMode1.
- Короткий live24 RU/EN:18,145/18,145/27,567 FPS по трём мирам.
  Это не полный turn120/walk120 результат.
- Spatial440: минимум11,945500/9,954583/14,931875 FPS. Mode2 выбран в43 видах.
  Во всех397 Mode1-видах фактический PPU SHA совпадает с2775.
  43 Mode2-вида имеют отличия изображения; отдельная проверка foreground/UI
  именно адаптивного пути ещё не заявляется.
- Против парного2775 spatial sweep:26 видов быстрее,66 медленнее,348 на той же
  ступени предъявления. Медианное отношение времени CPU trial/control по мирам:
  1,0138/1,0470/1,0095. Это **не общий выигрыш**.
- L1cell520225°:1 254 144cycles; L1cell3640225°:1 110 048cycles.
  Оба выбираютMode2; L2cell1592135°:1 537 152cycles, Mode1;
  L2cell2871225°:1 602 464cycles, Mode1; L3cell1544315°:929 536cycles, Mode1.

Отчёты: `research/experiments/g20a-hw-adaptive-v2/{exact18-live,target,spatial}.json`.
Coarse estimator добавляет заметную геометрию; его цена пока съедает часть
целевого выигрыша. Допустим один ограниченный опыт более дешёвого выбора,
после чего при отсутствии общего выигрыша ветку откладывать. Не продвигать
этот ROM в artifacts по локальному улучшению двух L1-видов.

Продолжение: ограниченный опыт выполнен, **адаптивная ветка отложена**.
`research/experiments/g20a-hw-adaptive-grid4/hw_v128_low_grid4/` использует16 center samples
вместо256 visibility cells. Spatial440:15 видов быстрее,62 медленнее,363 равны
по FPS относительно2775; минимумы9,954583/9,954583/14,931875. Медианные отношения
CPU trial/control:1,0206/1,0293/1,0095 по мирам. Mode2 выбран в21 виде; все419
Mode1 PPU SHA exact.18 обычных кадров exact; live24 RU/EN18,616/18,616/27,567.
Дешёвый выбор снизил часть накладных расходов, но потерял полезное переключение
L1cell520225° и не дал общего выигрыша. Отчёты `{spatial,exact18-live}.json`
в указанном build-каталоге. ROM в artifacts не копировался.

Отдельный аудит `scripts/analyze_gba_obj_candidates.py` на2775 исследовал17
видов: пять тяжёлых и по четыре стартовых направления каждого мира. Нулевой
набор простых opaque64×64 OBJ candidates. Непрозрачные wall rectangles имеют
источник96×192 и/или crop; большинство остальных прямоугольников masked.
Это отвергает только самый простой односоставной путь без разбиения исходников,
не hardware OBJ-архитектуру вообще. Воспроизводимый отчёт:
`research/experiments/g20a-hw-obj-candidates.json`; площади bounding boxes — верхние оценки,
перекрытия/невидимость не вычитались, прогноз FPS по ним не делается.

Текущие проверки не заменяют396 detail, warm Mode1/Mode2 transitions, water,
AI/combat/items/time/stress. Water harness для этого опыта требует учитывать
compact single-frame layout внутри dual-frame slot; старое определение только
по отсутствию `hw_bg_frames` неверно. Прежняя294 Pause/Resume проблема baseline
также остаётся открытой. Физической GBA и оригинальной BIOS в проверке нет.

Аппаратный и архитектурный резерв разобран в [аудите](gba-hardware-audit.md).
