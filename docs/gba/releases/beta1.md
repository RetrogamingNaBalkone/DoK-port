# Dungeons of Kremlin — GBA Beta 1

Первая публичная бета GBA-порта «Подземелий Кремля» для плейтеста.
Порт — **Ретрогейминг на балконе / Retrogaming Na Balkone**.
Оригинальная игра — **NewCom, Москва, 1995**; авторы трёхмерной технологии —
Александр и Андрей Разбаковы, художник — Дмитрий Цирухин.

## Что входит

- Три независимо выбираемых уровня: «Хоромы нечисти», «Подземная река»,
  «Подвалы Кремля».
- Русская и английская локализации в одной ROM; язык выбирается в меню.
- Игровой цикл с оружием, противниками, предметами, ключами, дверями,
  повторами после смерти и завершением уровней.
- Карта на Select с прокруткой и возвратом к герою. Предметы и противники
  отображаются после подбора карты уровня.
- Исходные заставка, музыка, звуки и предыстория.
- Раздел «Об авторах» / Credits: авторы оригинала и GBA-порта на двух экранах.

В сборку включены последние исправления попаданий лазера вблизи,
переносов текста, щелей пола и оптимизации отрисовки бочек и низких потолков.

## Запуск и управление

Скачайте **`Dungeons.of.Kremlin.Beta1.gba`** и откройте ROM в эмуляторе GBA
либо запустите с совместимого флеш-картриджа. Отдельные файлы данных для
готовой ROM не нужны. Проверка на физической GBA пока не проводилась.

| Кнопки | Действие |
|---|---|
| Крестовина | Движение и поворот |
| A | Огонь |
| B | Бег |
| L / R | Шаг вбок |
| L + R | Смена оружия |
| Start | Действие / открыть дверь |
| Select | Карта |
| Start + Select | Пауза |

В меню A/Start подтверждают выбор; B возвращает назад. На текстовых экранах
A/Start листают вперёд, B — назад; Select меняет язык.

## Статус и ограничения

- Это **pre-release для тестирования**, не финальный релиз.
- Стабильные 30 FPS пока не достигнуты. В тяжёлых сценах, особенно с низкими
  потолками и большим числом объектов, возможны заметные просадки скорости.
- Игровых сохранений нет. «Продолжить» доступно в паузе текущей игры;
  «Начать игру» создаёт новый мир выбранного уровня.
- Проверены в mGBA все три уровня на обоих языках, переходы игрового цикла,
  смерть/повтор/Game Over, меню, карта и локализация. Для текущей ROM отдельно
  прошли flow/UI/story/credits/frontend/latency, включая 54 выхода из титров
  и два повтора музыки без underrun. Повторная сборка ROM побайтно совпала.
- Полное ручное прохождение, физическая GBA и оригинальный BIOS ещё не проверены.
  Эмуляторные проверки не подтверждают производительность реального устройства.

Если встретится ошибка, приложите язык, уровень, место, шаги воспроизведения
и название эмулятора или устройства к [issue в репозитории](https://github.com/RetrogamingNaBalkone/DoK-port/issues).
