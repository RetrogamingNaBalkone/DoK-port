# Подземелья Кремля 1.0

Полноценный GBA-порт **Dungeons of Kremlin / «Подземелья Кремля»**:
все три уровня, русский и английский языки в одной ROM.

Порт — **Ретрогейминг на балконе / Retrogaming Na Balkone**.
Авторы оригинальной игры, указанные в её титрах:

- **Александр Разбаков и Андрей Разбаков** — авторы трёхмерной технологии.
- **Дмитрий Цирухин** — художник.

**© NewCom, Москва, 1995.**

## Что нового после Beta2

- Переработано окно попыток: «ПОПРОБУЙ СНОВА» и количество оставшихся
  попыток по центру, без повторного сообщения и лишнего счётчика страниц.
- Подсказка B теперь прямо указывает переход в меню.
- Исправлен возврат старого окна смерти из паузы после повтора попытки
  или начала новой игры.
- Исправлено английское название в главном меню: **Dungeons of Kremlin**.
- Английские названия уровней сохранены из DOS-оригинала; тексты начала
  и окончания всех трёх уровней побайтно совпадают с оригинальными ресурсами.

Версия сохраняет улучшения Beta2: исправленное точное наведение на врагов,
оптимизацию перестрелок и отрисовки, обновление экрана в VBlank,
QR-код и ссылку на канал автора порта. Разрешение сцены — 120×128.

## Запуск

Скачайте **`Dungeons.of.Kremlin.1.0.zip`**, распакуйте архив и откройте
**`Dungeons.of.Kremlin.1.0.gba`** в эмуляторе GBA либо запустите
с совместимого флеш-картриджа. Отдельные файлы данных не нужны.
В архиве также находятся README и контрольная сумма ROM.

| Кнопки | Действие |
|---|---|
| Крестовина | Движение и поворот |
| A | Огонь |
| B | Бег |
| L / R | Шаг вбок |
| L + R | Смена оружия |
| Start | Действие / открыть дверь |
| Select | Карта |
| Start + Select | Пауза |

В меню A/Start подтверждают выбор. В окне попыток A/Start продолжают игру,
B открывает главное меню. На страницах текста A/Start листают вперёд,
B возвращает назад, Select меняет язык.

Если встретится ошибка, укажите язык, уровень, место, шаги воспроизведения
и эмулятор или устройство в [issue](https://github.com/RetrogamingNaBalkone/DoK-port/issues).
