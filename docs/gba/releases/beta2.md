# Dungeons of Kremlin — GBA Beta2

Вторая публичная бета GBA-порта «Подземелий Кремля», сборка G22.
Все три уровня, русский и английский языки в одной ROM.
Порт — **Ретрогейминг на балконе / Retrogaming Na Balkone**.
Оригинальная игра — **NewCom, Москва, 1995**.

## Исправления и улучшения после Beta1

- Перенесены обновление экрана и перенастройка графического DMA в VBlank.
  Это устранило зависание Beta1 в контрольной проверке на GBA с EZFlash
  Omega Definitive в режиме Clean Boot.
- Исправлены промахи при точном наведении на летучих мышей и других
  противников. Исправление работает для ружья и бластера; урон, скорость
  снарядов и расход боеприпасов сохранены.
- Ускорены массовые перестрелки: оптимизированы поиск попаданий снарядов
  и отрисовка оружия. Особенно заметен выигрыш в комнатах с ключами
  и большим числом противников на втором и третьем уровнях.
- Ускорена отрисовка потолков и прозрачных поверхностей. Сборка G22
  сохраняет разрешение сцены 120×128, карты, противников и игровые правила.
- Обновлена вторая страница «Об авторах»: добавлены QR-код и ссылка
  на канал автора порта, на русском и английском языках.

## Запуск и управление

Скачайте **`Dungeons.of.Kremlin.Beta2.gba`** и откройте ROM в эмуляторе GBA
либо запустите с совместимого флеш-картриджа. Отдельные файлы данных не нужны.

| Кнопки | Действие |
|---|---|
| Крестовина | Движение и поворот |
| A | Огонь |
| B | Бег |
| L / R | Шаг вбок |
| L + R | Смена оружия |
| Start | Действие / открыть дверь |
| Select | Карта |
| Start + Select | Пауза |

В меню A/Start подтверждают выбор, B возвращает назад. На текстовых экранах
A/Start листают вперёд, B — назад, Select меняет язык.

## Особенности беты

- Частота кадров зависит от сцены; в насыщенных боях возможны замедления.
- Игровых сохранений нет. «Продолжить» доступно в паузе текущей игры;
  «Начать игру» создаёт новый мир выбранного уровня.
- Beta2 прошла автоматические проверки в mGBA. Аппаратная проверка
  исправления зависания относится к предшествующей VBlankOnly-сборке;
  итоговая Beta2 отдельно на физической GBA пока не проверена.

Если встретится ошибка, укажите язык, уровень, место, шаги воспроизведения
и эмулятор или устройство в [issue](https://github.com/RetrogamingNaBalkone/DoK-port/issues).
