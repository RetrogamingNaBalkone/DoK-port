# G14: AI: обнаружение и перемещение

## Контекст нового чата

Рабочий корень: `C:\Source\DoK-port`. Сначала прочитать `AGENTS.md`,
`docs/gba/plan.md`, `docs/gba/handoff.md`. Главная цель — GBA; SDL2 не является
зависимостью. Этот паспорт не предполагает доступности предыдущей переписки.

**Зависимости:** G13. Проверить их фактические результаты в плане и файлах.
Выполнять только границы этой задачи; соседние задачи — отдельные чаты.

Вход после G13: [combat.md](../combat.md), `analysis/gba/g13-review.json`, общий
ROM `build/gba/g13/`. `dok_combat_spawn` принимает owner object ID и template glyph;
same-class immunity, flight/damage/impact/cleanup уже реализованы. WAKE сообщает
первый контакт sleeping state 0 без вычитания health; DAMAGE/DEATH/RECLAIM
разделены. G14/G15 должны подключить consumers, а не подменять AI переходы
visual completion. RECLAIM обязан снимать будущие AI owners до повторного
использования glyph slot. Dynamic occupancy хранится отдельно от static MMap
и подключена через borrowed collision overlay для одного активного GBA world.
Перед уничтожением его context нужно вызвать `dok_collision_overlay(0,0,0)`;
при смене уровня production adapter устанавливает context заново. Object 36,
player 60 и ARM runtime 33864 не изменились. EWRAM после G13 — 239416 байт,
свободно 22728; IWRAM 23980, до stack reserve остаётся 596 байт. Новые холодные
функции размещать в ROM. Performance до 30 FPS не доведена; это остаётся G20.

## Реализация

Перенести обнаружение и навигацию монстров в переносимый C и GBA-runtime. Определить источник случайности, состояние RNG и возможность повторить сценарий. Боевые переходы согласовать с интерфейсом будущего G15.

## Критерии готовности

Монстры активируются и меняют курс по проверенным условиям; трасса воспроизводится при том же seed/input. RUS/ENG LEVEL1 сохраняют разные параметры. Проверены заблокированное движение, границы и повторный glyph.

Проверки выбирать по реальным рискам задачи. Сравнение C/Python полезно, но само
по себе не доказывает совпадение с работающей DOS-игрой. Если тест или запуск
не выполнен, указать это явно и не отмечать соответствующий критерий готовым.

## Результат

Выполнена 26 октября 2026 года. Спецификация и доказательства:
[ai-movement.md](../ai-movement.md). Код — `ports/gba/src/ai.c`, `ports/gba/include/dok/ai.h`,
`ports/gba/platform/ai_probe.c`; combat WAKE/RECLAIM подключены к production sink.
Обнаружение вызывается для рассматриваемого renderer объекта, не глобально;
GBA использует предыдущий consideration lease в simulation time. Строгий
Chebyshev-порог, native coarse heading, десять проб полуклетки, N+1 course
counter и исходный AI-разгон перенесены. RNG в этих ветвях нет.

Ghidra C/ASM/binaries/manifests — `research/evidence/ai/{ru,en}/`, EXE SHA до/после совпали.
На язык исполнены 1049 native heading, 200 getter/threshold и 25 counter
vectors. Полный callback и FPU ctor не эмулировались целиком; внешние abs/wake
границы перехватывались. Host пересобирает оба исходных RES, сохраняет разные
LEVEL1 трассы RU `d5b9deed` / EN `97ed0ec7`; общий согласованный release
profile даёт `a20c2856` в обоих языках. Повторные traces, четыре world corners,
CONTACT без motion, removal/reuse и настоящий combat RECLAIM прошли.

Windows suites, Linux static и Thumb compilation прошли. ARM проверяет 40
proximity edges, повторное и заблокированное движение, повторный glyph,
живой consideration wake и корректное displayed image до первого callback;
дополнительно actual combat WAKE и RECLAIM. Renderer/язык/reset/guards/stack,
door/sensor/conveyor/FINISH и rational clock regressions прошли.

ROM/ELF/map/PNG — `build/gba/g14/`, ROM 32861724 байта, SHA-256
`9b4a9a28634fa5dbcb6ce15e74acf681c8bae7c91349c7da86f705d3b7e62926`.
EWRAM 247800/free 14344; IWRAM 23980, до stack reserve 596 байт.
Object 36/player 60/runtime 33864 сохранены. Scheduler AI использует 128
owners по actor_index; экономия относительно 256 owners — 7680 байт.
Main stack 2360/margin 5576; static regression 4668231…4690291 cycles.
30 FPS не достигнуты, оптимизация остаётся G20.

Команда: `powershell -NoProfile -ExecutionPolicy Bypass -File ports/gba/scripts/build-gba-ai.ps1 -CrossChecks -OriginalEvidence`.
Части pipeline выполнены отдельно; aggregate — `analysis/gba/g14-review.json`.
Полная DOS-сессия, физическая GBA/оригинальный BIOS, Linux/CMake/MSVC execution
не проверялись. Exact DOS render/event interleaving не заявляется.
Следующая задача — **G15**, боевые состояния, hurt/attack/death и completion.
