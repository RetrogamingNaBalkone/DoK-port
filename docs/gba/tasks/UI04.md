# UI04: английское название игры

3 ноября 2026. По исправлению пользователя английское название —
**Dungeons of Kremlin**, в главном меню `DUNGEONS OF KREMLIN`.
Прежнее `KREMLIN DUNGEONS` ошибочно.

Прочитаны GBA plan, handoff, UI03. Основа — UI03 / g22_split_active,
120×128. Изменяются строка генератора ui_copy.py, ui_text.inc и ожидаемый
текст в verify_ui_gba.py. Оригиналы, игровая логика и другие порты вне задачи.
19 символов по 8 px (152 px) помещаются с прежним отступом x16.

Проверки: штатная host/Linux/Thumb/ROM-сборка, проверка UI в mGBA,
исходные FONT16 pixels и визуальный просмотр английского главного меню.
Готовая ROM — artifacts/gba/DoK-port_UI04.gba, включает UI03.
Физическая GBA не проверяется. Следующий основной ID остаётся G21.

Статус: готово, 3 ноября 2026.

## Команды и результат

```powershell
py -3.14 -X utf8 ports/gba/scripts/ui_copy.py
py -3.14 -X utf8 ports/gba/scripts/build_gba_frontend.py --out build/gba/ui04-title --variant g22_split_active
py -3.14 -X utf8 ports/gba/scripts/verify_ui_gba.py --build-dir build/gba/ui04-title/hardware/g22_split_active --report build/gba/ui04-title/ui.json
```

Host-тесты, Linux/Thumb-компиляция и сборка ROM прошли. Полная штатная
UI-проверка в mGBA прошла: исходные шрифты, меню RU/EN, управление,
пауза, локализация, HUD, сообщения и границы буферов. Английский заголовок
проверен попиксельно по исходному FONT16; PNG просмотрен, обрезания нет.
Другие наборы `--verify` повторно не запускались: после UI03 изменена
только строка меню и её ожидаемый текст в проверке.
