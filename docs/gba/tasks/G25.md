## Исходная постановка

Оценка существующих 96 строк не зависит от G23. Расширенная атрибуция
depth/LIGHT нужна только для выбора области нового LOD потолка, а не для
начала всей задачи. Завершение реализации H04 не требуется.
Создана по запросу пользователя после G22.
**Приоритет: после G24 → G26 → G27**, по выбору пользователя сначала
проверяются способы сохранить изображение. Готовность H05 без G23 —
техническая независимость, а не указание выполнить её раньше этой очереди.

## Работа и проверки

Вести два независимых результата: H05 (уже реализованные 96 строк) и H09
(новый локальный LOD материала). Не смешивать глобальное изменение выборки
сцены с упрощением только потолка и не задерживать H05 ожиданием G23.
H05 может быть проверена первой без новой архитектуры; H09 — по шагам ниже.

1. По G23 выбрать ограниченную область/материалы, где sampling дорог и
   изменение не затрагивает силуэты, высоты, coverage и навигацию.
2. Подготовить отдельный кандидат с более редкой выборкой материала;
   ближний детальный путь сохранить. Не менять AI/leases, геометрию и время.
3. Сравнить с текущим exact-контролем и отдельным 96-row ориентиром:
   одинаковые frozen poses, cold/moving inputs, RU/EN, CPU/p95/FPS и память.
4. Оценить оба кандидата по нативным 240×160 кадрам и ходьбе/поворотам:
   полосы, швы, мерцание, решётки, мыши, предметы и дальние цели. Малый RGB diff
   сам по себе не доказывает качество, а большой diff не является отказом.
   Проверить заметность целей/предметов, прицеливание, ориентацию и комфорт
   движения. Видимое, но незначительное ухудшение допустимо; описать его явно.

## Готовность и передача

По решению пользователя 2 ноября 2026 года G25 — последняя задача текущего
цикла оптимизаций. Пользователь прошёл игру ещё без оптимизаций; после G25
не создавать продолжение исследований FPS без нового запроса. Это не
закрывает отдельные баги и релизную приёмку.

Сохранены prototype defines/SHA, измерения, визуальные доказательства и решение
принять/отклонить конкретный вариант. Если выигрыш не оправдывает существенное
ухудшение игрового опыта — остановиться; не нужен заданный процент.
Не отклонять только за несовпадение текстур или пикселей. Для принятого варианта полный
G20D/G21 regression; физическую проверку указывать только при выполнении.
Обновить паспорт, бэклог, аудит и GBA-handoff. G26/G27 по принятому порядку
уже рассмотрены; следующий ID определяется оставшимися результатами бэклога.
Выходы — `build/gba/g25/`, `research/evidence/gba-g25/`, `docs/gba/` и
сводка по report policy. Пользовательская сборка только в `artifacts/gba/`.
Не создавать отдельный Performance-продукт; G21/BUG02 и NDS/SDL2 не закрывать.
