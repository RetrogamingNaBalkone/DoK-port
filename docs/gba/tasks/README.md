# Паспорта задач GBA

Общий реестр и зависимости: [gba-plan.md](../plan.md).
Текущее состояние: [handoff.md](../handoff.md).

Указание пользователя 24 октября 2026 года: выполнять этапы последовательно
без остановки между ними, при необходимости привлекать субагентов.
После завершения паспорта обновлять результаты и сразу выбирать следующий
этап по зависимостям. Старое указание в паспортах о соседних задачах
«в отдельных чатах» не требует завершать текущий чат: границы результата
и проверки сохраняются, новый запрос пользователя не нужен.

Каждый файл G00–G21 — отдельное задание для нового чата. Сначала читать
корневой `AGENTS.md`, план и handoff, затем выбранный паспорт. Его зависимости
должны быть выполнены либо явно заменены согласованным результатом.

Для запуска достаточно написать:

```text
В C:\Source\DoK-port выполни задачу G01 из docs/gba/tasks/G01.md.
Сначала прочитай AGENTS.md, docs/gba/plan.md и docs/gba/handoff.md.
В конце обнови документацию, статус задачи и передачу контекста.
```

Не просить пользователя пересказывать предыдущие чаты, если сведения уже
сохранены в проекте. При нехватке доказательств сначала исследовать указанные
входы. Не запускать соседние задачи автоматически только ради объёма работ.

Общий критерий готовности: результат паспорта получен, проверки выполнены
либо их ограничения явно отражены в статусе, существенные выводы документированы,
команды воспроизводимы, оригиналы не изменены. Для выводов по EXE нужны адреса,
система адресации и доказательства; для GBA — реальные артефакты и измерения.

В конце паспорта вести короткий раздел «Результат»: фактические пути,
проверки, отклонения от плана. Центральный статус хранится в общем реестре.
