# G26: модель постоянных затрат аппаратного потолка — H10

**Статус: готова к началу.** Плановая очередь после G25, без технической
зависимости от её успеха. Создана по запросу пользователя после G22.

## Входы

Прочитать `AGENTS.md`, GBA `plan.md`, `gba-backlog.md`, `handoff.md`,
`performance-audit-20261101.md`, `g22-hypothesis-results.md`,
`gba-lowered-ceiling-trial.md`, `gba-adaptive-ceiling-checkpoint.md`,
`gba-architecture-selection.md`. Исторические grid/feedback уже проверялись.

`53fdf1b1b868effecfd68c8feb87ffb60bcc72190a4d01f38d8684a781860247`;
перед опытом сверить актуальный handoff и закрепить контроль.
Код в `ports/gba/platform/hardware_*.inc`, варианты —
`ports/gba/scripts/prototype_gba_bsp.py`; общий toolchain — `docs/building.md`.

## Работа

1. На текущем layout построить модель Mode1/Mode2: DMA/VRAM/OAM, UI,
   background transport, foreground, режимные переходы и VBlank budget.
2. Отделить постоянную цену от успешного HW raster и CPU fallback.
   Сопоставить модель с существующими paired measurements; при необходимости
   добавить узкие instrumented probes, не выдавая их за production CPU.
3. Предложить конкретное изменение transport/размещения, устраняющее измеренную
   причину проигрыша. Показать вместимость памяти, UI и расписания DMA.
4. При отсутствии решения закрыть задачу отрицательной моделью и оставить H10
   условно отложенной. Не повторять grid/threshold/feedback на прежнем transport.

## Условие открытия native-опыта

Модель указывает реальную экономию и допустимое размещение без сокращения
резерва стеков/игровых правил. Только после этого оформить паспорт native
forced A/B, переходов и auto selection. Успех модели ещё не принятие рендера.

## Готовность и передача

В `docs/gba/` есть модель с единицами, источниками, проверенными фактами,
неопределённостями и решением «открыть native / не открывать».
Обновить паспорт, бэклог, аудит и GBA-handoff; следующий ID — G27.
Промежуточные данные — `build/gba/g26/`, доказательства —
`research/evidence/gba-g26/`, compact summary по report policy.
Нет фиксированного FPS gate; аппаратную приёмку не подменять моделью.
Оригиналы, статусы G21/BUG02, NDS/SDL2 не менять.
