# UI02: канал автора GBA-порта и QR-код

## Постановка

1 ноября 2026 года. По запросу пользователя переделать вторую страницу
«Об авторах» по приложенному экрану порта «Поля Чудес»: QR слева, автор справа,
ссылка снизу. Адрес: `https://t.me/RetroGamingNaBalkone`.
Сохранить стиль «Подземелий Кремля», обе локали и прежнюю навигацию.

## Входы и границы

- Прочитаны `docs/gba/plan.md`, `gba-backlog.md`, `handoff.md`,
  `tasks/G20B.md`, `ui01-credits.md`.
- Реализация: `ports/gba/src/ui.c`, `ui_text.inc`, генератор `scripts/ui_copy.py`.
- Референс: изображение пользователя и `C:/Source/Wonderfield-gba/src/presentation.inc`
  (`gba_author`), генерация QR в `scripts/pack.py` того же проекта.
- Изменяется только страница автора GBA. ENDTXT, flow/navigation, игровая
  логика, оригиналы, NDS/SDL2 и параллельная оптимизация G22 вне задачи.
- QR генерируется на ПК, в ROM хранится статическая битовая маска.

## Проверки и критерии готовности

Собрать Windows host/Linux/Thumb и отдельную ROM. Проверить в mGBA обе локали,
все модули и защитное поле QR, независимо декодировать кадр до точного URL,
проверить исходный FONT8 и прежние переходы, музыку и восстановление меню.
Просмотреть PNG обеих локалей. Готовую ROM выдавать из `artifacts/gba/`.
Физическую GBA без фактического запуска не считать проверенной.

## Статус

Готово с проверкой в mGBA, 1 ноября 2026 года.

## Реализация и доказательства

- `src/ui.c`: вторая страница сохраняет заголовок, панель, зелёный FONT8
  и footer 2/2. QR V3 M расположен в (8,24), 111×111 px, поле 4 модуля,
  масштаб 3×3. Чёрный/белый выбраны из существующей палитры меню;
  имя справа в (128,40/72/88), ссылка по центру на y136.
- `ui_copy.py` воспроизводит локализованные строки и 106-байтовую QR-маску
  `src/ui_channel_qr.inc`. Использован тот же Nayuki 1.8.0 MIT, что в референсе.
  Генератор и независимый декодер jsQR 1.4.0 с лицензиями находятся
  в `ports/gba/scripts/vendor/`; сеть при сборке не требуется.
- `prototype_gba_bsp.py`: только добавление нового include в копирование
  и source manifest. Прочие изменения этого файла принадлежат параллельной G22.
- `verify_channel_qr.py` вызывается из прежней проверки flow: проверяет
  каждый пиксель QR/поля, исходные FONT8 и декодирует actual PPU callback
  независимым jsQR до точного адреса. PNG RU/EN просмотрены.

## Команды

```powershell
py -3.14 -X utf8 ports/gba/scripts/ui_copy.py
py -3.14 -X utf8 ports/gba/scripts/build_gba_frontend.py --out build/gba/ui02-channel --variant g20d_compact
$gbaAuthorBuild = 'build/gba/ui02-channel/hardware/g20d_compact'
py -3.14 -X utf8 ports/gba/scripts/verify_credits_gba.py --build-dir $gbaAuthorBuild --report build/gba/ui02-channel/credits.json
py -3.14 -X utf8 ports/gba/scripts/verify_story_gba.py --build-dir $gbaAuthorBuild --report build/gba/ui02-channel/story.json
py -3.14 -X utf8 ports/gba/scripts/verify_flow_gba.py --build-dir $gbaAuthorBuild --report build/gba/ui02-channel/flow.json
py -3.14 -X utf8 ports/gba/scripts/verify_frontend_gba.py --build-dir $gbaAuthorBuild --report build/gba/ui02-channel/frontend.json
py -3.14 -X utf8 ports/gba/scripts/verify_ui_gba.py --build-dir $gbaAuthorBuild --report build/gba/ui02-channel/ui.json
py -3.14 -X utf8 ports/gba/scripts/verify_frontend_latency.py --build-dir $gbaAuthorBuild --report build/gba/ui02-channel/latency.json
```

Windows host UI прошёл; Linux/Thumb скомпилированы. Credits: обе локали,
исходные ENDTXT/FONT8, точный URL с actual PPU, 54 выхода, B со второй
на первую, Select на обеих страницах, полное восстановление меню/палитры,
сохранение мира и непрерывность музыки. Story, flow всех шести миров,
frontend и latency прошли: 16 коротких нажатий, boot 10 кадров,
максимальная задержка UI 5 кадров; два повтора музыки без underrun.
Результат UI указан в компактном отчёте.
