# UI03: окно оставшихся попыток

## Постановка и границы

3 ноября 2026. Пользователь согласовал заголовок «ПОПРОБУЙ СНОВА»,
строку «Осталось 2 попытки» / «Осталась 1 попытка», центрирование блока,
удаление повторов и 1/1, подписи A: Продолжить / B: В меню.
Конец игры: один заголовок и A: В меню. B сохраняет переход в меню.
Обе локали; игровая логика, остальные текстовые экраны и оригиналы не меняются.

Проверка B → меню → новая игра → пауза → продолжить выявила старый
`resume=DEATH`: новая игра не очищала состояние возврата. В границы включён
сброс resume=PLAY при создании новой игры и продолжении после смерти;
иначе пауза возвращала окно смерти также после обычного повтора.
Оба пути включены в регрессионную проверку. Баланс и восстановление героя прежние.

## Входы

Прочитаны GBA plan, handoff, gba-backlog, G18, UI02; реализация ui.c,
ui_copy.py, flow_backend.c, проверка verify_flow_gba.py.
Основа — выбранная Beta2, вариант g22_split_active (120×128), без PERF04–06.
Существующие изменения очистки хранилища не принадлежат UI03.

## Проверки и готовность

Сборка host/Linux/Thumb и ROM. В mGBA проверить 2/1/0 попыток в RU/EN,
пиксели исходных шрифтов, отсутствие повторов и пагинации, A/Start и B,
сохранение состояния мира при продолжении. Просмотреть PNG.
Готовую ROM разместить в artifacts/gba/. Физическая GBA не проверена.

## Статус

Готово, 3 ноября 2026. Следующий основной ID остаётся G21.

## Реализация

- `dok_ui_attempts` рисует отдельную панель 240×160: исходный FONT16,
  заголовок по центру на y52, FONT8 с остатком на y80; конец игры на y64.
  Подсказки занимают прежнюю нижнюю строку y148 без счётчика страниц.
- Строки RU/EN воспроизводятся `ui_copy.py` в CP866. Оригинальные ресурсы
  и другие страницы не редактировались. Переходы A/Start/B прежние;
  дополнительно исправлено устаревшее состояние возврата в паузе.
- `verify_flow_gba.py`: все шесть миров и текстовые ресурсы, остаток 2/1/0
  обеих локалей, исходные FONT16/FONT8, пустота вне текстовых блоков,
  полная строка подсказок без пагинации, Select без расхода попыток,
  A/Start, B → меню → новая игра → пауза → продолжить, пауза после повтора.

py -3.14 -X utf8 ports/gba/scripts/verify_frontend_gba.py --build-dir build/gba/ui03-attempts/hardware/g22_split_active --report build/gba/ui03-attempts/frontend.json

## Наблюдения промежуточного прогона

Первая ROM: 2/1/0 RU/EN и frontend прошли, общий flow выявил `resume=DEATH`
после B → новая игра → пауза → продолжить. Этот прогон не считается
успешной полной проверкой. Итоговый прогон выполняется после исправления.
Две попытки сборки в ограниченной среде завершились `UnableToSpawnSelf`
в `zig objcopy`; запуск тем же общим Zig вне ограниченной среды прошёл.
Далее сборка перезапущена после включения исправления обоих путей resume.

## Итоговая проверка и артефакты

Итоговый build прошёл host-тесты, Linux/Thumb-компиляцию и линковку ROM.
`verify_flow_gba.py` и `verify_frontend_gba.py` прошли на одной итоговой ROM.
Проверены шесть миров, исходные текстовые ресурсы, сохранение инвентаря,
мира, scheduler и снарядов при retry, 2/1/0 RU/EN, переключение языка,
A/Start, B и оба исправленных пути паузы. Все шесть PNG просмотрены.
Главное меню, исходные арты, удержание кнопок, выбор/отмена уровня и два
повтора музыки прошли; корреляция повторов 0,99395.
