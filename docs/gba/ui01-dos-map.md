Прежняя карта 64×64 по 2 пикселя с панелью заменена исходной отрисовкой

## Исходные правила и доказательства

Адреса — **NE-загрузчик Ghidra**, не файловые смещения и не DPMI-селекторы.
Карта: PKR `1098:1290…30C0`, PKE `1030:1374`.
Экспорт read-only: `tools/ghidra/InspectAutomap.java`, `tools/originals/analyze_automap.py`.
Проекты — `research/ghidra/projects/{ru,en}/Kremlin.gpr`; листинги, бинарные
сегменты, отдельный автоматический C и журналы — `research/evidence/automap/`.
Автоматический C не является собираемым кодом движка.

SHA-256 EXE до и после экспорта совпали:

- PKR: `12f78afc0eba05f76b5dc0bb99da38d7daa20585024c0ba958fe828aa3864d28`.
- PKE: `cce7bc5993d0734ad87e93db37a70b8b52faedfff14ac48d6e317e5ac996a37b`.

Подтверждены шаг 3×3 (float 3.0: RU DS0893 / EN DS092B), обращённая
экранная ось X, направление строк Z, заливка пола, контуры стен только
со стороны исследованного прохода, независимые проверки соседей для двух
направлений центральных линий классов 4/7, квадраты классов 8/12 и указатель
героя. Цвет — исходный byte marker `object+1B`, палитра — GAMEPn уровня.
При завершённом открытии двери marker инвертирован, как native `NOT AL`;
порт выводит его из `parameter_54==1` без новой mutable копии.

**Без предмета карты предметы и враги скрыты.** Native world+0C разрешает
квадраты классов 3/10/6/13 и живых монстров класса 9 (`+A2 != 4`).
Статические элементы 8/12 сохраняются по исходному правилу. Подбор карты
не обходит visited: ещё не исследованные клетки не раскрываются.
Это исправляет прежнее GBA-поведение, где флаг открывал весь план.

Вход `__cdecl16far`: far this на BP+6, `LES`, `RETF`, caller cleanup.
Геометрия и классы — signed WORD; marker — BYTE; координаты примитивов
передаются DWORD. Проверены ASM-вызовы прямоугольника, горизонтальной и
вертикальной линий, пикселя, включённые конечные точки, ветки соседей и
угловые диапазоны указателя. Far pointers не перенесены в структуры C.

`ports/gba/scripts/verify_automap_original.py` исполняет оригинальные инструкции x86
через общую Unicorn. Подменены только графическое устройство/clip setup и
два x87-преобразования масштаба на подтверждённое значение 3. Перед обходом
установлены будущие координаты героя в двух stack locals: DOS рисует указатель
после каждой строки, в том числе до обнаружения героя, используя неинициализированные
значения. Их случайные следы не воспроизводятся; GBA рисует героя после плана.
Это явное исправление неопределённого исходного поведения, не pixel oracle
для целой DOS-сессии. Восемь пиксельных знаков направления также получены
отдельным исполнением исходной функции.

Сверка исходного x86 и host C: три уровня × два оригинала × наличие/отсутствие
предмета × два положения окна = **24 сравнения без различий**. Два окна
покрывают весь исходный план по высоте и ширине, включая героя.
Полный локальный отчёт: `research/evidence/automap/execution.json`.

## Адаптации GBA и проверки

Экран карты — 240×144, две строки подсказок — y144…159. При открытии окно
центрировано на герое, исходный масштаб сохранён. Скроллинг ограничен
размерами плана, удержание крестовины повторяет шаг, A центрирует снова.
Нет меню-текстуры, декоративной рамки и дополнительного framebuffer.
Палитра уровня используется и в режиме карты, возвращение восстанавливает
игровой режим. Статический кеш меню исключает MAP, иначе прокрутка не была
бы видна. Раскрытие visited существующим GBA-веером сохранено; точное
DOS-раскрытие по render records не заявляется.

Host Windows прошёл, Linux/Thumb скомпилированы. Host проверяет предметный
флаг, сокрытие мёртвого монстра и неисследованной клетки, repeat крестовины
и блокировку кнопок при выходе. mGBA на всех шести мирах проверяет прокрутку,
A, Select/B, оба pause chord, флаг карты, неизменность мира и часов, отсутствие
запуска музыки меню. При открытой карте диагностические freeze выключены:
мир останавливает именно production pause. PNG RU/EN просмотрены.
Прошли существующие UI/flow/playtest/latency suites и 294 аппаратных перехода:
5008 callbacks, 0 смешанных, 18 целых чёрных кадров при смене layout.

ROM: `artifacts/gba/DoK-port_UI01.gba`, **16014848 B**, SHA-256
`f6473b2b5688b363ed1b9ad95186713f22283cb36ab89fc6644fbcf3ecb8b54b`.
Сборка, ELF/map/PNG и отчёты — `build/gba/ui01-dos-map/`.
EWRAM 261444 B, свободно 700 B; IWRAM 24424 B, свободно 152 B до резервов
стеков. Наблюдавшийся main stack 2584 B, запас 5352 B.

Физическая GBA и новый полный DOS-плейтест не проверены. Чистый повтор,
