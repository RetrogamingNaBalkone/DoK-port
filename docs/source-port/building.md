# Сборка SDL2-порта

2 ноября 2026: C++17, CMake 4.4.4, Ninja 1.13.2, общий Zig 0.13.0.
Новая реализация независима от кода GBA/NDS. Подготовлена предварительная
сборка PKR/PKE/Old Gold для плейтеста; ограничения в `ports/sdl2/PLAYTEST.md`.

Актуальные команды из корня:
`powershell -NoProfile -ExecutionPolicy Bypass -File ports/sdl2/tools/build.ps1 -Configuration Release`
и `powershell -NoProfile -ExecutionPolicy Bypass -File ports/sdl2/tools/package.ps1`.
Результат — `artifacts/sdl2/windows-playtest`. CTest13/13.
`--renderer gl|software`, `--size 1280x720`; Old Gold запускается с
`--res originals/Old_Gold_3D/OLD_GOLD.RES --level LEVEL4`.
Актуальный пакет на 4 ноября: `artifacts/sdl2/windows-playtest-20261104-render-opt/`;
команды и проверки — [отчёт оптимизаций](spec/render-optimization-20261104.md).
Ниже сохранены также исторические результаты отдельных этапов; номера
CTest и описания возможностей относятся к дате соответствующей записи.

## Windows

Общий SDL2 SDK 2.32.10 установлен в
`%LOCALAPPDATA%/Programs/SDL2/SDL2-2.32.10/`.
Источник: `https://www.libsdl.org/release/SDL2-devel-2.32.10-mingw.tar.gz`.
SHA-256 загруженного архива:
`83a5d74012311edc3c0d40ea6faecbe57ad692aa033fa5dc273cc937e3938ff2`.
Хеш фиксирует использованный файл; отдельная подпись поставщика не проверялась.
CMake/Ninja установлены через `py -3.14 -m pip install --user cmake ninja`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ports/sdl2/tools/build.ps1 -Fresh
py -3.14 -X utf8 ports/sdl2/tools/check_assets.py
build/sdl2/windows/dok_port.exe --res originals/Old_Gold_3D/OLD_GOLD.RES --res originals/pkr/RUS/PKR.RES --res originals/pkr/ENG/PKE.RES --frames 3 --screenshot build/sdl2/windows/bootstrap.bmp
```

`-Fresh` пересоздаёт CMake cache, не удаляет исходники или оригиналы.
Для обычной инкрементальной сборки опустить. `-Headless` исключает приложение
и зависимость от SDL2; `-Configuration Release` выбирает оптимизированную сборку.
Toolchain общий, кеш компилятора находится в `build/sdl2/zig-cache/`.
В песочнице Ninja зависал без дочернего compiler process; при проверке использован
обычный запуск сборочного скрипта вне ограниченного процесса. Это не сбой C++.

`dok_inspect.exe RES...` проверяет контейнер и уровни. `--json RES` экспортирует
данные для машинной сверки. Все строки ресурсов в диагностическом JSON — hex
исходных CP866-байтов. Таблицы распознавания воспроизводятся командой
`py -3.14 -X utf8 ports/sdl2/tools/generate_catalogs.py` из отслеживаемых каталогов.

Приложение принимает повторяемый `--res`, перетаскивание RES, переключение
наборов стрелками/крестовиной, F11 для borderless и Esc/Back для выхода.
На этапе каркаса приложение показывало статический ресурс. В текущем
плейтесте есть игровая сцена и меню; актуальные возможности — в плане и PLAYTEST.md.
Путь журнала определяется SDL_GetPrefPath("DoK-port", "SourcePort").
`--frames` и `--screenshot` предназначены для воспроизводимой smoke-проверки.

## Проверки и границы

- Чистая CMake-конфигурация, compiler ABI probe, сборка и CTest прошли.
- Windows SDL2-окно реально открывалось; завершение после 3 кадров, все 3 RES.
- Все 203 отдельных изображения, 60 анимаций и 56 звуков свёрены по формату,
  параметрам и FNV-1a полезных байтов с отдельным Python-декодером.
- Все 899 определений и 21 карта семи уровней совпали с отдельным сканером;
  шесть LEVEL Кремля также совпали с ранее принятыми stage5-данными.
- Семь сочетаний архивов, перемещение блоков/каталога и усечение проверены.
- Проверены все 13 палитр, 6 шрифтов, 6 LIGHT и 26 мутаций архивов/LEVEL.
- Первичная расстановка актёров и карты шести миров Кремля совпали с исходными
  world-доказательствами; в OG сумма денег105. Это не полный runtime.
- CTest7/7 проверяет загрузчики, арифметику, часы, события, начального героя,
  камеру и raster. PIT-арифметика прошла3399 x86-векторов; полный scheduler
  ещё не прошёл независимую x86-проверку.
- Отчёт проверки — `build/sdl2/checks/assets-report.json`.

Начальная статичная сцена Кремля доступна через `--level`:

```powershell
build/sdl2/windows/dok_port.exe --res originals/pkr/RUS/PKR.RES --level LEVEL1
py -3.14 -X utf8 ports/sdl2/tools/check_scene.py
```

Проверены6 уровней RU/EN и48 ракурсов; приложение реально показало сцену.
Доступно движение с коллизиями: WASD, Q/E, поворот мышью/стрелками;
левый стик движение/стрейф, правый — поворот. Esc/Start — пауза, Shift — бег.
Потеря фокуса ставит мир на паузу; Esc возобновляет. Space/Enter/A открывает
дверь перед героем; ключи подбираются в исходных клетках карты.
Работают дверная анимация и сенсоры FCMap, классический HUD Кремля.
Общие анимации пока не готовы. Left/Right переключают набор только на заставке.
Up/Down или D-pad выбирают уровень, Enter/A/Start запускают его; 1/2/3
запускают соответствующий уровень сразу. После смерти Enter/A повторяет
попытку с сохранением мира; после Game Over/финиша возвращает выбор.
Перед игрой показывается исходное вступление, после выхода — финал.
Enter/A/Start листает страницы, Esc/B возвращает выбор. `--skip-intro`
пропускает вступление. HUD показывает исходные сообщения подбора и смерти
монстров в течение4 секунд игрового времени.
CTest 12/12; `dok_item_tests.exe RES...` проверяет все размещённые предметы.
Подборы/конвейеры, изображение оружия и настоящие снаряды подключены.
Оружие появляется после подбора и меняется цифрами1/2, PageUp/PageDown или
плечевыми кнопками геймпада. `dok_weapon_probe.exe RES...` проверяет анимации
и смену. Огонь подключён: Ctrl/ЛКМ/X/правый триггер после подбора оружия.
`dok_projectile_probe.exe RES...` проверяет полёт, попадания и освобождение.
AI и анимация смерти монстров подключены; `dok_monster_probe.exe RES...`
проверяет их в контролируемых аренах. Игра пока не завершена.
`dok_interaction_tests.exe RES...` дополнительно проверяет двери
и сенсоры исходных карт. `dok_walk_probe.exe RES` проверяет движение и отрисовку на трёх
уровнях выбранного Кремля при 30/60/144 FPS (4212 кадров на архив).
В этом режиме OG пока явно отклоняется, его профиль камеры не проверен.

Не заявлены звук во время игры, OpenGL backend, полные меню,
полная симуляция трёх игр, сохранения и прохождения. Пользовательский релиз ещё не упакован;
выходы build не выдаются как готовая игра. Linux/ARM/PortMaster — SP20.
