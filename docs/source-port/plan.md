# План отдельного Source Port

Обновлено 26 октября 2026 года. Цель: одна SDL2-кодовая база для Old Gold,
оригинальных PKR и PKE с сохранением различий профилей.
Этот реестр не меняет задачи и статусы GBA-порта.

| ID | Задача | Статус |
|---|---|---|
| OG01 | Декомпиляция запрошенного OG.EXE, проверки, особенности Old Gold | Завершена в границах автоматического восстановления |
| SP00 | Оценка общего порта трёх вариантов | Завершена; архитектурное предложение, не реализация |
| SP01 | Профили данных и адаптер диалекта LEVEL Old Gold | Следующая; не начата |
| SP02 | Отдельная SDL2-цель: выбор профиля и начальный мир всех трёх | Не начата |
| SP03 | Общие движение, коллизии, двери, поверхности; оригинальные эталоны | Не начата |
| SP04 | Предметы, снаряды, оружие, AI; проверка различий OG/PKR/PKE | Не начата |
| SP05 | HUD, game flow, Speaker/SB sound policy и полные сценарии | Не начата |

OG01: [паспорт результата](tasks/OG01.md),
[декомпиляция](old-gold-decompilation.md),
[особенности](old-gold-features.md).
SP00: [оценка](shared-port-assessment.md).

Перед продолжением читать [передачу контекста](handoff.md).
Декомпиляция не закрывает SP01–SP05. Новые улучшения управления,
сохранений и графики планировать после воспроизводимого базового режима.
