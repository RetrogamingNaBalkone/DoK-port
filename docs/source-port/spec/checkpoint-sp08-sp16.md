## Состав

Основной Windows-видеоэтап, FOV/4:3/classic/overlay, Sharp Bilinear/FXAA;
исправления OG движения/дверей/поверхностей/смерти/звука; исправление
невидимого блокирующего трупа Кремля; RU/EN всех игровых текстов с одним RES;
центрированные меню/HUD, более крупный шрифт, полировка по ui-ux-pro-max и
Unslop; карта, справка, браузер и выбор источников RES.

SP16: безопасный повтор не затирает живого актёра в spawn, переносит дверную
занятость однократно и транзакционно отказывает при отсутствии места.
Интерфейс возвращает экран исхода при отказе. OG перед звуком смерти
останавливает прежний голос по исходной ветви; три профильных audio-trace
сценария добавлены в flow tests.

## Оставшиеся границы

Полная матрица прохождения семи уровней и исходов SP16 продолжается отдельно.
Эта сборка не обещает её завершения. Игровых сохранений SP17 нет.
Физический геймпад, GLES/RK3326, mixed-DPI и Linux/PortMaster требуют
отдельной приёмки. Последующие mipmap/aniso/xBR — отдельные расширения.
Точная аналоговая/mixer/clock эквивалентность и акустика каждого игрового
события не заявлены по ограниченным DOS-записям SP13.

в `NOTICES.txt`. Применялась лёгкая полировка существующего игрового стиля.
