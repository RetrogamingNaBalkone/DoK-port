# Меню, настройки и исходные видеорежимы — 3 ноября 2026

Уточнение 6 ноября 2026: новые профили, отсутствующие поля INI и сброс
видеонастроек дают FPS Выкл., FXAA Выкл., Nearest для GL-текстур и software.
Явно сохранённые значения профиля сохраняются. F12 пишет в screenshots/
выбранного профиля, рядом с settings.ini и saves/; portable использует каталог
EXE. Явный --screenshot ПУТЬ по-прежнему разрешается относительно cwd.
Проверки — [SP-CLASSIC-PAD](../tasks/SP-CLASSIC-PAD.md).

Реализованный участок SP15; связанные SP07–SP10, SP13, SP14, SP16 и SP19.
Это адаптация оболочки порта, а не доказательство полного соответствия DOS.

## Контракты реализации

Уточнение SP21 от 4 ноября: FOV автоматический от DOS-кадра 4:3,
аспект справочный. Borderless OpenGL имеет отдельное внутреннее разрешение
всей композиции, которое вписывается в drawable с полями; размер окна хранится
отдельно. Настройки HUD не ограничивают широкий viewport. Подробности и
актуальная приёмка — [видеоспецификация](video-windows.md) и [SP21](../tasks/SP21.md).
Исторические сведения о borderless/геометрии ниже читать с этим уточнением.

- `Frontend` управляет экранами и рисует единый пиксельный кадр для обоих
  рендереров. `Display` владеет окном и выводом; World, события, оружие,
  монстры и звуковые эффекты принадлежат игровой сессии в main.
- Главное меню: начало, настройки, авторы, выход. Единственный RES пропускает
  выбор набора. Несколько наборов имеют явно подписанные PKR/PKE/Old Gold.
  Начальное оформление PKR → PKE → OG; после выбора запоминается набор.
- FON, МЕНЮ_ПАЛ, FONT8/FONT16 и иллюстрации загружаются из пользовательского
  RES. При отсутствии ресурсов используется собственный минимальный
  кириллический bitmap-шрифт. Новый декоративный стиль не вводился.
- PKR/PKE: заставка → README → выбор уровня с BSPRn и BINTROn → создание
  World только по «Начать». OG: заставка → INTRO4BSPR/INTRO4B → LEVEL4.
  Текст на отдельной непрозрачной панели; ручные страницы, иллюстрация остаётся.
  Маленькие окна используют вертикальную компоновку и FONT8. Титры также
  постраничные. Исходные названия уровней выбираются по RES, не языку оболочки.
- Графика, звук, управление, геймплей и интерфейс — отдельные вертикальные
  меню. Пауза не продвигает мир. Выход и главное меню из игры подтверждаются.
- `AppSettings`: версия 1, `%APPDATA%/DoK-port/SourcePort/settings.ini`.
  Запись во временный файл и атомарная замена; повреждённые значения дают
  проверенные defaults и уведомление с журналом. CLI перекрывает настройки
  только в процессе; сохраняются изменения, сделанные пользователем.
- Первый запуск: SDL_GetPreferredLocales, первый язык `ru` → русский,
  остальные → English. Сохранённый выбор не заменяется локалью ОС.
  Каталог новых строк — `menu_strings.hpp`; сюжеты и игровые сообщения
  остаются на языке RES. Переключение интерфейса не сбрасывает World.
- Видеорежим применяется отдельной кнопкой. Новое окно создаётся до
  уничтожения старого; подтверждение 15 секунд, Escape/таймаут откатывает.
  При отказе GL есть software. F3/F4/F11 синхронизированы с настройками.
- Software framebuffer: только 320×200, 640×400, 640×480, 800×600, 1024×768.
  Мир растеризуется в выбранном разрешении, а не растягивается из VGA.
  Изменение разрешения в меню меняет и размер окна; ручной resize только
  масштабирует готовый кадр. Borderless использует рабочий стол. Линейный
  фильтр относится к сцене/масштабированию кадра; меню остаётся nearest.
- Общая громкость, эффекты и музыка заставки регулируют исходный моно-S16
  поток. Музыка существует без World; многоголосие не добавлено.
- Клавиатура и геймпад имеют независимые современные/классические пресеты,
  пользовательские назначения, конфликт replace/cancel. Переназначаются
  две клавиши и кнопка мыши на действие, кнопка геймпада либо триггер.
  Навигация меню не зависит от игровых назначений. Отключение контроллера
  отменяет захват. Start удерживать + Select отменяет захват без клавиатуры.
- Инерция по умолчанию включена. Выключение меняет только поступательное
  ускорение игрока, сохраняет аналоговую величину, бег, коллизии и течение.
  Ускорение поворота и монстры не меняются. Карта/сохранения не реализованы.

## Доказательства оригиналов

Использованы сохранённые экспорты Ghidra и ASM, не GBA-код. Указанные ниже
адреса — NE-сегмент:смещение или адрес экспортированного Ghidra-пространства,
не файловые смещения и не runtime-селекторы DPMI.

- PKR NE1008:01BA, PKE NE1008:023E: штатная заставка. Вызов звука once:
  PKR1008:0275/PKE1008:0304; остановка 0294/0323. README — PKR1008:00B3,
  PKE1008:00D7; переход к выбору 1008:02F7/1008:044B. Сводки исходного
  исследования: `docs/nds/spec/N21-evidence.md`, `N18-audio-evidence.md`.
  Используются только наблюдения оригиналов, не архитектура NDS.
- OG Ghidra20c4:0027 (`og_title_screen`), 20c4:0198 (`og_story_screen`),
  main20c4:03b0: title → select demo → story → world. Kremlin README здесь
  не вставляется. Вызовы звука18a6:022a и остановки18a6:025d. Исходные
  ожидания 10/60 секунд заменены пользовательским подтверждением оболочки.
- BSPRn/ESPRn → GAMEPn; заставка → ЗАСТАВКА_СПР/ЗАСТАВКА_ПАЛ.
  У OG GAMEPAL/МЕНЮ_ПАЛ/ЗАСТАВКА_ПАЛ совпадают побайтно; история использует
  GAMEPAL. Палитры не заменены общей нарисованной темой.
- Названия Кремля и роли авторов взяты из ресурсов. PKR/PKE ENDTXT:
  Александр/Андрей Разбаковы — 3D-технология, Дмитрий Цирухин — художник,
  NewCom, Москва, 1995. OG ENDTXT — братья Разбаковы, внешний README —
  Gelios. NewCom к OG не приписывается. Автор порта указан отдельно:
  «SDL2-порт — Ретрогейминг на балконе».
- PKR `decompiled/ru/functions/1138_01c4.c`: VGA13h, VESA100h,101h,103h,105h
  подтверждают пять разрешений. 640×400 выбирается авто-VESA100h; явные
  параметры 1 и 2 оба переходят на101h — особенность исходного переключателя.
- PKR1120:01D8: xscale=width/320, yscale=height/200. ASM1008:0B8B–0B9F:
  K=trunc(4096*xscale). ASM1008:0CF5–0D1E: высота за вычетом панели39*yscale,
  FISTP с усечением; renderer использует чётную часть высоты (160 для VGA).
  World1098:3428 задаёт D=200. Оружие1068:2EE9–2F58 масштабируется по x/y.
- OG образец создаёт VGA; исходный VESA для OG не подтверждён. Пять режимов
  общего SDL2 software доступны и OG как адаптация порта.

## Проверки и воспроизведение

Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ports/sdl2/tools/build.ps1 -Configuration Release
build/sdl2/windows/dok_frontend_probe.exe . build/sdl2/checks/frontend
py -3.14 -B ports/sdl2/tools/check_frontend.py
py -3.14 -B ports/sdl2/tools/check_hud.py
build/sdl2/windows/dok_gl_probe.exe
build/sdl2/windows/dok_old_gold_probe.exe originals/Old_Gold_3D/OLD_GOLD.RES
build/sdl2/windows/dok_hud_desktop_probe.exe originals/pkr/RUS/PKR.RES build/sdl2/checks/menu/desktop-pkr
build/sdl2/windows/dok_hud_desktop_probe.exe originals/Old_Gold_3D/OLD_GOLD.RES build/sdl2/checks/menu/desktop-og
```

- Release CTest15/15. Ввод — в том числе виртуальный SDL-контроллер,
  пресеты, Alt-стрейф, remap, конфликт/отмена. Settings — roundtrip,
  повреждение/NaN, отказ записи с сохранением старого файла, CLI isolation,
  языки, возврат из паузы, таймаут видеоподтверждения.
- Движение: три профиля × оба режима инерции × 30/60/144 FPS, отпускание,
  смена направления, аналоговая диагональ. Течение: обе инерции, оси X/Z,
  силы ±1400, 30/60/144 FPS; точные траектории и непрерывность камеры.
- frontend_probe: семь комбинаций RES, штатные переходы, 72 реальных кадра
  двух backend/RU/EN/640×480/1280×720/1920×1080; 35 native software-сцен
  (семь уровней × пять режимов), запрет1280×720 для software-сцены.
  Четыре пересоздания вывода без изменения отдельного World.
- check_frontend.py: настоящий процесс, GL → software из паузы, совпали
  адрес мира, ticks, pose, HP, charge, hash карт. Окно640×400; продолжение,
  перезапуск с сохранённым режимом, отмена изменения видео, пустой/плохой
  RES, принудительный отказ GL через SDL dummy. Отчёт
  `build/sdl2/checks/frontend-process/report.json`, сценарии/логи рядом.
- Просмотрены кадры меню/уровней/настроек/титров и пустых ресурсов; отдельно
  OG preview640×480 EN, PKE LEVEL3 1920×1080 RU, credits320×200 с пагинацией.
- Классическая VGA-панель совпала с DOS для PKR/PKE: 12480/12480 пикселей.
  GL probe прошёл; OG probe — 105 рублей, два оружия, 600 кадров и выход.
  Desktop HUD probes PKR/OG прошли; сохранено сопутствующее удаление номеров
  карточек оружия из desktop HUD, найденное в рабочем дереве.

## Границы результата и следующий шаг

Нужен пользовательский плейтест SP15/SP09 физическим геймпадом, включая
hotplug на конкретном устройстве. Автотест виртуального SDL-контроллера не
заменяет эту проверку. Нет заявления о полном прохождении всех игр.
Высокие software-режимы рисуют мир native, но панель HUD масштабируется из
принятой VGA-панели: попиксельное DOS VESA-соответствие не доказано. Исходный
HUD OG уже адаптирован; существующие ограничения геометрии/растра сохраняются.
Музыка и громкость не сверены акустически с новой DOS-записью. Полная
локализация SP14, карта, сохранения SP17, GLES/Linux/PortMaster остаются
отдельными задачами. Этот участок не закрывает все связанные паспорта.
