# Общий Source Port: Old Gold, PKR и PKE

Отдельная линия разработки общего SDL2-порта. Документация, план и передача
контекста этой линии находятся здесь. План и результаты GBA этой задачей
не меняются; завершение GBA не является предварительным условием SDL2.

**Актуальная основа — [план, перестроенный 4 ноября 2026 года](plan.md).**
Windows-плейтест уже объединяет OG/PKR/PKE, software и самостоятельный GL2,
игровые подсистемы, меню и настройки. Следующая задача —
[SP18: предварительная сверка семи уровней](tasks/SP18.md); затем доводка,
сохранения и релизная приёмка. Полные прохождения, игровые сохранения,
локализация всех текстов и платформенная приёмка ещё впереди.
Перед работой читать [правила проекта](../../AGENTS.md),
[актуальную передачу](handoff.md) и паспорт. Команды — в [сборке](building.md).
Предыдущие этапы сохранены в [истории плана](plan-history.md)
и [истории передачи](handoff-history.md).

Основа восстановления — декомпиляции Old Gold/PKR/PKE с проверкой ASM
и оригинального поведения. GBA-порт не используется как архитектурная основа.
WASDify служит источником исследований; ECWolf — ориентиром для современного
порта. Историческая оценка SP00 не заменяет утверждённый план.

26 октября 2026 года выполнена автоматическая декомпиляция `OG.EXE` из
`originals/Old_Gold_3D`: **889 функций**, отдельный проект Ghidra,
полные локальные экспорты, воспроизводимые скрипты и проверка ресурсов.
Это исследовательская база текущего SDL2-движка; автоматическая декомпиляция
не означает проверенную эквивалентность игрового поведения.

`Old_Gold_3D`.
