# Общий Source Port: Old Gold, PKR и PKE

Отдельная линия исследования для будущего SDL2-порта. Документация, план
и передача контекста этой линии находятся здесь. План и результаты GBA
этой задачей не меняются.

26 октября 2026 года выполнена автоматическая декомпиляция `OG.EXE` из
`originals/Old_Gold_3D`: **889 функций**, отдельный проект Ghidra,
полные локальные экспорты, воспроизводимые скрипты и проверка ресурсов.
Это база для восстановления движка; исполняемый SDL2-порт ещё не создан.

- [Декомпиляция: артефакты, адреса, проверки и ограничения](old-gold-decompilation.md).
- [Особенности Old Gold и их судьба в «Подземельях»](old-gold-features.md).
- [Оценка общего порта трёх вариантов](shared-port-assessment.md).
- [План](plan.md) и [передача контекста](handoff.md).

Предыдущее [сравнение комплектов Old Gold](../old-gold-version-comparison.md)
подтверждает, что каталог `Old_Gold_Old_Version` не содержит другого движка:
загружаемые байты совпадают. Для этой задачи использован только запрошенный
`Old_Gold_3D`.
