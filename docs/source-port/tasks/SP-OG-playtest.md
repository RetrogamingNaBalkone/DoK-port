# Old Gold — базовая играбельность для плейтеста

Статус: базовый сценарий реализован, передан на плейтест. Область: LEVEL4 в общем SDL2-приложении, software и GL,
движение, двери, предметы, палочки, монстры, деньги и выход. Полную релизную
доводку пользователь отложил до плейтеста. Зависимости: SP03–SP13, SP15–SP16.

Основа: OG.EXE, Ghidra MZ-адреса (не файловые смещения),
`decompiled/old-gold/functions/` и `listing.asm`; хеш образца в OG01.
Ресурсы OLD_GOLD.RES сохраняются неизменными. GBA-код не используется.

Проверяемые отличия: reader 1ae1:21ea — урон +5A, нижний предел +5C;
spawn 2266 — высота 3/4 высоты источника и стоимость 1;
tick 230c — clamp 0x600, деление шага пополам, общая анимация после попадания.
Предметы/выход 18b9/1e16, смерть 15a2, двери 2eea, монстры 32ac/3a42.
HUD 1f1d:0251/04c8/05c5: отдельная тема и деньги.

Приёмка: сборка/CTest, сценарий на настоящем LEVEL4 с подбором денег,
условием выхода, движением и выстрелами; запуск обоих рендереров и просмотр
кадров. Полное прохождение человеком и точное сравнение всех OG-ветвей с DOS
остаются для следующих итераций; успешный smoke test их не заменяет.

## Результат

LEVEL4 запускается из меню и CLI, OLD_GOLD.RES обнаруживается рядом с exe.
Подключены данные собственного баланса, сбор денег, выход, оружие/AI/двери,
повтор после смерти, INTRO4B/INTRO4E, денежный HUD. Палочки имеют обратный ход
анимации (1ae1:2840); снаряд летит с первым кадром, после контакта продолжает
тот же клип. Включены различия spawn/read/tick из адресов выше.
Общие пути движения/подборов/AI использованы после сопоставления декомпиляций;
полная ASM- и поведенческая приёмка этих путей для OG остаётся открытой.
Far pointers заменены ссылками на владельцев/ресурсы, signed WORD-урон и SAR
сохранены. Reader/spawn проверены в listing.asm 21ea–22f4; RETF и LES
подтверждают far ABI. Исходник не компилируется как готовый C.

Звук: 180b:0002 делитель floor(0x1234dd/frequency)&255, PIT1193182;
2b41:0077 IRQ передаёт исходный ненулевой байт DSP-командой0x10,
терминатор0 прекращает или зацикливает звук. Листинг 009b–00a5 проверен.
Реализация выводит эти PCM-байты без нормализации. Акустической сверки нет.

Release CTest13/13. `dok_old_gold_probe.exe originals/Old_Gold_3D/OLD_GOLD.RES`
проверил105 реальных денежных клеток,2 палочки, максимум магии300,
стоимость/высоту снарядов,600 кадров симуляции/рендеринга и выход.
Подборы в тесте используют перенос к клеткам: это не доказательство полного
прохождения. `dok_port --res ... --level LEVEL4 --skip-intro --renderer gl|software
--frames60` прошёл, кадры og-gl.bmp/og-software.bmp просмотрены.
Хеш OG.EXE до/после:7965e1d67128f196fbcf2bc449d97197f355c6b81cf043608fc9e01103ea043f.

Ограничения: общий VGA viewport320×160, адаптированный HUD вместо исходной
панели320×29, точный OG FOV/видеорежимы отдельно не приняты. Общие анимации
не подключены. Остальные ограничения — в PLAYTEST.md. Следующий шаг: плейтест.
