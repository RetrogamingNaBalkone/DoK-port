# SP14 — локализация

## Выполнено в текущем проходе — 4 ноября 2026

Программная граница локализации реализована: русский и английский доступны
для интерфейса, игровых сообщений и сюжетов с любым единственным RES.
Этот результат заменяет историческую отсрочку и указания о языке RES ниже.

Добавлен UTF-8 каталог: 77 смысловых ключей, 158 алиасов оригинальных
сообщений, все 609 текстовых полей семи LEVEL. Английский Old Gold переведён
для порта, английский Кремль вычитан по оригиналам. Подключены README,
BINTRO/EINTRO, INTRO4B/INTRO4E, ENDTXT, названия уровней, подборы, смерть
монстров, door/key-строки и `cheat.idkfa`: «Ах ты хитрый думер!» /
`You sneaky Doomer!`.

Смена языка сразу переводит уже активное сообщение и не продвигает мир.
Для SP17 добавлено сохраняемое `World::message_key` рядом с исходным текстом
и сроком. Исходные CP866-байты сохранены для диагностики; перевод UTF-8
преобразуется в CP866 на границе шрифта. Оригинальные RES/EXE не менялись,
новый анализ EXE не требовался.

По новому указанию пользователя выбор игр упорядочен: Старое золото,
русское издание Кремля, английское издание Кремля. Название OG и описания
локализованы; PKR/PKE убраны из пользовательских подписей выбора.
Внутренние идентификаторы и диагностические имена файлов сохранены.

Проверки: единый Release CTest 17/17; все 609 полей и оба перевода;
38 сюжетных языковых вариантов, 2698 проверенных страниц; 36 сочетаний
single RES/язык/backend/размер; 12 настоящих процессов с переключением
языка в паузе и сохранением World/ticks/maps/pose/HP/charge. Все шесть
исходных шрифтов покрывают 126 используемых глифов. SHA-256 RES неизменны.

## Цель и граница

Каталог смысловых строк меню, настроек, подсказок и исходов; независимый от
DatasetId LocaleId. Смена языка не меняет мир/набор. Исходные CP866 шрифты
читаются из RES; без RES используется собственный запасной шрифт.
Полный SP14 требует также перевода сюжетных/игровых текстов и английского OG.
Этот объём отложен пользователем: меню явно сообщает язык исходных текстов.

## Контракты и приёмка

Новые строки хранятся как UTF-8, граница исходного bitmap font преобразует
поддерживаемые символы в CP866. Тексты ресурсов не перекодируются дважды.
Оба языка доступны при любом единственном RES и без RES. Проверить длины,
переносы, возврат фокуса, смену языка в паузе без продвижения мира.
Имена/роли оригинальных авторов сверять с ENDTXT и README оригиналов.

## Результат

RU/EN интерфейса реализован: каталог menu_strings.hpp, CP866 на границе
исходных шрифтов, запасной кириллический шрифт без RES. Первый запуск
использует локаль ОС: ru → RU, иначе EN. Сохранённый выбор имеет приоритет;
проверены RU и DE через SDL preferred-locale hint, roundtrip и немедленная
смена языка. Два языка × два backend × три размера окна прошли.
Исходные имена уровней, сюжеты и игровые сообщения остаются на языке RES.
Полная локализация трёх игр не завершена. Следующий шаг SP14 — отдельное
согласование переводов. [Проверки и границы](../spec/menu-settings.md).
