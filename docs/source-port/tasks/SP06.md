# SP06 — состояние мира и жизненный цикл

Статус: начато создание мира; полная интеграция зависит от SP04/SP05.
Материалы: `docs/originals/world.md`, `analysis/originals/worlds-{ru,en}.json`,
OG MZ Ghidra `21b8:0d90`; PKR/PKE NE Ghidra `1098:004f` / `1030:0079`.

## Контракт и работы

World владеет LevelDefinition и runtime-состоянием; один объект на glyph,
а не экземпляр на каждую клетку. Карты отражаются по строкам, точки становятся
пробелами. Герой/монстры получают позицию из последнего размещения в MMap.
Сумма категории99 в TMap — signed16 с wrap; OG ожидает 105 рублей.
Неразмещённый объект не получает выдуманную позицию. Определения снарядов
сохраняются. Ссылки используют стабильные индексы, не адреса DOS.

## Приёмка

Все семь миров; карты/позиции/сумма денег против оригинальных доказательств,
повторяющиеся glyph, создание/уничтожение/повторный вход. Далее — состояния
конструкторов, анимации, динамические слоты и регистрация событий по SP05.
Первичная расстановка без них не закрывает SP06.

## Результат

World создаёт карты/visited, один WorldObject на определение, optional-позу
и счётчик размещений. Сверены все актёры, координаты, heading, placements и
SHA-256 нормализованных карт шести миров Кремля с `worlds-{ru,en}.json`.
Для OG подтверждена сумма105; полная динамическая сверка поз OG ещё впереди.
Команда — `py -3.14 -X utf8 ports/sdl2/tools/check_assets.py`, PASS.
Добавлены event owners всех определений и PlayerState:11 слов LEVEL +5e…+72,
девять weapon ID, current/pending, lives3, score0, неизвестное поле +da=0.
Семантически не названные слова сохранены, не объявлены padding.
OG constructor MZ `1ae1:128f`, ASM `12d2…133f`; PKR/PKE NE
`1068:1657`/`1020:1b61`, ASM `169a…16e8`/`1ba4…1bf2` подтверждают начальные
значения и interval416. Readers OG `1ae1:13ef`, PKR `1068:1789`
читают11 слов; эти поля ранее сверены как определения LEVEL.
Расписание регистрируется в порядке определений, включая неразмещённых героев,
а не только после поиска единственного player в MMap. Owner ID=index+1.

`World::advance_events` продвигает логическое время и выполняет sweep на каждый
native tick. Это явное изменение кадрового опроса DOS ради независимости от FPS;
запоздание из-за длительности DOS-отрисовки не воспроизводится. Пропущенное host
время не отбрасывается; вызовы используют время симуляции, а не wall-clock внутри
callback. Пока интерфейс требует внешний обработчик, без no-op по умолчанию:
player callback и прочая игровая логика ещё не реализованы.

CTest world: идентичные72 вызова на ticks416…29952 за3 секунды при30/60/144 FPS,
нулевое elapsed не меняет мир; уничтожение owner отменяет вызовы; новый World
сбрасывает время, score и очередь. Это проверка event plumbing с тестовым
callback, не движения/боя. `check_assets.py` повторно прошёл все7 миров,
начальные PlayerState,7 сочетаний RES и26 повреждений/перепаковок.
Дальше — базовые/специализированные конструкторы остальных классов, анимации,
слоты динамических объектов и обработчики событий. SP06 не закрыта.
