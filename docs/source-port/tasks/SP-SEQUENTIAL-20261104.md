# Последовательное завершение открытых областей SDL2

Запрос пользователя от 4 ноября 2026 года: пройти задачи «в работе»,
на каждую запускать отдельного субагента последовательно, сохранять handoffs.
Область уточнена пользователем: только SDL2; GBA и NDS не входят.

Предыдущая сессия остановлена после SP07 по указанию пользователя.
Новый запрос разрешает SP08–SP16, отдельным субагентом на каждую задачу.
Актуальные исполнители, результаты и передача продолжения:
[проход SP08–SP16](SP08-SP16-20261104.md).

## Исходная точка

HEAD: `b1830c754991cfc3c653b120728a5d1681f41947`.
До начала уже изменены `README.md`, `building.md`, `handoff.md`, `plan.md`
в `docs/source-port/`; не отслеживались `handoff-history.md`,
`plan-history.md`, `tasks/SP-REPLAN.md`, `tasks/SP18.md`. Эти изменения сохраняются.

По текущему плану сначала выполняется предварительная сверка SP18.
Далее области SP03–SP16 проходят последовательно; зависимые остатки
возвращаются на проверку после реализации необходимого контракта.
Финальная SP18, SP17, выпуск SP19 и платформенная SP20 не считаются
автоматически завершёнными этим проходом.

Каждый исполнитель читает актуальный план, handoff, паспорт и результаты
предыдущего исполнителя с диска. Перед передачей сохраняет реализацию,
команды и результаты проверок, доказательства оригинала, ограничения,
изменённые контракты и конкретный следующий шаг. Основной агент проверяет
передачу перед запуском следующего исполнителя. Статус области меняется
на завершённый только при выполнении её критериев приёмки.
