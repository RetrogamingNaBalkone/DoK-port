# SP20-07 — Пакет PortMaster и плейтест

Статус: Пакет готов для первого запуска; пользовательская аппаратная приёмка открыта.

## Цель и зависимости

Пакет PortMaster и плейтест. Зависимости: SP20-03, SP20-06.

## Материалы и контракты

[План](../plan.md), [handoff](../handoff.md), [SP20](SP20.md),
[сборка и проверки](../linux-portmaster.md). Реализация только ports/sdl2.
Общий игровой код и формат сохранений; без отдельного движка ARM и миграций
промежуточных сборок. Оригиналы не менять и не поставлять. GBA/NDS не затрагивать.
Windows принята; повторяем проверки затронутого кода.

## Работы

Пакет без RES с лицензиями/метаданными. Чистая установка и обновление без замены user. Семь уровней трёх игр, RU/EN, звук, оба пресета, сон/пробуждение, перенос сохранений Windows/Linux/PortMaster. DS Plus повторяет сценарии при появлении.

## Приёмка

Пользователь принимает Vita Pro/ROCKNIX. DS Plus ведётся отдельно и не подменяет Vita или RK3326.

## Воспроизведение и результат

Команды и фактические результаты текущего участка — в linux-portmaster.md.
Полные отчёты — build/sdl2; постоянные доказательства — research/evidence/source-port;
готовые пакеты — artifacts/sdl2. Новый анализ EXE эта задача не требует.
Доступ к SSH пользователь отложил 8 ноября 2026. Фактические версии ОС,
драйверов, частоты, управление и сон устройств пока не проверены.
Следующий ID: SP20-08.

## Участок 8 ноября 2026

PortMaster ZIP без RES/профиля, ELF64 aarch64 GLES2, лицензии, launcher и метаданные. Windows/Linux/ARM quicksave PKR: 9/9 загрузок PASS; другие игры, microSD, сон и физический ввод ещё не приняты.

Команда из корня (Linux; для build — внутри соответствующего builder):

```sh
python3 ports/sdl2/tools/check_unix_package.py artifacts/sdl2/OGDoK-PortMaster-playtest-20261108-r3.zip
```

Общие результаты, окружение и ограничения: [linux-portmaster.md](../linux-portmaster.md).

## Проверка установочной структуры

Метаданные в готовом ZIP находятся в ogdok/port.json и ogdok/gameinfo.xml,
инструкция — ogdok/ogdok.md; в корне только OGDoK.sh. Это преобразование
исходной структуры выполняет официальный PortMaster build_port_zip.
Проверка check_unix_package теперь независимо от manifest отклоняет метаданные
в корне ZIP. Регрессии Unix tools: 4/4 PASS; состав, SHA-256 и права r3 проверены.
