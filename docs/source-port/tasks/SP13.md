# SP13 — Sound Blaster

## Актуальный результат — 4 ноября 2026

Отдельный субагент SP13 в проходе SP08–SP16. Этот раздел заменяет старые
пометки ниже о неподтверждённых OG и музыке. Исправлены OG live loop flag
при повторном запросе той же identity, дополнительный PIT-интервал на
нулевом терминаторе loop, signed WORD частоты. OG title/story используют
loop, Kremlin — once; main-ветвь согласована с исполнителем SP15.

Добавлен логический Voice/SdlAudio snapshot/restore под audio lock для SP17,
без указателей и без формата игровых сохранений. Неверный ресурс/профиль/фаза
отклоняются. Разные negotiated output rates пока требуют отдельного переноса.

Проверки: 48/48 OG native wrapper/admission/IRQ сценариев, 42/42 native
DSP/PIT rates, 56 полных цифровых PCM-последовательностей, SDL pause/gain/
identity/restore PASS. Единая Release CTest 17/17. EXE/RES SHA-256 неизменны.
Три реальных headless процесса актуального main подтвердили OG title/story
loop и Kremlin title once; отдельные user-dir, штатный Frontend/SdlAudio.

Записан фактический DOS Sound Blaster output всех трёх title waveform.
OG SB IRQ и active voice подтверждены runtime; consumer hold восстановлен.
Медианы локальной NCC: PKR 0,9714, PKE 0,9270, OG 0,9912. Один глобальный
сдвиг не даёт точного равенства: guest IRQ rate и fitted wave clock измерены
отдельно; CPU overrun не объявлен причиной без доказательства. Нормализация,
усиление 6 → 8 бит и DC-компенсация наугад не добавлены.

Реальная акустическая сверка проведена в границе title excerpts, а не всех
игровых событий/аналоговой карты/hardware latency. Полная приёмка SP13/A10
сохраняет эти ограничения. [Адреса, команды и доказательства](../spec/audio-audit.md).
Основная команда: `py -3.14 -B ports/sdl2/tools/check_audio.py`.
Следующие ID — SP14 локализация, SP15 интерфейс; SP17 получает state contract.

## Музыка оболочки и громкость — 3 ноября 2026

Заставка звучит независимо от World. Восстановлена последовательность
PKR/PKE title → README → выбор; OG title → INTRO4B. Mono once/stop,
без нового многоголосия. Общая громкость/эффекты/музыка сохраняются,
применяются к исходному S16 потоку под SDL audio lock. CTest audio прошёл;
новой акустической сверки с DOS нет, SP13 остаётся в работе.
Адреса оригинальных вызовов: [доказательства меню](../spec/menu-settings.md).

Статус: в работе. Первый участок — монофонический путь PKR/PKE и SDL2.
Читать plan.md, handoff.md, SP03/SP05/SP11/SP12. Old Gold не трактовать
как PCM8 без проверки его собственного аппаратного пути.

Основа: Ghidra NE PKR10f0:005e/00ea/0125,1108:01f7/0232/026d/0298,
1118:0829/046e/0222; PKE1058:186a и соответствующие wrappers1060.
C — decompiled/{ru,en}/functions, ASM — research/evidence/audio/{ru,en}.
Один активный звук; новый отвергается до окончания или явного global stop.
Loop latch меняется только при успешном старте. Identity объекта отличается
от имени PCM-ресурса. Частота DSP задаётся округлённым микросекундным периодом.

Первый результат: проверяемый переносимый голос, SDL-устройство и игровые
потребители, остановка при замене мира, пауза. Полная приёмка дополнительно
требует OG, сопоставления с DOS-записями, всех событий и сохранения позиции.

Первый результат: MonoVoice + SdlAudio, один голос, guarded once/loop,
stop по identity и global stop. PCM8 unsigned преобразуется в S16 без
нормализации; ресэмплирование — удержание значения. DSP period считается
как round(1000000/frequency), с 8-bit time constant (PKR1118:0222).
Подключены двери/замки, подборы, выстрел, контакт снаряда, урон/смерть героя,
пробуждение/атака/смерть монстра. Identity=(owner<<16)|binding; динамические
снаряды используют собственные owner. Замена мира закрывает устройство;
пауза/чтение вступления приостанавливают воспроизведение.

Release собран, CTest13/13; audio test проверяет admission, loop latch,
PCM polarity, identity stop и EOF. SDL-окно LEVEL1 прошло180 кадров,
устройство открылось без ошибки в port.log. Захват фактического звука и
сравнение с DOS не выполнялись. OG, музыка заставки, регулятор громкости
и сохранение позиции голоса остаются открытыми.
