# SP23 — настройки, портативный режим и подключение RES

Статус: завершена 5 ноября 2026 года; Windows-приёмка пройдена.

## Цель и граница

Независимые обычный, портативный и явно заданный профили; перенос папки
с настройками и RES; предсказуемые CLI и автопоиск. Игровые сохранения — SP17,
здесь закреплён только будущий каталог. GBA/NDS не затрагиваются.
Это политика современного SDL2-порта, не поведение DOS-оригиналов.

Правила проекта, [план](../plan.md), [handoff](../handoff.md),

## Контракты

| Условие | Каталог профиля |
|---|---|
| --user-dir PATH | Указанный путь; относительный — от cwd запуска; при повторе последний |
| Обычный файл portable или portable.* рядом с EXE | Каталог самого EXE |
| Иначе | SDL_GetPrefPath("DoK-port", "SourcePort") |

Маркер регистронезависимый, содержимое любое; каталог с таким именем не маркер.
При явном/портативном профиле SDL_GetPrefPath не вызывается. Нет автоматического
импорта из AppData. Ручной перенос settings.ini поддерживается. В профиле
settings.ini и port.log; будущая папка сохранений SP17 — saves/, сейчас не создаётся.
Отказ записи диагностируется без перехода в другой профиль.

CLI разбирается до открытия профиля. `--res PATH` — до трёх повторений;
пустое/пропущенное значение, четвёртый RES и неизвестная опция — ошибка.
Все относительные CLI-пути разрешаются от cwd; идентификация игры — по содержимому.
Явные RES исключают автопоиск, сохранённые пути и сохранённый выбор источника.
Без CLI восстанавливаются сохранённые пути и ищутся .res (регистр неважен)
непосредственно рядом с EXE, без data, рекурсии и поиска в постороннем cwd.
--res-source, точная свёртка копий, конфликты и отдельные ошибки файлов сохранены.

В памяти пути профиля разрешены абсолютно; при записи внутренние пути и выбор
источника кодируются относительно профиля, внешние — абсолютно. Старые абсолютные
пути читаются. CLI сам не сохраняет источники и переопределения настроек;
явные изменения через меню/drop сохраняются. Успешное добавление/замена удаляет
потерянные пути из профиля; неудачное добавление не очищает список.
При живом World, включая паузу, смена архивов запрещена.

Формат настроек остаётся v1, игровые API не меняются. Существующие миграции
видео/громкости/управления сохранены. Запись атомарная. Повреждённый settings.ini
не меняется в простое; до замены при явном редактировании создаётся точная
settings.ini.bak (при занятом имени — .bak.N). Ошибка резервирования блокирует замену.

## Приёмка и воспроизведение

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ports/sdl2/tools/build.ps1 -Configuration Release -DirectCommands
py -3.14 -X utf8 -B ports/sdl2/tools/check_launch_paths.py
$env:SDL_AUDIODRIVER='dummy'
py -3.14 -X utf8 -B ports/sdl2/tools/check_resource_sources.py
py -3.14 -X utf8 -B ports/sdl2/tools/check_frontend.py
py -3.14 -X utf8 -B ports/sdl2/tools/check_menu_ux.py research/evidence/source-port/sp23-menu
powershell -NoProfile -ExecutionPolicy Bypass -File ports/sdl2/tools/package.ps1 -PackageName windows-playtest-sp23
py -3.14 -X utf8 -B ports/sdl2/tools/check_package.py artifacts/sdl2/windows-playtest-sp23 --hidden
py -3.14 -X utf8 -B ports/sdl2/tools/check_launch_paths.py --app artifacts/sdl2/windows-playtest-sp23/dok_port.exe
py -3.14 -B tools/reports/summarize_reports.py
```

Launch-paths проверяет маркеры, приоритет CLI, относительный и кириллический профиль,
семь сочетаний RES, переименование, 4/пустой/пропущенный RES, отсутствие поиска
в data/cwd, изоляцию CLI, сохранение и восстановление внутренних/внешних путей,
ручной перенос INI, перенос папки, замену потерянного пути, повреждение настроек,
резервную копию, отказ записи и недоступный профиль. Оригинальные RES не изменяются:
SHA-256 сравниваются до/после. Файловые образцы: originals/Old_Gold_3D/OLD_GOLD.RES,
originals/pkr/RUS/PKR.RES, originals/pkr/ENG/PKE.RES. Новый анализ EXE не выполнялся.

Unit-проверка обычного профиля использует подставленный поставщик платформенного
пути; реальный пользовательский AppData при процессных тестах не изменяется.
Проверены отсутствие вызова поставщика при portable/--user-dir, каталог portable,
обычные маркеры и сохранение внутренних/внешних путей.
