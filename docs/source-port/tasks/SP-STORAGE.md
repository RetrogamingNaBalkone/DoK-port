# SP-STORAGE — очистка диска и хранение снимков

## Цель и граница

По запросу пользователя удалить старые снимки и архивы тестовых билдов,
исправить накопление временных файлов. Сохранить материалы анализа оригиналов,
исходники, текущие поставки и входы сборок. Игровые контракты не меняются.
Статусы GBA/NDS и основная очередь Source Port не меняются.

## Материалы и контракты

Прочитаны plan.md, handoff.md, docs/storage-maintenance.md, storage_archive.py,
prune_test_storage.py, prune_superseded_builds.py, png.cpp и SDL2-сборщики.
Исходное дерево содержало незавершённую SP17 и доводку; эти изменения сохранены.
Задача не требует анализа EXE и не использует адресов оригинала.

PNG-кодировщик современного порта писал stored DEFLATE: около 54 ГБ снимков.
По уточнению пользователя старые снимки не архивируются, а удаляются.
Архивы старых билдов очищены от тестовых выходов; записи с DOS, original,
reference, Ghidra и декомпиляциями сохранены с исходными путями и SHA-256.
Сохранён архив исходных DOS RAM sp07-cold-memory и старых декомпиляций.

## Реализация

- Удалены старые PNG/BMP/RGB и benchmark-матрицы, воспроизводимые выходы
  компилятора и кэши. prune_obsolete_test_outputs.py по умолчанию показывает
  план; --apply удаляет только неотслеживаемые файлы в разрешённых деревьях.
  Оригинальные наблюдения и frozen G18 исключены.
- png.cpp использует bounded LZ77 и fixed Huffman, без новой DLL.
- SDL2 build.ps1 и build_commands.py владеют отдельным кэшем на запуск;
  дочерний сборщик наследует его, владелец удаляет через finally при ошибке.
  DOK_KEEP_COMPILER_CACHE=1 оставляет кэш для отладки.
- check_frontend.py и check_saves.py удаляют профили и снимки прогона
  через finally, сохраняя компактный итоговый JSON.

## Проверки и воспроизведение

```powershell
py -3.14 -B scripts/prune_obsolete_test_outputs.py --report research/evidence/maintenance/NEW.json
py -3.14 -B -m unittest discover -s ports/sdl2/tools -p test_compiler_cache.py
py -3.14 -B ports/sdl2/tools/test_png_storage.py
```

PNG: независимый Python zlib проверил CRC, размеры и все пиксели для одиночного
пикселя, однотонного кадра, повторяющегося рисунка и случайных данных.
494468 байт однотонных строк дают PNG 3826 байт; рисунок — 6872 байта.
Все 4 случая прошли. Три проверки кэша прошли: вложенность с ошибкой и
восстановлением окружения, отклонение постороннего пути, явное сохранение.
Рабочие каталоги проверок удалены.

Полные локальные списки: research/evidence/maintenance/cleanup-20261105/.
Сводка: analysis/storage-cleanup-20261105.json.
Исторические проверки удалённых билдов больше не воспроизводятся по их
старым снимкам; это прямое решение пользователя. Их нельзя выдавать за
доступные доказательства. Современные проверки пересоздают свои выходы.
Полная пересборка игры и платформенная приёмка этой задачей не выполнялись.
