# SP19 — Windows-сборка

## Пакет меню — 3 ноября 2026

`artifacts/sdl2/windows-playtest-20261103-menu`, Release Windows x64.
Команда `package.ps1 -PackageName windows-playtest-20261103-menu`.
Play.cmd использует сохранённые настройки; Play-OpenGL/Software.cmd
задают CLI override. EXE, SDL2.dll, инструкция, лицензия; без RES/EXE оригиналов.
CTest15/15 и проверки [меню](../spec/menu-settings.md) прошли.
Готовый EXE из artifacts реально запущен: PKR GL и OG software800×600,
по3 кадра, штатное завершение. Состав — семь файлов, исходных RES нет.
Предварительный плейтест, не Windows v1. Следующий шаг — SP15/SP09 плейтест.

Вторая итерация 3 ноября: `artifacts/sdl2/windows-playtest-20261103-r2`,
`package.ps1 -PackageName windows-playtest-20261103-r2`. Включает дробную
GPU-проекцию, плавный LIGHT и nearest/linear (F4, default nearest).
Проверки и ограничения записаны в SP08; прежние пакеты не заменяются.

## Плейтест 3 ноября 2026

Новый пакет `artifacts/sdl2/windows-playtest-20261103` содержит исправления
GL LIGHT/depth, независимую активацию AI, нижние сообщения, FPS/F3 и PNG/F12.
Команды: `build.ps1 -Configuration Release`, затем
`package.ps1 -PackageName windows-playtest-20261103`. CTest 13/13; GL probe,
27 групп/36 AI-прогонов, OG probe и PNG CRC/zlib проверки прошли.
Пакет реально запущен с PKR LEVEL1 GL, штатно завершил 3 кадра.
Оригинальные RES не включены. Старый пакет занят пользовательским процессом,
его не останавливали; поэтому сборка размещена отдельно. После выхода из старой
игры можно заменить только EXE новым, сохранив прежние RES рядом с ним.

Статус: предварительная Release-сборка для плейтеста подготовлена, не Windows v1.
Пользователь попросил остановить расширение работ на базовой играбельности
и перейти к плейтесту. Полная спецификация остаётся в плане как дальнейшая.

Состав предварительного пакета: Release dok_port.exe, SDL2.dll, инструкция,
локальный launcher. Исходные RES/EXE и research/build в пакет не включать.
Готовый пакет хранить в artifacts/sdl2/. Проверить CTest и реальный запуск.
Пакет: `artifacts/sdl2/windows-playtest`, воспроизводится `tools/package.ps1`
в каталоге порта. Включены PKR/PKE/OG и software/GL; CTest13/13,
OG-сценарий600 кадров, реальный запуск пакета. Ограничения перечислены
в `ports/sdl2/PLAYTEST.md`; полное прохождение не доказано.

Уточнение пользователя: перед остановкой на плейтест обязательно добавить
OpenGL и Old Gold. Текущую сборку пока не выдавать как достигнутую контрольную
точку до их подключения. Это условие выполнено; дальнейшее расширение
до полной релизной спецификации отложено до плейтеста.
