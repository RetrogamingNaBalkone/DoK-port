## Минимальная ОС — 5 ноября 2026 года

По запросу пользователя для готового Windows-пакета заявлен минимум
**Windows 8 x64**. Windows 7 не поддерживается; её адаптация отложена.
Запуск на Windows 8 пока не проверен, поэтому это нижняя граница совместимости,
а не результат платформенной приёмки. Полная SP19 остаётся открытой;
следующий основной ID — SP22.

Проверены PE-импорты `dok_port.exe` во всех пяти распакованных пакетах
`artifacts/sdl2/`: `windows-playtest`, `windows-playtest-20261104-sp15-r6`,
`windows-playtest-20261104-sp15-r7`, `windows-playtest-20261104-sp21`,
`windows-playtest-20261105-sp21-r1`. Во всех Machine = `0x8664` (x64)
и есть прямой импорт `KERNEL32.dll!GetSystemTimePreciseAsFileTime`.
Это проверка таблицы импортов PE, не анализ оригинальных EXE.
По [документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-getsystemtimepreciseasfiletime)
функция доступна начиная с Windows 8; на штатной Windows 7 такой импорт
блокирует загрузку приложения. Наличие UCRT и остальные зависимости
на Windows 8 отдельно не проверялись.

Воспроизводимая проверка (Python 3.14, `pefile`, из корня репозитория):

```powershell
py -3.14 -c "import pathlib,pefile; [(print(f.parent.name,hex(p.FILE_HEADER.Machine),[(e.dll.decode(),i.name.decode()) for e in p.DIRECTORY_ENTRY_IMPORT for i in e.imports if i.name==b'GetSystemTimePreciseAsFileTime'])) for f in pathlib.Path('artifacts/sdl2').glob('*/dok_port.exe') for p in [pefile.PE(str(f))]]"
```

Обновлены PLAYTEST (источник README пакета), инструкция сборки, план и handoff.
README текущей папки `artifacts/sdl2/windows-playtest/` синхронизирован с PLAYTEST;
исторические пакеты и ZIP не переупаковывались. Код и бинарные файлы не менялись.
Проверка документации: `git diff --check -- ports/sdl2/PLAYTEST.md docs/source-port`.

## Локальная упаковка с RES — 5 ноября 2026 года

По прямому указанию пользователя `ports/sdl2/tools/package.ps1` по умолчанию
копирует рядом с EXE три файла: `originals/Old_Gold_3D/OLD_GOLD.RES`,
`originals/pkr/RUS/PKR.RES`, `originals/pkr/ENG/PKE.RES`. Исходники не изменяются.
Отсутствие любого входа завершает упаковку ошибкой до изменения папки результата.
Для пакета без ресурсов есть явный `-WithoutResources`; он удаляет только
эти три известных имени из выбранной папки результата.

Команда: `powershell -NoProfile -ExecutionPolicy Bypass -File ports/sdl2/tools/package.ps1 -PackageName windows-playtest`.
Результат: `artifacts/sdl2/windows-playtest/`, семь файлов. `check_package.py`
проверяет побайтовое совпадение всех трёх RES и автоматическое обнаружение
трёх наборов при запуске без `--res`. Восемь packaged-процессов PASS.
Проверка: `py -3.14 -X utf8 ports/sdl2/tools/check_package.py artifacts/sdl2/windows-playtest --hidden`.
Это локальная упаковка по указанию пользователя, полная SP19 не закрыта.
Следующий основной ID — SP22.
