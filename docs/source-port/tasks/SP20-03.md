# SP20-03 — Linux-поведение и пакет

Статус: Пакет и автоматические проверки готовы; пользовательский Linux-плейтест открыт.

## Цель и зависимости

Linux-поведение и пакет. Зависимости: SP20-02.

## Материалы и контракты

[План](../plan.md), [handoff](../handoff.md), [SP20](SP20.md),
[сборка и проверки](../linux-portmaster.md). Реализация только ports/sdl2.
Общий игровой код и формат сохранений; без отдельного движка ARM и миграций
промежуточных сборок. Оригиналы не менять и не поставлять. GBA/NDS не затрагивать.
Windows принята; повторяем проверки затронутого кода.

## Работы

Проверить RES, регистр, UTF-8/пробелы, cwd, приоритет профиля, fullscreen, звук, ввод, запись и ошибки. Пакет без RES, с системной SDL2 и glibc <=2.35.

## Приёмка

Пакет в artifacts/sdl2, проверка в чистом runtime и пользовательский плейтест семи уровней.

## Воспроизведение и результат

Команды и фактические результаты текущего участка — в linux-portmaster.md.
Полные отчёты — build/sdl2; постоянные доказательства — research/evidence/source-port;
готовые пакеты — artifacts/sdl2. Новый анализ EXE эта задача не требует.
Доступ к SSH пользователь отложил 8 ноября 2026. Фактические версии ОС,
драйверов, частоты, управление и сон устройств пока не проверены.
Следующий ID: SP20-04.

## Участок 8 ноября 2026

Чистый runtime без SDK: 15 процессов PASS. Профили, lowercase RES, UTF-8/пробелы, cwd, снимки/CSV проверены. Реальные звук, клавиатура/мышь/геймпад и полное прохождение остаются плейтестом.

Команда из корня (Linux; для build — внутри соответствующего builder):

```sh
python3 ports/sdl2/tools/check_unix.py --exe artifacts/sdl2/OGDoK-Linux-x86_64-playtest-20261108-r3/OGDoK --out build/sdl2/checks/linux-next
```

Общие результаты, окружение и ограничения: [linux-portmaster.md](../linux-portmaster.md).
