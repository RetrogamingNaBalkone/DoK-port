# SP20-01 — Очередь и платформенные контракты

Статус: Программная часть выполнена; паспорт реального устройства отложен пользователем.

## Цель и зависимости

Очередь и платформенные контракты. Зависимости: нет.

## Материалы и контракты

[План](../plan.md), [handoff](../handoff.md), [SP20](SP20.md),
[сборка и проверки](../linux-portmaster.md). Реализация только ports/sdl2.
Общий игровой код и формат сохранений; без отдельного движка ARM и миграций
промежуточных сборок. Оригиналы не менять и не поставлять. GBA/NDS не затрагивать.
Windows принята; повторяем проверки затронутого кода.

## Работы

Описать Linux x86_64 Ubuntu 22.04/glibc 2.35 и PortMaster aarch64. Windows принята пользователем на двух ПК. Снять паспорт Vita Pro при появлении доступа; будущая DS Plus проверяется отдельно.

## Приёмка

Документы и очередь готовы; паспорт устройства ожидает доступа.

готовые пакеты — artifacts/sdl2. Новый анализ EXE эта задача не требует.
