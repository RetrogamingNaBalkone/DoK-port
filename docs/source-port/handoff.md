## Исправления плейтеста — 3 ноября 2026

Эта запись имеет приоритет над историей ниже. Пользователь попросил дожать
графику и игру, полноценную переработку UI отложил. В GL включён depth buffer:
стены закрывают дальние спрайты независимо от порядка подачи. Динамические
монстры ограничены областью сцены. LIGHT использует абсолютную глубину и
линейную интерполяцию вдоль исходной оси растра, UV остаются перспективными.
Таблицы LIGHT сохранены: последняя строка сама по себе не абсолютно чёрная.

AI в обоих backend использует original_cell_bounds на player tick; GL-ширина
больше не расширяет область пробуждения. Это сознательное уточнение прежнего
требования активации по широкому FOV по текущей просьбе пользователя.
FPS включён, F3 скрывает. Сообщения GL внизу, длинные строки переносятся;
текст смерти публикуется при смертельном попадании, не после длинной анимации.
F12: PNG в `screenshots` текущей рабочей папки, имя содержит время и номер кадра;
ошибка записи журналируется без завершения игры. `--screenshot *.png` тоже работает.

Обязательно запланирована опция включения/выключения инерции движения с
сохранением настройки: SP09/SP10/SP15. В этом изменении она не реализована.

Проверки: Release, CTest 13/13; `dok_gl_probe` — LIGHT против software,
стена/спрайт в обоих порядках, прозрачные texels и UI; `dok_monster_probe`
PKR/PKE — 27 групп, 36 прогонов двух путей при 30/60/144 FPS, своевременный
текст смерти без повтора у трупа. OG probe: 105 денег, две палочки, 600 кадров.
Реальные окна обоих рендереров запускаются; GL-кадр просмотрен.
PNG обоих backend 1280×720 проверены независимо через Python: CRC всех chunks,
zlib-декодирование и размеры scanlines. F12 привязан к тому же захвату;
физическое нажатие F12 в этой проверке не выполнялось.
Старый `artifacts/sdl2/windows-playtest/dok_port.exe` занят запущенной игрой;
её не закрывали. Новый пакет: `artifacts/sdl2/windows-playtest-20261103`,
создан `package.ps1 -PackageName windows-playtest-20261103`. RES не включены.
Пользователь может перенести новый EXE в прежнюю папку после закрытия игры.
Следующий шаг — повторный плейтест; полные прохождения/GLES ещё не проверены.
