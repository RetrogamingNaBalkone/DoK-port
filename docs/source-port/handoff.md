Актуально на 4 ноября 2026 года после [перестройки плана](tasks/SP-REPLAN.md).
Читать [план](plan.md), правила проекта и паспорт выбранной задачи.
Предыдущие передачи, адреса и команды сохранены в [истории](handoff-history.md).
Их указания «следующий шаг» не заменяют текущую очередь.

## Достигнутая точка

Есть Windows-плейтест Old Gold, PKR и PKE с software и самостоятельным GL2.
Движение, двери/сенсоры, предметы, оружие/снаряды, AI, смерть/повтор/исходы
подключены. Есть Hor+, интерполяция GL-камеры/LIGHT, вода, desktop HUD,
исходные темы, меню/вступления/титры, пауза, настройки/INI, ремап и пресеты,
RU/EN интерфейса. SP01 и платформенный каркас SP02 завершены.
Не начинать эти подсистемы заново по старым записям паспортов.

Последний зафиксированный пакет:
`artifacts/sdl2/windows-playtest-20261104-render-opt/`.
Это плейтест, не Windows v1. Подробные ограничения — `ports/sdl2/PLAYTEST.md`.
Полного прохождения человеком всех семи уровней нет. Нет карты и игровых
сохранений; RU/EN сюжетов/игровых сообщений не завершены. Общие анимации/getters,
OG/VESA, геометрия/растр и точное соответствие части игровых ветвей требуют
доводки. Физический геймпад, Linux/ARM/PortMaster и GLES ещё не приняты.

## Проверки и границы доказательств

- RES/LEVEL: все три набора, семь сочетаний, 899 определений и 21 карта;
  SP03/SP04 сохраняют остаток по дублям, границам и OG ASM.
- PIT-арифметика: 3399 x86-векторов; это не независимая приёмка всего scheduler.
- Последний отчёт оптимизаций: Release CTest 15/15, Python 14/14,
  точное сравнение 4170 + 189 + 2 × 288 кадров с эталонами порта.
- Реальный запуск пакета: GL и software 1024×768, по 5 кадров.
- RK3326: расчётный p50 GL nearest/linear 74,8/60,6 FPS,
  p95 48,5/44,5; стабильные 60 FPS и GLES не подтверждены устройством.

Команды и исходные отчёты:
[сборка](building.md), [меню](spec/menu-settings.md),
[стенд](spec/render-benchmark.md), [оптимизации](spec/render-optimization-20261104.md),
[SP20](tasks/SP20.md). Это результаты предыдущих работ; при перестройке
документов сборка и игровые проверки не запускались.

## Принятые решения, которые легко потерять

Активация AI/эффектов использует исходные клеточные границы на player tick,
независимо от renderer, размеров и Hor+ (SP12, решение 3 ноября).
Это заменяет старое требование пробуждения на всей широкой периферии.

SP08/SP15: фильтры разделить по назначению. Первый новый этап — Sharp Bilinear
готового кадра и независимый FXAA сцены перед HUD/оружием/текстом/меню;
затем mipmaps/трилинейная фильтрация и анизотропия; затем эксперимент xBR.
Новые фильтры пока не реализованы; полный объём и проверки — в плане.

SP20: цель GL 1024×768, 60 FPS на RK3326. Оптимизации в расчётной границе
закончены; следующий платформенный участок требует реального RK3326/GLES
и полного игрового кадра. Software — запасной, без требования 60 FPS в этом
размере. Каждый новый эффект требует отдельных замеров.

## Следующий ID и первый шаг

**SP18 — предварительная сверка семи уровней**, по [паспорту](tasks/SP18.md).
Первым действием заполнить матрицу покрытия: набор/уровень, сценарий,
существующее доказательство, реальный результат, расхождение, владелец SPxx.
Не выдавать сценарий OG с 105 рублями или короткий запуск за полное прохождение.
Если старые доказательства упакованы, читать `docs/storage-maintenance.md`
перед их восстановлением; отсутствие распакованного файла не считать утратой.

Далее: игровые пробелы SP03–SP16 → карта/справка и проверка управления →
SP17 сохранения → полная локализация/звук и оставшаяся доводка видео →
финальный SP18 → SP19 Windows v1 → SP20 Linux/ARM/PortMaster.
Аудит состояния для SP17 и ранний GLES/ARM допустимы независимо, когда есть
нужные входы/устройство. Не ждать полного закрытия старых областей для
предварительной сверки уже работающей игры.
