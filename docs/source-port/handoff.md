Граница текущей сессии по уточнению пользователя: выполнить SP07 и остановиться;
SP08 в этой сессии не запускать. Долгосрочная очередь плана сохраняется.

SP06 завершена в границе состояния/конструкторов/lifecycle. [Инвентарь и
доказательства](spec/world-lifecycle.md): 13 классов OG/PKR/PKE по свежему
read-only Ghidra; AnimationState + Animations, ctor SwitchState/SurfaceState,
полный список сохраняемого/восстанавливаемого/transient для SP17.
Release CTest15/15; 7 миров/20 анимаций/50 slot reuse, exhaustion, class5 fixture,
assets899/21/26 мутаций PASS; 7 реальных процессов ×30 кадров. Хеши неизменны.
Локальные логи: `research/evidence/source-port/sp06-world/checks/report.json`.

Следующий **SP07**, A05/A06: связать `Animations::image(owner)` с Scene bindings,
включая анимированную **стену OG H=72** и предмет $=36, PKR/PKE X/Y/Z=88–90.
Main уже создаёт Animations и активирует по original_cell_bounds на player tick;
GameEvent::base_animation маршрутизирован. Getter const, renderer не меняет мир.
Budget200/signed intervals/END и пограничный двойной event/full queue сохранены.
Scene пока показывает первый кадр; визуальный этап этим не закрыт.
SurfaceState phase18/interval0 — ctor факт; его getter/flowing path довести в SP07.
SP10 получает подтверждённые native54/56/58 class6 без выдуманных названий.

Пустые dynamic projectile slots переиспользуются: native flags0400 помечает
завершённый снаряд, не обычный corpse. Порт освобождает optional сразу;
исходные 899 definitions не имеют0400. Уничтожение Monsters до Projectiles
проверено, callback closure снимается. SP17 снимает snapshot между sweeps,
с Events ring/cursor, дробью часов и audio lock; текущего save API ещё нет.
Изменения предыдущих задач сохранены; коммитов нет.

## Предыдущая передача: SP05 → SP06, 4 ноября 2026

SP05 завершена: read-only Ghidra/Unicorn проверили 45 scheduler-сценариев
трёх оригиналов, 6864 вектора арифметических примитивов, повторные 3399 PIT.
Release CTest 15/15. Семь исходных карт при 30/60/144 FPS дали одинаковые
callback-трассы и контрольные суммы подмножества состояния; pause elapsed0
не меняет мир. Ядро не менялось, добавлены воспроизводимые probes/exporter.
[Адреса, команды, отчёты и границы](spec/scheduler-arithmetic-audit.md).

Scheduler исполняет оригинальные инструкции с контролируемыми часами,
callback-телами и выделением памяти. Безопасные destroy/clear/deferred activation
порта — отдельный CTest-контракт, не равенство опасному native поведению.
Cadence-проверка headless, три секунды: это не полные прохождения, SDL focus,
реальный renderer и не полная snapshot-сверка. EXE/RES SHA-256 неизменны.

Следующая **SP06**, A04: полный инвентарь изменяемых полей/владельцев/слотов,
конструкторы всех классов, уничтожение/повторное использование/сброс и контракт
SP17. Начать с World/WorldObject, Events, Projectiles и текущих состояний служб;
расширять проверки reset/lifecycle по инвентарю. Текущий cadence digest сознательно
не покрывает каждое поле PlayerState/MonsterState/Projectiles.
Существующие изменения SP03/SP04/SP18 сохранены, коммитов нет.

## Принятые решения, которые легко потерять

Активация AI/эффектов использует исходные клеточные границы на player tick,
независимо от renderer, размеров и Hor+ (SP12, решение 3 ноября).
Это заменяет старое требование пробуждения на всей широкой периферии.

SP08/SP15: фильтры разделить по назначению. Первый новый этап — Sharp Bilinear
готового кадра и независимый FXAA сцены перед HUD/оружием/текстом/меню;
затем mipmaps/трилинейная фильтрация и анизотропия; затем эксперимент xBR.
Новые фильтры пока не реализованы; полный объём и проверки — в плане.

SP20: цель GL 1024×768, 60 FPS на RK3326. Оптимизации в расчётной границе
закончены; следующий платформенный участок требует реального RK3326/GLES
и полного игрового кадра. Software — запасной, без требования 60 FPS в этом
размере. Каждый новый эффект требует отдельных замеров.
