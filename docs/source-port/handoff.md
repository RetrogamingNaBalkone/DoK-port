## SP-XBR-GPU — завершено 6 ноября 2026

Исправлено падение FPS от xBR: прежний CPU xbr3 требовал 18,76/84,11/203,22 мс
на сценах 320×160/640×384/1024×614. Теперь отдельный GL2/GLES2 shader
обрабатывает загруженный исходный кадр в FBO 3× и выводит его Nearest;
замер upload+filter на текущем ПК — 0,146/0,478/1,227 мс, без vsync/present.
Это не замер полного runtime FPS и не прогноз для портативок.

У software-Display появился необязательный GL-presenter, но `Display::gl()`
возвращает nullptr и main продолжает CPU-растеризацию мира. При отсутствии
контекста/основного shader остаётся SDL Renderer, при отказе xBR/FBO/highp —
CPU xBR. Превышение лимита GL-текстуры в CPU fallback обслуживается плитками.
Минимумы GL2/GLES2/Windows 8 x64 не повышены. Сам xBR не требует compute,
новых обязательных расширений или иных системных API.

Численные решения xBR стабилизированы точным отношением luma и весами 1/8
на сетке 3×. Относительно прежнего float CPU возможны локальные изменения
на равных контурах. Новая CPU/GPU пара совпадает в пределах 1 уровня канала;
CPU fallback тоже ускорен таблицей весов. Интерфейс/оружие остаются после эффекта.

Release/CTest **20/20**, GL regression и новый xBR probe PASS; **25** процессов
готового пакета проверяют три игры, три размера, fallback/no-GL и 1:1 bypass.
Также **60** choice/alias/F4, **82** общих filter/settings, **68** save/load и
**8** packaged запусков PASS; исходные RES не менялись. Часть этих прогонов
предшествует последнему ограниченному добавлению плиток, покрытому итоговым
xBR probe и 25 пакетными процессами.

Текущий пакет: `artifacts/sdl2/windows-playtest-ogdok/OGDoK.exe`.

и реальные DOS title WAV; SP10 закрыла дополнительный native movement/resolver,
SP15 принята, пакет r1 выдан. SP16 продолжает полные маршруты и сквозные
исходы. Проверять актуальный паспорт SP16 перед продолжением.
Не выдавать короткий запуск или OG105рублей за полное прохождение.

Далее: игровые пробелы SP03–SP16 → карта/справка и проверка управления →
SP17 сохранения → полная локализация/звук и оставшаяся доводка видео →
актуальная очередь — SP20-01…08 Linux x86_64/PortMaster; Windows принята.
Аудит состояния для SP17 и ранний GLES/ARM допустимы независимо, когда есть
нужные входы/устройство. Не ждать полного закрытия старых областей для
предварительной сверки уже работающей игры.
